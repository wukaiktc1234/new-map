## 二、产品创建详细流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端<br/>ProductForm.vue
    participant Store as Pinia Store<br/>product.ts
    participant API as API层<br/>product.ts
    participant Controller as 后端控制器<br/>ProductController
    participant Service as 产品服务<br/>ProductServiceImpl
    participant Validator as 数据校验器<br/>ProductValidator
    participant CategoryService as 分类服务<br/>CategoryServiceImpl
    participant CodeGen as 编码生成器<br/>ProductCodeGenerator
    participant DB as 数据库<br/>MySQL
    participant EventPublisher as 事件发布器
    participant Redis as Redis缓存

    User->>Frontend: 填写产品信息
    Frontend->>Frontend: 前端表单校验
    alt 前端校验失败
        Frontend-->>User: 显示校验错误信息
    else 前端校验通过
        User->>Frontend: 点击"保存"
        Frontend->>Store: 调用createProduct方法
        Store->>API: 发送POST /api/v1/products
        API->>Controller: 传递ProductCreateRequest
        Controller->>Service: 调用createProduct方法

        Service->>Validator: 校验创建请求
        Validator->>Validator: 检查产品名称长度
        Validator->>Validator: 检查价格合法性
        Validator->>Validator: 检查条形码格式
        
        alt 数据校验失败
            Validator-->>Service: 抛出ValidationException
            Service-->>Controller: 返回400错误
            Controller-->>API: 返回校验错误信息
            API-->>Store: 显示错误信息
            Store-->>Frontend: 提示校验失败
        else 数据校验通过
            Service->>CategoryService: 查询分类信息
            CategoryService->>DB: SELECT * FROM product_category WHERE category_id = ?
            DB-->>CategoryService: 返回分类信息
            CategoryService-->>Service: 返回Category对象

            alt 分类不存在
                Service-->>Controller: 抛出BusinessException "分类不存在"
                Controller-->>API: 返回404错误
                API-->>Store: 显示错误信息
            else 分类存在
                Service->>CodeGen: 生成产品编码
                CodeGen->>CodeGen: 按规则生成唯一编码
                CodeGen-->>Service: 返回productCode

                Service->>DB: 检查编码唯一性
                DB-->>Service: 返回检查结果

                alt 编码已存在
                    Service->>CodeGen: 重新生成编码
                    CodeGen-->>Service: 返回新编码
                else 编码唯一
                    Service->>Service: 创建Product实体
                    Service->>Service: 填充基础信息
                    Service->>Service: 填充价格信息
                    Service->>Service: 填充分类信息（冗余存储）
                    Service->>DB: INSERT INTO product
                    DB-->>Service: 返回productId

                    alt 有SKU信息
                        Service->>Service: 保存SKU列表
                        Service->>DB: INSERT INTO product_sku
                        DB-->>Service: 返回skuIds
                    end

                    alt 有属性值
                        Service->>Service: 保存属性值
                        Service->>DB: INSERT INTO product_attribute_value
                        DB-->>Service: 返回valueIds
                    end

                    alt 有图片
                        Service->>Service: 保存图片
                        Service->>DB: INSERT INTO product_image
                        DB-->>Service: 返回imageIds
                    end

                    Service->>Redis: 缓存产品信息
                    Redis-->>Service: 缓存成功

                    Service->>EventPublisher: 发布ProductCreatedEvent
                    EventPublisher->>EventPublisher: 异步通知关联模块

                    Service-->>Controller: 返回ProductDTO
                    Controller-->>API: 返回201 Created
                    API-->>Store: 保存到状态管理
                    Store-->>Frontend: 返回创建成功
                    Frontend-->>User: 提示"产品创建成功"
                    Frontend->>Frontend: 跳转到产品列表
                end
            end
        end
    end
```

## 三、产品查询与搜索流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端<br/>ProductList.vue
    participant Store as Pinia Store<br/>product.ts
    participant API as API层<br/>product.ts
    participant Controller as 后端控制器<br/>ProductController
    participant Service as 产品服务<br/>ProductServiceImpl
    participant Cache as 缓存服务<br/>ProductCacheService
    participant Redis as Redis缓存
    participant DB as 数据库<br/>MySQL
    participant ES as Elasticsearch<br/>全文搜索

    User->>Frontend: 进入产品列表页面
    Frontend->>Store: 调用fetchProductList方法
    Store->>API: 发送POST /api/v1/products/list
    API->>Controller: 传递ProductQueryRequest
    Controller->>Service: 调用listProducts方法

    Service->>Service: 构建查询条件
    
    alt 有关键词搜索
        Service->>ES: 全文搜索产品名称
        ES-->>Service: 返回匹配的产品ID列表
    end

    Service->>Cache: 检查缓存
    Cache->>Redis: GET product:list:{queryHash}
    Redis-->>Cache: 返回缓存结果

    alt 缓存命中
        Cache-->>Service: 返回缓存数据
    else 缓存未命中
        Service->>DB: 执行分页查询
        Note over Service,DB: SELECT * FROM product WHERE ... ORDER BY create_time DESC LIMIT offset, size
        DB-->>Service: 返回产品列表

        Service->>DB: 查询产品主图
        DB-->>Service: 返回图片信息

        Service->>Service: 组装ProductDTO列表
        Service->>Cache: 写入缓存
        Cache->>Redis: SET product:list:{queryHash} {data} EX 300
    end

    Service-->>Controller: 返回PageResult<ProductDTO>
    Controller-->>API: 返回200 OK
    API-->>Store: 保存到状态管理
    Store-->>Frontend: 更新产品列表
    Frontend-->>User: 显示产品列表

    User->>Frontend: 输入搜索关键词
    Frontend->>Frontend: 防抖处理（300ms）
    Frontend->>Store: 调用searchProducts方法
    Store->>API: 发送搜索请求
    API->>Controller: 传递搜索参数
    Controller->>Service: 调用searchProducts方法

    Service->>ES: 全文搜索
    Note over Service,ES: 搜索product_name, description, specification
    ES-->>Service: 返回搜索结果

    Service->>DB: 根据ID查询完整信息
    DB-->>Service: 返回产品详情

    Service-->>Controller: 返回搜索结果
    Controller-->>API: 返回200 OK
    API-->>Store: 更新搜索结果
    Store-->>Frontend: 显示搜索结果
    Frontend-->>User: 展示搜索匹配的产品
```

## 四、产品更新与同步流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端<br/>ProductForm.vue
    participant Store as Pinia Store<br/>product.ts
    participant API as API层<br/>product.ts

    Store->>API: 发送PUT /api/v1/products/{productId}

    Controller->>Service: 调用updateProduct方法

            end

            Service->>Redis: 更新缓存
            Redis-->>Service: 更新成功

            Service->>EventPublisher: 发布ProductUpdatedEvent

            Store-->>Frontend: 返回更新成功
            Frontend-->>User: 提示"产品更新成功"
        end
    end
```

## 五、产品删除与校验流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端<br/>ProductList.vue
    participant Store as Pinia Store<br/>product.ts
    participant API as API层<br/>product.ts
    participant Controller as 后端控制器<br/>ProductController
    participant Service as 产品服务<br/>ProductServiceImpl
    participant CheckService as 删除校验服务<br/>DeleteCheckService
    participant InventoryService as 库存服务<br/>InventoryServiceImpl
    participant OrderService as 订单服务<br/>OrderServiceImpl
    participant DB as 数据库<br/>MySQL
    participant EventPublisher as 事件发布器
    participant Redis as Redis缓存

    User->>Frontend: 选择产品并点击"删除"
    Frontend->>Frontend: 显示确认对话框
    User->>Frontend: 确认删除
    Frontend->>Store: 调用deleteProduct方法
    Store->>API: 发送DELETE /api/v1/products/{productId}
    API->>Controller: 传递productId
    Controller->>Service: 调用deleteProduct方法

    Service->>DB: 查询产品信息
    DB-->>Service: 返回Product对象

    alt 产品不存在
        Service-->>Controller: 抛出BusinessException "产品不存在"
        Controller-->>API: 返回404错误
    else 产品存在
        Service->>CheckService: 检查是否可以删除
        
        CheckService->>InventoryService: 检查库存
        InventoryService->>DB: SELECT SUM(quantity) FROM product_stock WHERE product_id = ?
        DB-->>InventoryService: 返回库存数量
        InventoryService-->>CheckService: 返回库存结果

        CheckService->>OrderService: 检查未完成订单
        OrderService->>DB: SELECT COUNT(*) FROM sales_order WHERE product_id = ? AND status IN ('PENDING', 'PAID')
        DB-->>OrderService: 返回订单数量
        OrderService-->>CheckService: 返回订单结果

        alt 库存大于0
            CheckService-->>Service: 返回"存在库存，不能删除"
            Service-->>Controller: 抛出BusinessException "产品存在库存，无法删除"
            Controller-->>API: 返回400错误
            API-->>Store: 显示错误信息
            Store-->>Frontend: 提示"产品存在库存，无法删除"
        else 存在未完成订单
            CheckService-->>Service: 返回"存在未完成订单"
            Service-->>Controller: 抛出BusinessException "产品存在未完成订单，无法删除"
            Controller-->>API: 返回400错误
            API-->>Store: 显示错误信息
            Store-->>Frontend: 提示"产品存在未完成订单，无法删除"
        else 可以删除
            CheckService-->>Service: 返回"可以删除"
            
            Service->>Service: 逻辑删除产品
            Service->>DB: UPDATE product SET deleted = 1 WHERE product_id = ?
            DB-->>Service: 更新成功

            Service->>DB: 逻辑删除SKU
            Service->>DB: 逻辑删除属性值
            Service->>DB: 逻辑删除图片

            Service->>Redis: 删除缓存
            Redis-->>Service: 删除成功

            Service->>EventPublisher: 发布ProductDeletedEvent
            Note over EventPublisher: 通知关联模块清理数据

            Service-->>Controller: 返回成功
            Controller-->>API: 返回200 OK
            API-->>Store: 从列表中移除
            Store-->>Frontend: 返回删除成功
            Frontend-->>User: 提示"产品删除成功"
            Frontend->>Frontend: 刷新产品列表
        end
    end
```

## 七、库存联动流程

```mermaid
sequenceDiagram
    participant InventoryModule as 库存模块
    participant EventListener as 事件监听器<br/>ProductEventListener
    participant Service as 产品服务<br/>ProductServiceImpl
    participant DB as 数据库<br/>MySQL
    participant WebSocket as WebSocket服务
    participant Frontend as 前端<br/>ProductList.vue

    InventoryModule->>EventListener: 发布InventoryChangedEvent
    Note over InventoryModule: 入库、出库、盘点等操作

    EventListener->>Service: 处理库存变更事件
    Service->>DB: 查询产品当前库存
    DB-->>Service: 返回库存数据

    Service->>Service: 计算总库存
    Service->>Service: 计算可用库存

    alt 库存低于预警值
        Service->>Service: 标记库存预警状态
        Service->>WebSocket: 推送库存预警通知
        WebSocket->>Frontend: 实时显示预警标记
    end

    Service->>DB: UPDATE product SET total_stock = ?, available_stock = ?
    DB-->>Service: 更新成功

    Service->>WebSocket: 推送库存更新
    WebSocket->>Frontend: 实时更新库存显示
    Frontend->>Frontend: 更新产品卡片库存信息

    alt 库存从0变为有库存
        Service->>Service: 更新产品可售状态
        Service->>DB: UPDATE product SET status = 1 WHERE status = 0
        Service->>WebSocket: 推送产品上架通知
    else 库存变为0
        Service->>Service: 更新产品缺货状态
        Service->>WebSocket: 推送缺货通知
    end
```

## 十一、数据备份与恢复流程

```mermaid
sequenceDiagram
    participant Scheduler as 定时任务<br/>ProductBackupJob
    participant BackupService as 备份服务<br/>ProductBackupService
    participant DB as 数据库<br/>MySQL
    participant FileSystem as 文件系统
    participant Admin as 管理员
    participant RestoreService as 恢复服务<br/>ProductRestoreService

    Scheduler->>BackupService: 触发定时备份任务
    BackupService->>BackupService: 生成备份时间戳

    BackupService->>DB: LOCK TABLES product READ
    DB-->>BackupService: 锁定成功

    BackupService->>DB: SELECT * FROM product INTO OUTFILE
    DB-->>BackupService: 导出产品主表

    BackupService->>DB: SELECT * FROM product_sku INTO OUTFILE
    DB-->>BackupService: 导出SKU表

    BackupService->>DB: SELECT * FROM product_category INTO OUTFILE
    DB-->>BackupService: 导出分类表

    BackupService->>DB: UNLOCK TABLES
    DB-->>BackupService: 解锁成功

    BackupService->>FileSystem: 压缩备份文件
    FileSystem-->>BackupService: 压缩完成

    BackupService->>FileSystem: 保存备份清单
    BackupService->>BackupService: 清理过期备份（保留30天）
    BackupService->>Scheduler: 备份完成

    Admin->>RestoreService: 发起恢复请求
    RestoreService->>RestoreService: 验证备份文件完整性

    alt 备份文件损坏
        RestoreService-->>Admin: 返回"备份文件损坏"
    else 备份文件完整
        RestoreService->>DB: 创建恢复点
        RestoreService->>DB: 清空现有数据
        RestoreService->>DB: 导入备份数据
        RestoreService->>DB: 验证数据一致性

        alt 数据不一致
            RestoreService->>DB: 回滚到恢复点
            RestoreService-->>Admin: 返回"恢复失败，已回滚"
        else 数据一致
            RestoreService-->>Admin: 返回"恢复成功"
        end
    end
```
