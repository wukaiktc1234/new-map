## 三、系统设置配置流程

```mermaid
sequenceDiagram
    participant Admin as 管理员
    participant Frontend as 前端<br/>SystemSettings/Index.vue
    participant BasicSettings as 基础设置组件<br/>BasicSettings.vue
    participant API as API层<br/>systemSettings.ts
    participant Controller as 后端控制器<br/>SysSettingController
    participant Service as 系统设置服务<br/>SysSettingServiceImpl
    participant DB as 数据库<br/>sys_settings表

    Admin->>Frontend: 访问系统设置页面
    Frontend->>Frontend: 加载左侧菜单
    Frontend-->>Admin: 显示11个功能模块
    
    Admin->>Frontend: 点击"基础设置"
    Frontend->>BasicSettings: 加载基础设置组件
    BasicSettings->>API: getSettingsByGroup('basic')
    API->>Controller: GET /api/v1/settings/groups/basic
    Controller->>Service: getSettingsByGroup('basic')
    Service->>DB: SELECT * FROM sys_settings WHERE setting_group = 'basic'
    DB-->>Service: 返回基础设置列表
    Service-->>Controller: 返回Result<List<SysSetting>>
    Controller-->>API: 返回200 OK
    API-->>BasicSettings: 返回设置数据
    BasicSettings->>BasicSettings: 渲染表单
    BasicSettings-->>Admin: 显示基础设置表单
    
    Admin->>BasicSettings: 修改系统名称
    Admin->>BasicSettings: 点击"保存设置"
    BasicSettings->>API: setGlobalSetting('system_name', '新名称')
    API->>Controller: POST /api/v1/settings/global/system_name
    Controller->>Service: setGlobalSetting(key, value, currentUser)
    
    Service->>DB: 查询是否已存在该设置
    DB-->>Service: 返回查询结果
    
    alt 设置已存在
        Service->>DB: UPDATE sys_settings SET setting_value = ?, updated_by = ?
    else 设置不存在
        Service->>DB: INSERT INTO sys_settings (...)
    end
    
    DB-->>Service: 返回操作结果
    Service-->>Controller: 返回Result.success()
    Controller-->>API: 返回200 OK
    API-->>BasicSettings: 返回保存成功
    BasicSettings->>BasicSettings: 显示成功提示
    BasicSettings-->>Admin: 提示"设置保存成功"
```

## 四、分层配置优先级流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端
    participant API as API层
    participant Controller as SysSettingController
    participant Service as SysSettingServiceImpl
    participant DB as 数据库

    User->>Frontend: 请求获取设置值
    Frontend->>API: getSettingValue('theme', 'user', 'user123')
    API->>Controller: GET /api/v1/settings/values/theme?targetType=user&targetId=user123
    Controller->>Service: getSettingValue('theme', 'user', 'user123')
    
    Note over Service: 分层查找策略：用户级 > 门店级 > 全局级
    
    Service->>Service: 第1层：查找用户级配置
    Service->>DB: SELECT * FROM sys_settings WHERE setting_key='theme' AND scope_type='user' AND scope_id='user123'
    DB-->>Service: 返回结果
    
    alt 找到用户级配置
        Service-->>Controller: 返回用户配置值
    else 未找到用户级配置
        Service->>Service: 第2层：查找门店级配置
        Service->>DB: SELECT * FROM sys_settings WHERE setting_key='theme' AND scope_type='store' AND scope_id='store001'
        DB-->>Service: 返回结果
        
        alt 找到门店级配置
            Service-->>Controller: 返回门店配置值
        else 未找到门店级配置
            Service->>Service: 第3层：查找全局配置
            Service->>DB: SELECT * FROM sys_settings WHERE setting_key='theme' AND scope_type='global'
            DB-->>Service: 返回结果
            
            alt 找到全局配置
                Service-->>Controller: 返回全局配置值
            else 未找到全局配置
                Service-->>Controller: 返回null
            end
        end
    end
    
    Controller-->>API: 返回设置值
    API-->>Frontend: 返回Result<String>
    Frontend->>Frontend: 应用设置值
    Frontend-->>User: 显示配置结果
```
