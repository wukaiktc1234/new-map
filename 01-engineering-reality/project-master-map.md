| 分类 | 数量 | 说明 |

### 权限验证架构

```
┌─────────────────────────────────────────────────┐
│                 请求进入                         │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────┐
│  第1层：接口权限验证 (Permission Code)           │
│  - 校验用户是否拥有该接口的访问权限               │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────┐
│  第2层：数据范围验证 (Data Scope)                 │
│  - 8级数据范围过滤                               │
│  - 仅自己 / 部门内 / 区域内 / ... / 全部          │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────┐
│  第3层：字段级权限 (Field Permission)            │
│  - 控制敏感字段的可见性                          │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────┐
│                 业务逻辑执行                     │
└─────────────────────────────────────────────────┘
```

## 八、风险与关注点

| 风险点 | 说明 | 建议 |
|--------|------|------|
| Service 层膨胀 | 293 个 Service 可能存在职责不清 | 定期审视 Service 边界 |
| Mapper 与 Entity 比值 | Mapper 302 vs Entity 326，接近 1:1 | 检查是否存在冗余 Mapper |
| 权限码维护 | 180 个权限码管理成本高 | 考虑权限码分组或动态配置 |
| 迁移文件累积 | 160 个迁移文件 | 定期合并历史迁移 |
