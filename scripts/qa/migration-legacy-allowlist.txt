# migration-legacy-allowlist.txt —— 迁移文件命名**存量放行名单**
#
# 规则：
#   1) **只允许存量，不允许新增**；新增一行需 Lead 批准；
#   2) gate 只认本文件里**具体文件名**，不按「形状相似」放行 —— 新文件即使长得像历史形态也照样报错；
#   3) 每行格式：<文件名> | <放行理由>；
#   4) 到期复核：每次架构评审检查本文件，能删的行要删（迁移改名/合并后就不需要了）。
#
# 为什么需要它：项目早期命名有三种历史形态（点分 V1.0.0.x、连写 V2026021701、日期无序号 V20260404），
# 统一改名的代价大于收益（会动 Flyway 版本号/checksum），故按存量放行、新增从严。
