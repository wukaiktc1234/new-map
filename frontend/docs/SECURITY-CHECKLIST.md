## 🚨 应急响应预案

### 场景1：求职者反映二维码无法使用

**可能原因及解决方案**：
```
原因A：Token已过期（超过30分钟）
解决：在管理端重新生成二维码

原因B：Token使用次数已达上限（10次）
解决：在管理端重新生成二维码

原因C：H5服务器未运行
解决：检查终端1的服务器状态，必要时重启

原因D：求职者未连接门店WiFi
解决：指导其连接正确的WiFi网络
```

### 场景2：怀疑有人恶意扫描系统

**应急措施**：
```
1. 立即检查H5服务器日志
   - 查看是否有大量来自同一IP的请求
   - 查看是否有异常的API调用

2. 如发现可疑行为：
   - 记录可疑IP地址和时间戳
   - 重启H5服务器清除所有Token
   - 通知店内员工暂停使用二维码

3. 后续加固：
   - 降低速率限制阈值（如改为30次/分钟）
   - 缩短Token有效期（如改为10分钟）
   - 考虑启用IP黑名单功能
```

### 场景3：路由器配置被重置

**恢复步骤**：
```
1. 重新登录路由器管理界面
2. 启用访客网络功能
3. 开启AP隔离选项
4. 修改WiFi密码（防止未授权访问）
5. 测试AP隔离是否生效
6. 记录新的配置信息到本文档
```
