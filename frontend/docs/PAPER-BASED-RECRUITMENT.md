# 门店招聘系统 - 纸质材料过渡方案 v1.0

## 📌 方案概述

**适用场景**：个体餐饮门店日常招聘
**使用周期**：现在 → 小程序开发完成前（预计2-3个月）
**核心思路**：纸质收集 + 后台批量录入 + 数据数字化管理

## 🔧 第二部分：店员操作流程

### 日常工作流程

```
每日开店前：
□ 检查应聘表库存（不足50张时补充打印）
□ 准备好签字笔、夹板、收集盒
□ 将应聘表放在前台显眼位置

接待求职者时：
□ 主动递上应聘表和笔
□ 简要说明："请先填一下这张表，我们稍后联系您"
□ 指导填写位置（如果有座位的话）

收集表格后：
□ 快速检查必填项是否完整
  - 姓名、电话、应聘职位 三项必须有
  - 如有遗漏，当场询问补充
□ 在"店员操作区"生成取票码
  - 格式：FT-XXXXXXXX（8位随机字母数字）
□ 将表格放入"待录入"文件夹

空闲时段（建议每天固定时间）：
□ 统一将纸质表单录入到管理系统
□ 使用管理端的"快速录入"功能
□ 录入后勾选"录入系统"并填写日期
□ 将已录入的表格归档保存（保留30天备查）
```

### 取票码生成规则

```
格式：FT-XXXXXXXX

规则：
- FT = 固定前缀（代表"Fight Talent"或自定义含义）
- X = 8位字符（大写字母+数字混合）
- 示例：FT-KL7M9X2P、FT-A3B8C9D2

生成方法：
方法A：手动编写（按顺序）
  - 从 FT-00000001 开始递增
  
方法B：随机生成（推荐）
  - 使用在线工具或手机App生成随机码
  - 或参考以下Python脚本：

import random
import string

def generate_ticket_code():
    prefix = "FT-"
    chars = string.ascii_uppercase + string.digits
    code = ''.join(random.choices(chars, k=8))
    return prefix + code

# 示例输出：FT-J7K9M2XP
```

## 📊 第四部分：数据管理最佳实践

### 归档策略

```
纸质表格生命周期：

新表格（未填写）
  ↓ 放在前台
  ↓ 求职者领取填写
  ↓ 已填写完毕
  ↓ 放入"待录入"文件夹（当天）
  
已录入系统
  ↓ 放入"已归档"文件夹
  ↓ 保留30天（备查期）
  ↓ 超过30天
  ↓ 粉碎机销毁（保护隐私）

文件夹结构建议：
📂 招聘文档/
  ├── 📁 待录入/          （当日收集的表格）
  ├── 📁 已归档/          （已录入系统的表格）
  │   ├── 📁 2026-05/
  │   ├── 📁 2026-06/
  │   └── ...
  ├── 📁 空白表格/        （备用的新表格）
  └── 📄 应聘登记表模板.docx （原始模板文件）
```

### 录入频率建议

| 门店规模 | 建议录入频率 | 每次耗时 |
|---------|------------|---------|
| 小型（<50人/天） | 每天下班前集中录入 | 15-30分钟 |
| 中型（50-150人/天） | 上下午各录一次 | 每次20分钟 |
| 大型（>150人/天） | 安排专人实时录入 | 持续进行 |

### 数据质量检查

```
每周检查项：

□ 录入完整性
  - 所有纸质表格都已录入？
  - 是否有遗漏的表格？

□ 数据准确性
  - 电话号码格式正确？（11位手机号）
  - 必填字段都有值？

□ 状态更新
  - 已联系的求职者状态是否已更新？
  - 超过7天未处理的记录是否有跟进？

□ 隐私合规
  - 已归档的表格是否安全保管？
  - 超期表格是否已销毁？
```

## 💡 第七部分：常见问题解答

### Q1：纸质表容易丢失怎么办？

**A**：
- 表格成本低（几分钱一张），多打印一些备用
- 在表格底部印上门店联系电话（万一丢失可联系归还）
- 重要数据已录入系统，丢失纸质表不影响业务
- 定期盘点库存（每周一次）

### Q2：字迹潦草看不清怎么办？

**A**：
- 设计大字体（正文12pt以上）
- 关键字段（姓名、电话）加大加粗
- 要求使用黑色签字笔（禁止铅笔）
- 录入时如有疑问，立即电话确认
- 必要时可要求求职者重填

### Q3：有人恶意填写假信息怎么办？

**A**：
- 电话回访时会自动发现无效号码
- 录入时标注可疑记录（明显乱填的）
- 不影响正常业务（忽略即可）
- 这在任何招聘渠道都会遇到，不是纸质特有问题

### Q4：纸质方案看起来不够"高科技"，会影响品牌形象吗？

**A**：
- 恰恰相反！很多高端餐厅仍使用纸质菜单
- 体现人文关怀和温度感
- 对不擅长使用手机的求职者更友好
- 可以配合精美的设计和排版提升质感
- 关键是服务质量，不是形式

### Q5：将来切换到小程序时，历史数据怎么处理？

**A**：
- 所有数据都在数据库中（通过手动录入）
- 切换时零成本迁移
- 纸质和小程序只是不同的"输入渠道"
- 后端存储完全一致，无需任何转换
