# Windows防火墙快速配置指南 - 图形界面版

## 方法：通过控制面板添加防火墙规则（推荐新手）

### 步骤详解（带截图说明）

#### Step 1: 打开防火墙高级设置

**方法1：通过搜索**
1. 按 `Win` 键（Windows键）
2. 输入关键词：`wl`
3. 点击搜索结果中的：
   ```
   "高级安全 Windows Defender 防火墙"
   或
   "Windows Defender 防火墙高级安全"
   ```

**方法2：通过控制面板**
1. 按 `Win + R` 键
2. 输入：`firewall.cpl` 
3. 回车
4. 左侧点击："高级设置"

---

#### Step 2: 创建新的入站规则

在打开的窗口中：

1. **左侧菜单**，点击：**"入站规则"**
   
2. **右侧操作栏**，点击：**"新建规则..."**
   （位置在右上角，"操作"标题下方）

---

#### Step 3: 规则类型选择

弹出向导窗口：

1. 选择第一个选项：**"端口(P)"**
2. 点击：**"下一步 >"**

---

#### Step 4: 协议和端口

1. 选择：**"TCP(T)"**
2. 选择：**"特定本地端口"**
3. 在输入框中填入：**`3003`**
4. 点击：**"下一步 >"**

---

#### Step 5: 操作

选择：**"允许连接(A)"**
点击：**"下一步 >"**

---

#### Step 6: 配置文件

**全部勾选**这三个选项：
- ☑ **域(D)** (Domain)
- ☑ **专用(P)** (Private)  
- ☑ **公用(U)** (Public)

> 说明：公用网络 = 访客WiFi通常被识别为此类型

点击：**"下一步 >"**

---

#### Step 7: 名称和描述

填写以下信息：

| 字段 | 填写内容 |
|------|---------|
| **名称(N):** | `H5招聘服务器` |
| **描述(D):** | `允许访客网络访问门店招聘表单服务(端口3003)` |

点击：**"完成"**

---

#### Step 8: 验证规则创建成功

回到"入站规则"列表页面：

1. 在规则列表中找到刚创建的规则
   - 名称：**"H5招聘服务器"**
   - 方向：**"入站"**
   - 操作：**"允许连接"**
   - 配置文件：**"域,专用,公用"**
   - 已启用：**"是"** ✅

2. 如果看到绿色图标且显示"已启用"，说明成功！

---

## 验证测试

### 测试步骤：

1. **手机连接访客WiFi**
2. **打开浏览器，访问**：
   ```
   http://192.168.0.106:3003/
   ```

3. **预期结果**：
   - ✅ 显示："📶 门店WiFi已连接 - 欢迎页"
   - （这是我们设置的伪装页面）

4. **进一步测试**：
   - 在管理端生成新二维码
   - 手机扫描二维码
   - 应该能看到应聘登记表单

## 如果仍然无法访问？

### 检查清单：

□ **规则是否真的创建成功？**
   - 在"入站规则"列表中能否看到"H5招聘服务器"？
   - 它的"已启用"列是否显示"是"？
   - 它的"配置文件"是否包含"公用"？

□ **手机连接的是正确的网络吗？**
   - 确认手机连接的是"访客WiFi"
   - 不是主WiFi或其他网络

□ **IP地址正确吗？**
   - 在电脑上重新确认IP：`ipconfig`
   - 确认手机访问的IP与电脑IPv4地址一致

□ **尝试关闭所有防火墙测试（临时）**
   
   **警告：这会降低安全性，仅用于测试！**
   
   步骤：
   1. 控制面板 → Windows Defender 防火墙
   2. 左侧："启用或关闭 Windows Defender 防火墙"
   3. 专用网络设置："关闭 Windows Defender 防火墙"
   4. 公用网络设置："关闭 Windows Defender 防火墙"
   5. 点击确定
   
   测试完成后**务必重新开启**！

## 高级排查（如果上述方法都不行）

### 使用命令行验证连通性：

在电脑上打开CMD（命令提示符），执行：

```cmd
# 测试本地监听
telnet localhost 3003

# 如果提示连接成功，说明本地正常

# 测试从内网访问
telnet 192.168.0.106 3003

# 如果失败，检查防火墙
```

### 查看防火墙日志：

```powershell
# 以管理员身份运行PowerShell

# 启用防火墙日志
Set-NetFirewallProfile -All -LogFileName "%systemroot%\System32\LogFiles\Firewall\pfirewall.log" -LogMaxSizeKilobytes 1024 -LogAllowed True -LogBlocked True

# 查看最近的阻止记录
Get-Content "$env:SystemRoot\System32\LogFiles\Firewall\pfirewall.log" -Tail 50 | Select-String "3003"
```

### 使用PowerShell添加规则（需要管理员权限）：

```powershell
# 右键点击开始菜单 → "终端(管理员)" 或 "PowerShell(管理员)"

# 执行以下命令：
New-NetFirewallRule `
    -DisplayName "H5招聘服务器-端口3003" `
    -Direction Inbound `
    -LocalPort 3003 `
    -Protocol TCP `
    -Action Allow `
    -Profile Any `
    -Description "允许访客设备访问门店招聘H5表单"

# 验证
Get-NetFirewallRule -DisplayName "H5*"
```

## 常见错误及解决

### 错误1："访问被拒绝"

**原因**：权限不足
**解决**：确保以管理员身份运行

### 错误2：规则创建后仍无法访问

**可能原因**：
- 规则的"配置文件"没有包含"公用"
- 手机连接的网络被识别为其他类型
- 还有其他安全软件拦截（杀毒软件、第三方防火墙）

**解决**：
1. 编辑规则，确保三个配置文件都勾选
2. 临时关闭杀毒软件测试
3. 检查是否有第三方防火墙软件

### 错误3：规则列表中找不到刚创建的规则

**可能原因**：
- 创建时出错但没报错
- 创建到了错误的分类（出站而非入站）
- 被组策略覆盖

**解决**：
1. 刷新规则列表（F5）
2. 在"出站规则"中也查找一下
3. 尝试重新创建

## 完成后的安全建议

✅ **必须做**：
- 防火墙规则仅开放必要的端口（3003）
- 保持AP隔离开启
- 定期检查规则是否还存在

📝 **建议做**：
- 记录此规则的创建时间和目的
- 在安全文档中备注此例外
- 设置定期审查提醒（每月一次）

❌ **不要做**：
- 不要开放不必要的端口范围（如1-65535）
- 不要将规则设置为永久有效（如果只是临时使用）
- 不要在公共网络环境下完全关闭防火墙
