# 路由器访客网络配置指南

## 问题诊断

当前状态：
- ✅ 访客网络已开启
- ❌ 但未启用"AP隔离"或"VLAN隔离"
- 结果：访客设备仍可访问主网络设备的IP和端口

## 解决方案（按路由器品牌分类）

### 方法1：启用AP隔离（大多数路由器支持）

#### TP-Link路由器：
1. 登录管理界面（通常 http://192.168.0.1 或 http://tplogin.cn）
2. 进入「无线设置」→「无线高级设置」
3. 找到「启用AP隔离」或「客户端隔离」选项
4. **勾选启用**
5. 保存并重启

#### 小米/Redmi路由器：
1. 打开小米WiFi App或访问 miwifi.com
2. 进入「常用设置」→「WiFi设置」
3. 找到「访客WiFi」→「高级设置」
4. 启用「隔离模式」（防止互访内网）
5. 保存

#### 华为路由器：
1. 登录 192.168.3.1 或使用华为智能家居App
2. 进入「Wi-Fi设置」→「访客网络」
3. 开启「AP隔离」开关
4. 应用设置

#### ASUS/华硕路由器：
1. 登录 router.asus.com
2. 进入「无线网络」→「专业设置」
3. 在「Isolation」选项中选择「Enable」
4. 应用

### 方法2：创建独立VLAN（企业级路由器/OpenWrt）

如果您的路由器支持VLAN功能：

```bash
# OpenWrt/LEDE 配置示例
# /etc/config/network

config interface 'guest'
    option type 'bridge'
    option ifname 'eth0.10'  # VLAN 10
    option proto 'static'
    option ipaddr '192.168.100.1'
    option netmask '255.255.255.0'

# 防火墙规则：禁止访客网络访问主网络
config rule
    option name 'Deny-Guest-to-LAN'
    option src 'guest'
    option dest 'lan'
    option target 'REJECT'
    option dest_port '8081'  # 后端端口
    option dest_port ':3002' # 管理前端端口
```

### 方法3：使用独立的访客路由器（最安全但成本高）

硬件方案：
```
[互联网] → [主路由器] → [店员网络]
                    → [副路由器(访客)] → [求职者手机]
                              ↓
                        完全物理隔离
```

优点：
✅ 物理级别隔离（无法绕过）
✅ 可独立控制带宽、时长
✅ 即使被攻击也不影响主网络

缺点：
❌ 需要额外购买路由器（¥50-200）
❌ 需要额外的网络布线或桥接配置

## 验证隔离是否生效

### 测试步骤：

1. **手机连接访客WiFi**
2. **打开浏览器访问**：
   - http://192.168.0.106:3003 （H5服务器）
   - http://192.168.0.106:8081 （后端API）
   - http://192.168.0.106:3002 （管理前端）

3. **预期结果（隔离成功）**：
   - ❌ 所有页面都无法打开（超时或拒绝连接）
   - ✅ 只能上网（访问外网），不能访问内网

4. **预期结果（隔离失败）**：
   - ⚠️ 仍能打开某些页面（说明隔离未生效）

## 如果路由器不支持AP隔离怎么办？

### 替代方案：软件防火墙

在店员电脑上配置Windows防火墙规则：

```powershell
# 以管理员身份运行PowerShell

# 允许特定端口仅从本地访问
New-NetFirewallRule -DisplayName "Block External Port 3003" `
    -Direction Inbound -LocalPort 3003 -Protocol TCP `
    -Action Block -RemoteAddress 192.168.0.0/24

# 允许特定IP访问（如店员自己的手机）
New-NetFirewallRule -DisplayName "Allow My Phone" `
    -Direction Inbound -LocalPort 3003 -Protocol TCP `
    -Action Allow -RemoteAddress 192.168.0.xxx
```

**注意**：这会阻止所有外部设备访问，包括合法的求职者手机！

## 推荐的最终架构

### 对于门店场景（低成本 + 安全）：

```
┌─────────────────────────────────────────────┐
│  最佳实践：三层防护                          │
├─────────────────────────────────────────────┤
│                                             │
│  Layer 1: 网络层                            │
│  ├─ 启用AP隔离（路由器设置）                │
│  ├─ 或使用独立访客网络                      │
│  └─ 效果：访客设备无法扫描内网IP            │
│                                             │
│  Layer 2: 应用层（已实现 ✅）               │
│  ├─ Token时效性（30分钟过期）               │
│  ├─ 使用次数限制（10次/码）                 │
│  ├─ IP白名单（仅允许私有地址）              │
│  └─ 速率限制（防暴力扫描）                  │
│                                             │
│  Layer 3: 流程层                           │
│  ├─ 二维码即时生成（用完即删）              │
│  ├─ 不在顾客面前显示完整URL                 │
│  └─ 定期更换Token密钥                       │
│                                             │
└─────────────────────────────────────────────┘
```
