# 第十九轮：交班「应上交现金」区块精简

> 反馈："应交现金部分太过于复杂"。这轮只做减法，不减信息。

---

## 改前 → 改后

**改前**（同一块里 6 层信息）：
- 大标题「应上交现金」+ 38px 金额
- 3 个胶囊：现金收入 / 现金退款 / = 净现金
- 备用金胶囊（另起一行）
- 「钱箱应有现金」整行（标签 + 长算式 + 金额）
- 「实点现金」整行（标签 + 输入 + 差异）
- 两行长提示语

**改后**（3 行，一眼扫完）：

```
应上交现金                                        ¥0.00
现金收入 ¥0.00 − 现金退款 ¥116.00 = −¥116.00（退款大于收款，已由备用金垫付）
──────────────────────────────────────────────
备用金 ¥500.00 留存钱箱 │ 钱箱应有 ¥384.00 │ 实点 [填入] 待点钞
⚠ 本班次现金净流出 ¥116.00，已从备用金垫付；请店长补足，否则下一班零钱不足。
```

具体动作：
1. **胶囊全删**，换成一行小字算式；净额为负时才补一句括号说明；
2. **金额改为左右对齐**（label 左、金额右），字号 38 → 34px，卡片高度从 220 → ~150px；
3. **钱箱核对收成一条**：备用金 / 钱箱应有 / 实点输入 / 长短款胶囊用竖线分隔，不再各占一行；
4. **长提示语删除**，只留一条会"催人"的净流出提示（且不再重复金额）；
5. 「备用金 + 现金收入 − 现金退款」的算式改为 **sr-only**：读屏和断言仍能取到，视觉上不再重复；
6. 连带清理了 5 个已废弃的样式块（chip / float / cc-row / cc-label / cc-value）与深色覆盖。

## 信息没有丢

| 信息 | 位置 |
|---|---|
| 应上交多少 | 第一行右侧大字 |
| 怎么算出来的 | 第二行小字（现金收入 − 现金退款） |
| 备用金多少、留存 | 第三行第一段（含「留存钱箱」） |
| 钱箱应有（验算口径） | 第三行第二段（`data-test="shift-drawer-expected"`） |
| 实点与长短款 | 第三行第三、四段（0 → 账实相符；差 → 长/短款） |
| 净流出时谁补钱 | 第四条红色提示 |
