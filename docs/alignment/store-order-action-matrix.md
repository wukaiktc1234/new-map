# 门店运营 / 订单 / 销售 / 产品中心操作矩阵

> 范围：门店档案、门店证件、门店库存、门店要货、待办任务、日结对账、桌台/排队、订单查询、退款管理、预约管理、菜品管理、套餐管理、分类管理
> 用途：梳理各页面可执行动作、触发位置、状态约束、回写 API 及实现缺口
> 生成日期：2026-07-30

---

## 矩阵字段说明

| 字段 | 说明 |
|-----|------|
| 模块/页面 | 功能模块及对应 Vue 文件 |
| 操作名称 | 用户可见动作 |
| 操作入口 | 动作在页面中的触发位置 |
| 状态/前置条件 | 执行动作前单据或数据需满足的条件 |
| 调用 API | 实际回写的后端接口（含 Method + Path） |
| 目标状态 | 动作完成后业务对象的状态变化 |
| 实现状态 | 已实现 / 部分实现 / 未实现 / 模拟 |
| 备注 / 问题 | 用 `[待修复]` 标注缺口、命名不一致、权限缺失等问题 |
