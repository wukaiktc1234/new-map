## 第一章 系统概述

### 1.1 系统简介

食品溯源系统管理端是面向个体餐饮企业（单店或2-5家门店的小型连锁）的一站式数字化经营管理平台。系统以**食品溯源**为核心差异化能力，整合产品、采购、仓储、门店运营、财务、人事、订单、会员、设备、电子签章等全业务流程，帮助经营者实现"从农田到餐桌"的食品安全全链路透明化。

系统主要解决餐饮企业的五大核心痛点：
- 食材来源难以追溯、合规压力大
- 库存管理混乱、损耗高
- 成本核算不精确、利润不清晰
- 人员管理粗放、健康证/合同到期容易遗漏
- 多门店协同效率低、数据无法实时汇总

### 1.2 适用对象

| 维度 | 描述 |
|------|------|
| 企业规模 | 单店或2-5家门店的小型连锁餐饮企业 |
| 员工数量 | 5-50人 |
| 年营业额 | 50万-500万元 |
| 典型用户 | 单店经营者、小连锁经营者、合规敏感型经营者 |

### 1.3 登录方式

1. **访问地址**：在浏览器输入 `http://localhost:3000/` 进入登录页
2. **默认管理员账号**：
   - 用户名：`admin`
   - 初始密码：`Admin@123`
3. **登录步骤**：
   - 打开登录页，系统显示"食品溯源系统"登录表单
   - 在"用户名"输入框中输入账号
   - 在"密码"输入框中输入密码
   - 点击【登录】按钮进入系统
4. **首次登录**：强烈建议管理员首次登录后立即修改默认密码（参见 2.4 修改密码）。

> **安全提示**：默认账号仅用于初始化，正式使用前请创建专属账号并禁用或修改默认管理员密码。Token 有效期 30 分钟，过期后系统自动使用 Refresh Token 续期（7天有效），无需频繁重新登录。

### 1.4 浏览器要求

| 浏览器 | 最低版本 | 推荐版本 |
|--------|---------|---------|
| Google Chrome | 90+ | 最新稳定版 |
| Microsoft Edge | 90+ | 最新稳定版 |
| Mozilla Firefox | 88+ | 最新稳定版 |

> **不支持**：IE 浏览器、Chrome 89 及以下版本。建议屏幕分辨率不低于 1366×768，推荐 1920×1080。

### 1.5 系统角色与权限

系统基于 RBAC（基于角色的访问控制）权限模型，预设以下主要角色：

| 角色 | 角色标识 | 适用人员 | 数据范围 |
|------|---------|---------|---------|
| 老板/超级管理员 | owner | 企业老板、所有者 | 全部数据 |
| 系统管理员 | admin | IT管理员（系统内置） | 全部数据 |
| 运营总监 | ops_director | 运营负责人 | 公司级数据 |
| 财务总监 | finance_director | 财务负责人 | 公司级财务数据 |
| HR总监 | hr_director | 人事负责人 | 公司级人事数据 |
| 店长/门店经理 | store_manager | 门店负责人 | 本门店数据 |
| 组长/团队负责人 | team_leader | 门店班次负责人 | 本班次数据 |
| 区域经理 | region_manager | 多门店区域负责人 | 指定门店数据 |
| 排班员 | scheduler | 门店排班专员 | 本门店排班数据 |
| 稽查专员 | auditor | 合规/审计人员 | 全部只读数据 |
| 普通员工 | employee | 门店一线员工 | 仅本人数据 |

不同角色可见的菜单和操作权限不同，由系统管理员在【权限中心】统一配置（详见第十五章）。

## 第二章 首页与导航

### 2.1 登录后首页布局

成功登录后，系统默认进入【工作台】首页（地址 `/home`）。整体布局分为三个区域：

1. **顶部导航栏**（位于页面顶部）：
   - 左侧：系统Logo与名称"食品溯源系统"
   - 中部：当前页面标题（随路由变化自动更新浏览器标签页标题）
   - 右侧：主题切换按钮、通知图标、用户头像下拉菜单
2. **左侧菜单栏**（位于页面左侧）：
   - 按"工作台 / 产品中心 / 订单管理 / 运营中心 / 门店管理 / 采购管理 / 仓储管理 / 会员管理 / 财务中心 / 资产管理 / 人事管理 / 食品追溯 / 设备管理 / 电子签章 / 系统管理"顺序排列
   - 每个一级菜单可展开/折叠，显示该模块下的二级功能菜单
   - 菜单按用户角色自动过滤，无权限的菜单不显示
   - 菜单可整体折叠为图标模式，扩大内容区可视面积
3. **内容区**（位于页面中央）：
   - 显示当前选中页面的具体内容
   - 工作台首页展示经营关键指标卡片（如今日营业额、订单数、库存预警、临期食材等）

### 2.2 工作台首页

**功能说明**：工作台是用户登录后的默认首页，集中展示经营关键指标和待办事项，帮助用户快速了解当前经营状态。

**主要区域**：
- 顶部统计卡片：今日营业额、今日订单数、在售菜品数、库存预警数
- 中部图表区：近7天营业额趋势、订单来源分布
- 待办事项列表：临期食材预警、健康证到期提醒、合同到期提醒、采购审批待办等
- 快捷入口：常用功能一键跳转（如新增菜品、创建采购订单、库存盘点等）

**操作步骤**：
1. 登录系统后自动进入工作台
2. 查看顶部统计卡片了解当日经营概况
3. 在待办事项列表中点击具体事项，可直接跳转到对应处理页面
4. 点击快捷入口图标，快速进入常用功能

**注意事项**：
- 工作台数据每5分钟自动刷新一次，也可手动点击右上角刷新按钮立即更新
- 待办事项根据当前用户角色动态显示，不同角色看到的待办内容不同

### 2.3 主题切换（浅色/深色）

**功能说明**：系统支持浅色和深色两种主题，适配不同光线环境下的使用需求。

**操作步骤**：
1. 在顶部导航栏右侧找到主题切换图标（太阳/月亮图标）
2. 点击图标，系统在浅色/深色主题间切换
3. 主题选择会自动记忆，下次登录保持一致

**注意事项**：
- 所有页面均完整适配两种主题，切换不会丢失当前页面数据
- 推荐白天使用浅色主题，夜间或低光环境使用深色主题以减轻视觉疲劳

### 2.4 个人中心

**进入方式**：点击顶部导航栏右上角的用户头像，在下拉菜单中选择【个人中心】，进入 `/personal-center` 页面。

#### 2.4.1 修改密码

**操作步骤**：
1. 进入个人中心页面
2. 切换到"修改密码"标签页
3. 输入"当前密码"
4. 输入"新密码"（要求8位以上，包含大小写字母、数字、特殊字符）
5. 输入"确认新密码"，确保与上一步一致
6. 点击【确认修改】按钮
7. 修改成功后，系统提示"密码修改成功"，下次登录需使用新密码

**注意事项**：
- 出于安全考虑，修改密码后当前登录态不会失效，但其他设备的登录会被踢出
- 建议每90天修改一次密码，不要使用过于简单的密码

#### 2.4.2 偏好设置

**功能说明**：个性化偏好设置，包括默认主题、默认首页、表格分页大小等。

**操作步骤**：
1. 进入个人中心页面
2. 切换到"偏好设置"标签页
3. 设置默认主题（浅色/深色/跟随系统）
4. 设置默认首页（工作台/运营总览/待办事项等）
5. 设置表格默认每页显示条数（10/20/50/100）
6. 点击【保存设置】按钮

#### 2.4.3 个人信息

**功能说明**：查看和编辑个人基本信息。

**可查看信息**：用户名、姓名、所属角色、所属门店/部门、邮箱、手机号、头像、入职日期等。

**注意事项**：部分敏感信息（如角色、所属门店）需联系系统管理员修改，个人仅可编辑联系方式和头像。

## 第三章 产品中心

产品中心是系统的基础数据模块，管理菜品、套餐、分类、定价和成本核算，为订单和采购提供产品数据支撑。

**进入方式**：左侧菜单栏点击【产品中心】展开子菜单。

### 3.1 菜品管理

**功能说明**：维护餐厅所有菜品的详细信息，包括菜品名称、分类、规格、价格、图片、配方（BOM）等。菜品是订单和成本核算的基础。

**进入路径**：产品中心 → 菜品管理（`/product/food`）

#### 3.1.1 新增菜品

**操作步骤**：
1. 进入菜品管理页面，显示菜品列表（默认按创建时间倒序）
2. 点击页面右上方【新增】按钮，弹出新增菜品对话框
3. 填写菜品基本信息：
   - 菜品名称（必填，不可重复）
   - 菜品分类（必选，从已有分类中选择）
   - 菜品编码（系统自动生成或手动输入）
   - 售价（必填，单位：元）
   - 成本价（系统根据配方自动核算，也可手动调整）
   - 单位（份/斤/瓶/盘等）
   - 菜品图片（上传菜品实物图，建议 800×600 像素）
   - 菜品描述（口味、特色等）
4. 设置菜品规格（如大份/小份、加辣/不加辣等，可选）
5. 配置配方（BOM）：关联所需原料及用量（用于成本核算和库存扣减）
6. 设置菜品状态：在售/停售
7. 点击【保存】按钮完成新增

**注意事项**：
- 菜品编码一旦保存不可修改，请谨慎填写
- 配方（BOM）中的原料必须先在【商品档案】中创建（详见4.1）
- 配方设置后，系统自动计算成本价；如手动覆盖成本价，后续配方变更不会自动同步

#### 3.1.2 编辑菜品

**操作步骤**：
1. 在菜品列表中找到目标菜品
2. 在操作列点击【编辑】按钮（蓝色文字按钮）
3. 在弹出的编辑对话框中修改信息
4. 点击【保存】按钮提交修改

**注意事项**：已产生订单的菜品不建议修改售价，可通过"菜品定价"功能进行价格调整并保留历史记录。

#### 3.1.3 删除菜品

**操作步骤**：
1. 在菜品列表中找到目标菜品
2. 在操作列点击【删除】按钮（红色文字按钮）
3. 系统弹出确认对话框，提示"确定要删除该菜品吗？"
4. 点击【确定】完成删除

**注意事项**：
- 系统采用逻辑删除，删除后菜品不在列表显示，但历史订单中的菜品记录保留
- 已被套餐引用或在售订单关联的菜品不允许删除，需先解除关联
- 误删可通过联系系统管理员在数据库层面恢复（仅限48小时内）

#### 3.1.4 导入导出

**导入操作**：
1. 在菜品列表页点击【导入】按钮
2. 下载导入模板（Excel格式）
3. 按模板填写菜品信息
4. 点击【选择文件】上传填好的Excel
5. 系统校验数据并提示导入结果（成功数、失败数、失败原因）

**导出操作**：
1. 在菜品列表页可按条件筛选菜品
2. 点击【导出】按钮
3. 系统将当前筛选结果导出为Excel文件下载

**注意事项**：导入时如菜品编码已存在，将更新该菜品信息而非新增。

#### 3.1.5 查询菜品

**操作步骤**：
1. 在菜品列表上方的搜索区域，可按以下条件筛选：
   - 菜品名称（模糊查询）
   - 菜品分类
   - 菜品状态（在售/停售/全部）
   - 价格区间
2. 点击【查询】按钮刷新列表
3. 点击【重置】按钮清空所有筛选条件

### 3.2 菜品分类管理

**功能说明**：维护菜品分类树（如凉菜、热菜、汤品、主食、饮品、酒水等），用于菜品归类和点单界面的分类导航。

**进入路径**：产品中心 → 菜品分类（`/product/category`）

#### 3.2.1 新增分类

**操作步骤**：
1. 进入菜品分类页面，左侧显示分类树
2. 选择父分类（如需创建子分类），点击【新增子分类】按钮；或在根节点点击【新增顶级分类】
3. 在弹出的对话框中填写：
   - 分类名称（必填）
   - 分类编码（必填，唯一）
   - 排序号（数字越小越靠前）
   - 分类图标（可选）
   - 分类描述
4. 点击【保存】按钮

#### 3.2.2 编辑/删除分类

**编辑**：选中分类 → 点击【编辑】按钮 → 修改信息 → 保存
**删除**：选中分类 → 点击【删除】按钮 → 确认删除

**注意事项**：
- 含有子分类的分类不允许直接删除，需先删除所有子分类
- 已被菜品引用的分类不允许删除，需先将菜品迁移到其他分类
- 分类编码不可修改

### 3.3 套餐管理

**功能说明**：将多个菜品组合成套餐，统一售价，支持套餐内菜品替换、加减项等灵活配置，常用于午餐套餐、家庭套餐等促销场景。

**进入路径**：产品中心 → 套餐管理（`/product/combo`）

#### 3.3.1 创建套餐

**操作步骤**：
1. 进入套餐管理页面，点击【新增套餐】按钮
2. 填写套餐基本信息：
   - 套餐名称（如"双人情侣套餐"）
   - 套餐编码
   - 套餐售价
   - 套餐图片
   - 有效期（开始日期、结束日期）
   - 销售时段（如仅午市可用）
3. 配置套餐内容：
   - 添加主菜（必选，1份）
   - 添加配菜（可选，可设置可选数量）
   - 添加饮品（可选，可多选）
4. 设置套餐内菜品是否可替换（如主菜可在A/B之间二选一）
5. 设置套餐状态：在售/停售
6. 点击【保存】按钮

**注意事项**：
- 套餐成本 = 套餐内所有菜品的成本之和，系统自动核算
- 套餐售价应低于菜品单点总价，否则失去套餐吸引力
- 套餐过期后自动下架，需重新设置有效期才能恢复销售

### 3.4 菜品定价

**功能说明**：集中管理菜品价格调整，保留历史价格记录，支持按分类批量定价、按时间段定价（如午市特价）等策略。

**进入路径**：产品中心 → 菜品定价（`/product/pricing`）

#### 3.4.1 调整菜品价格

**操作步骤**：
1. 进入菜品定价页面，显示所有在售菜品当前售价
2. 可按分类筛选菜品
3. 在菜品行的"新售价"列输入调整后的价格
4. 可选：填写"调价原因"（如成本上涨、促销活动）
5. 可选：设置"生效时间"（默认立即生效，可设置未来某时间生效）
6. 点击【批量保存】按钮提交调价

**注意事项**：
- 每次调价都会生成价格历史记录，可在菜品详情中查看完整调价轨迹
- 调价生效后，新订单按新价格计算；已有订单不受影响
- 大规模调价建议先在测试环境验证，避免影响线上经营

### 3.5 菜品成本分析

**功能说明**：基于菜品配方（BOM）和原料最新采购价，自动核算菜品成本，分析毛利和毛利率，辅助定价决策。

**进入路径**：产品中心 → 菜品成本分析（`/product/cost-analysis`）

**主要功能**：
- 成本清单：展示每个菜品的配方成本明细（原料名称、用量、单价、小计）
- 毛利分析：显示售价、成本、毛利、毛利率
- 成本趋势：展示菜品成本随原料价格变化的趋势图
- 预警提示：毛利率低于设定阈值的菜品高亮显示

**操作步骤**：
1. 进入菜品成本分析页面
2. 选择分析维度：按菜品查看 / 按分类汇总
3. 设置时间范围（默认本月）
4. 查看成本构成和毛利分析
5. 点击菜品行可展开查看配方成本明细
6. 点击【导出】按钮可导出成本分析报告

**注意事项**：
- 成本数据依赖菜品配方（BOM）的完整性，未设置配方的菜品成本显示为0
- 原料价格取最近一次采购入库的实际价格，无采购记录的取商品档案中的参考价
- 建议每月初查看成本分析，及时调整售价或优化采购

## 第四章 采购管理

采购管理模块覆盖从供应商管理、采购计划、采购订单到入库验收、结算的全流程，与仓储管理联动实现采购到入库的无缝衔接。

**进入方式**：左侧菜单栏点击【采购管理】展开子菜单。

### 4.1 商品档案

**功能说明**：维护采购物资（原料、辅料、包材等）的基础档案，是采购、仓储、追溯模块的基础数据。每条档案对应一种可采购物资。

**进入路径**：采购管理 → 商品档案（`/purchase/archive`）

#### 4.1.1 新增商品

**操作步骤**：
1. 进入商品档案页面，点击【新增】按钮
2. 在弹出的对话框中填写：
   - 商品名称（必填，如"五花肉"）
   - 商品编码（必填，唯一，建议使用条码或自定义编码规则）
   - 商品分类（必选，详见4.2）
   - 规格（如500g/袋、10kg/箱）
   - 单位（kg、g、L、个、袋等）
   - 参考采购价（用于采购计划预算估算）
   - 保质期（天，用于临期预警）
   - 储存条件（常温/冷藏/冷冻）
   - 供应商（可关联默认供应商）
   - 商品图片
3. 点击【保存】按钮

**注意事项**：
- 商品编码建议与供应商条码一致，便于扫码收货
- 保质期字段影响食品追溯模块的临期预警，请准确填写
- 一种商品可关联多个供应商，但需指定一个默认供应商

#### 4.1.2 编辑/删除商品

操作方式同菜品管理（3.1.2、3.1.3），注意已被采购订单引用的商品不允许删除。

### 4.2 商品分类

**功能说明**：维护商品（物资）分类，如肉类、蔬菜类、水产类、调味品、粮油、酒水饮料、包材等。

**进入路径**：采购管理 → 商品分类（`/purchase/material-category`）

**操作步骤**：参考菜品分类管理（3.2），支持树形分类结构，可新增、编辑、删除分类。

### 4.3 供应商档案

**功能说明**：维护供应商信息，包括资质证照、供货范围、合作历史、评价等，是采购合规和追溯的关键基础数据。

**进入路径**：采购管理 → 供应商档案（`/purchase/supplier`）

#### 4.3.1 新增供应商

**操作步骤**：
1. 进入供应商档案页面，点击【新增供应商】按钮
2. 填写基本信息：
   - 供应商名称（必填，如"XX农产品有限公司"）
   - 统一社会信用代码（必填）
   - 联系人、联系电话、邮箱
   - 供货地址
   - 主营品类（如肉类、蔬菜）
3. 上传资质证照：
   - 营业执照（必传）
   - 食品经营许可证（必传）
   - 食品生产许可证（如适用）
   - 检验检疫证明（如适用）
4. 设置合作状态：合作中/暂停合作/终止合作
5. 点击【保存】按钮

**注意事项**：
- 资质证照的"有效期"字段必填，到期前30天系统自动预警
- 暂停合作状态的供应商不能创建新的采购订单
- 资质信息是食品溯源的核心数据，请务必完整上传

#### 4.3.2 供应商评价

**操作步骤**：
1. 在供应商列表中选择目标供应商，点击【评价】按钮
2. 从五个维度打分（1-5分）：
   - 商品质量
   - 交货及时性
   - 价格合理性
   - 服务态度
   - 售后响应
3. 填写评价说明
4. 点击【提交评价】按钮

**注意事项**：系统按月汇总供应商评价，作为供应商分级（A/B/C/D级）的依据。

### 4.4 采购计划

**功能说明**：基于销售预测、库存现状和历史采购数据，制定周期性采购计划，经审批后生成采购订单。

**进入路径**：采购管理 → 采购计划（`/purchase/plan`）

#### 4.4.1 创建采购计划

**操作步骤**：
1. 进入采购计划页面，点击【新增计划】按钮
2. 填写计划基本信息：
   - 计划名称（如"2026年7月第一周采购计划"）
   - 计划类型（周计划/月计划/临时计划）
   - 计划周期（开始日期、结束日期）
   - 门店（多门店连锁时选择所属门店）
   - 编制人（默认当前用户）
3. 添加采购明细：
   - 选择商品（从商品档案选择）
   - 填写计划采购数量
   - 系统自动带出参考单价和预算金额
   - 填写备注（如特殊要求）
4. 可选：点击【智能推荐】按钮，系统根据历史消耗和库存自动推荐采购量
5. 点击【保存草稿】或【提交审批】按钮

**注意事项**：
- 草稿状态的计划可编辑，提交审批后不可修改
- 智能推荐基于近30天平均日消耗量和当前库存，仅供参考

#### 4.4.2 采购计划审批

**操作步骤**：
1. 审批人在采购计划列表中找到"待审批"状态的计划
2. 点击【查看】按钮查看计划详情
3. 可逐条审核采购明细，对有异议的明细可标记并填写意见
4. 点击【审批通过】或【审批驳回】按钮
5. 审批通过后，计划状态变为"已审批"，可据此生成采购订单

### 4.5 采购订单

**功能说明**：基于采购计划或临时需求创建采购订单，发送给供应商，跟踪订单状态直至收货。

**进入路径**：采购管理 → 采购订单（`/purchase/orders`）

#### 4.5.1 创建采购订单

**操作步骤**：
1. 进入采购订单页面，点击【新增订单】按钮
2. 选择创建方式：
   - **从采购计划生成**：选择已审批的采购计划，系统自动带出明细
   - **手动创建**：直接添加采购明细
3. 填写订单信息：
   - 供应商（必选）
   - 期望到货日期
   - 收货门店/仓库
   - 收货人、联系电话
   - 结算方式（月结/现结/预付）
4. 添加/调整采购明细：
   - 商品名称、数量、单位、单价
   - 系统自动计算金额和小计
5. 填写订单备注
6. 点击【保存草稿】或【确认下单】按钮

**注意事项**：
- "确认下单"后订单状态变为"已下单"，不可再编辑明细
- 系统自动生成唯一订单号，格式如 PO20260701001

#### 4.5.2 订单状态流转

采购订单状态及操作：
- **草稿** → 可编辑、可删除
- **已下单** → 等待供应商发货，可【取消订单】
- **部分收货** → 已收部分货物，可继续收货
- **已收货** → 全部收货完成，进入结算流程
- **已结算** → 完成付款结算
- **已取消** → 订单取消

**操作步骤（确认下单）**：
1. 在订单列表找到"草稿"状态的订单
2. 点击【确认下单】按钮
3. 系统提示"确定下单吗？下单后不可修改"，点击【确定】

### 4.6 采购收货

**功能说明**：供应商送货到货后，仓库管理员或收货员核对商品数量和质量，完成入库验收。

**进入路径**：采购管理 → 采购收货（`/purchase/stockin`）

#### 4.6.1 收货操作

**操作步骤**：
1. 进入采购收货页面，显示"已下单"状态的待收货订单
2. 找到对应订单，点击【收货】按钮
3. 系统弹出收货界面，显示订单明细
4. 逐条核对：
   - 订单数量 vs 实收数量
   - 检查商品外观、保质期、温度（冷藏/冷冻品）
   - 如有差异，在"实收数量"列修改
   - 如有质量异议，在"备注"列说明并选择"拒收"或"部分收货"
5. 上传收货照片（可选，用于质量追溯）
6. 填写收货人、收货时间
7. 点击【确认收货】按钮
8. 系统自动：
   - 生成入库单（推送至仓储管理）
   - 更新订单状态为"部分收货"或"已收货"
   - 触发库存增加

**注意事项**：
- 收货时务必核对保质期，临期或过期商品应拒收
- 冷链商品需核对到货温度是否符合要求
- 收货记录是食品溯源链的关键节点，请如实填写

### 4.7 采购合同

**功能说明**：管理与供应商签订的采购合同，支持合同起草、审批、签署、归档全流程。

**进入路径**：采购管理 → 采购合同（`/purchase/contract`）

#### 4.7.1 创建合同

**操作步骤**：
1. 进入采购合同页面，点击【新增合同】按钮
2. 填写合同信息：
   - 合同名称
   - 合同编号（自动生成）
   - 供应商
   - 合同类型（年度框架/单次采购/长期供货）
   - 合同金额
   - 签订日期、生效日期、到期日期
3. 选择合同模板（详见14.1电子签章）
4. 填写合同条款（基于模板预填）
5. 上传合同附件（如扫描件）
6. 点击【保存】或【提交审批】按钮

#### 4.7.2 合同审批

**操作步骤**：
1. 审批人在合同列表找到"待审批"合同
2. 查看合同详情和附件
3. 点击【审批通过】或【驳回】
4. 审批通过后，合同进入"待签署"状态

### 4.8 电子合同

**功能说明**：在线电子合同签署功能，支持双方在线签署、自动盖章、签署存证，免去纸质合同来回邮寄。

**进入路径**：采购管理 → 电子合同（`/purchase/electronic-contract`）

#### 4.8.1 发起电子签署

**操作步骤**：

2. 系统跳转到电子合同页面，选择我方签署印章（详见14.1）
3. 设置签署顺序：我方先签 / 对方先签
4. 填写对方签署人信息（姓名、手机号、邮箱）

#### 4.8.2 跟踪签署进度

**操作步骤**：
1. 在电子合同列表查看签署状态：
   - 待我方签署
   - 待对方签署
   - 已完成签署
   - 已过期
   - 已拒签
2. 点击合同查看签署日志（谁、何时、IP、设备等）

**注意事项**：
- 电子合同与纸质合同具有同等法律效力（依据《电子签名法》）
- 签署完成的合同自动归档，不可篡改
- 详见4.9"签署链接"和第十四章"电子签章"模块

### 4.9 签署链接管理

**功能说明**：管理发送给供应商的签署链接，可查看签署状态、重发链接、撤销签署等。

**进入路径**：采购管理 → 签署链接（`/supplier-portal/links`）

**操作步骤**：

**注意事项**：供应商也可通过专属 H5 签署门户（`/portal/sign`）无需登录直接签署，无需开通系统账号。

### 4.10 采购申请

**功能说明**：各部门/门店发起的临时采购需求，经审批后转为采购订单。

**进入路径**：采购管理 → 采购申请（`/purchase/request`）

**操作步骤**：
1. 点击【新增申请】按钮
2. 填写申请信息：
   - 申请部门/门店
   - 申请事由
   - 期望到货日期

### 4.11 物资需求提报

### 4.12 采购结算

**功能说明**：管理采购订单的付款结算，支持月结、现结、预付等多种方式，与财务中心应付账款联动。

#### 4.12.1 创建结算单

### 4.13 采购报表

### 4.14 采购数据分析

## 第五章 仓储管理

仓储管理模块提供多仓库、全链路库存管理能力，覆盖入库、出库、调拨、盘点、预警、报损等场景，为采购、追溯、财务提供库存数据支撑。

**进入方式**：左侧菜单栏点击【仓储管理】展开子菜单。

### 5.1 库存概览

**功能说明**：全局库存总览，展示各仓库/门店的库存金额、商品数量、预警情况等关键指标。

**进入路径**：仓储管理 → 库存概览（`/warehouse/overview`）

**主要展示**：
- 总库存金额、总商品种类数
- 各仓库/门店库存分布卡片
- 库存预警Top榜单（低于安全库存的商品）
- 临期商品Top榜单（接近保质期的商品）
- 近30天出入库趋势图

**操作步骤**：
1. 进入库存概览页面，默认显示全部仓库
2. 可在顶部切换查看的仓库/门店
3. 点击预警榜单中的商品，跳转到商品库存详情
4. 点击【刷新】按钮获取最新数据

### 5.2 门店库存查看

**功能说明**：门店员工查看本门店库存的只读视图，不可操作出入库。

**进入路径**：仓储管理 → 门店库存查看（`/warehouse/store-inventory`）

**操作步骤**：
1. 进入页面，默认显示当前用户所属门店的库存
2. 可按商品分类、商品名称、库存状态筛选
3. 点击商品行查看批次明细（生产日期、保质期、入库时间）

**注意事项**：此页面仅门店员工可见，仅供查看，不能操作；如需调拨或领用，需通过"库存调拨"或"库存出库"流程。

### 5.3 库存管理

**功能说明**：核心库存台账，展示所有商品的批次库存明细，支持按批次管理（先进先出）。

**进入路径**：仓储管理 → 库存管理（`/warehouse/inventory`）

**主要功能**：
- 商品库存列表（商品名称、规格、当前库存、可用库存、占用库存）
- 批次明细：每个商品按批次展示（批号、生产日期、保质期、数量、入库单号）
- 库存台账：商品历史出入库流水
- 库存快照：导出某时间点的库存快照

**操作步骤**：
1. 进入库存管理页面
2. 在搜索栏输入商品名称或编码
3. 点击商品行展开批次明细
4. 点击【查看流水】查看该商品的历史出入库记录

### 5.4 库存出库

**功能说明**：处理门店领用、菜品制作扣库、报废等出库场景。

**进入路径**：仓储管理 → 库存出库（`/warehouse/outbound`）

#### 5.4.1 创建出库单

**操作步骤**：
1. 进入库存出库页面，点击【新增出库】按钮
2. 选择出库类型：
   - **领用出库**：门店领用物资
   - **制作出库**：菜品制作扣减库存（通常由订单系统自动触发）
   - **报废出库**：物资损坏、过期报废
   - **退货出库**：退回供应商
3. 选择出库仓库/门店
4. 添加出库明细：
   - 选择商品
   - 系统显示当前可用库存
   - 输入出库数量
   - 选择批次（如有多批次，按先进先出原则推荐）
5. 填写出库原因、经办人
6. 点击【提交】按钮
7. 出库单生成后，库存立即扣减

**注意事项**：
- 出库数量不能超过可用库存
- 报废出库需上传照片说明报废原因，便于追溯
- 制作出库通常由订单系统自动触发，不建议手动创建

### 5.5 库存调整

**功能说明**：因计量误差、系统错误等原因对库存数量进行调整，所有调整记录留痕，便于审计。

**进入路径**：仓储管理 → 库存调整（`/warehouse/adjust`）

**操作步骤**：
1. 进入库存调整页面，点击【新增调整】按钮
2. 选择仓库、商品、批次
3. 显示当前库存数量
4. 输入调整后数量
5. 选择调整原因（盘盈/盘亏/计量误差/系统错误/其他）
6. 填写调整说明（必填，详细描述原因）
7. 上传附件（如盘点照片）
8. 点击【提交】按钮
9. 调整单进入审批流程（小幅度调整自动通过，大额度调整需主管审批）

**注意事项**：
- 库存调整是高敏感操作，所有调整记录永久保留，不可删除
- 建议优先通过"库存盘点"流程处理差异，盘点结果自动生成调整单

### 5.6 库存报损

**功能说明**：专门处理商品损坏、变质、过期等损失，记录报损原因和金额，与财务成本核算联动。

**进入路径**：仓储管理 → 库存报损（`/warehouse/inventory-loss`）

**操作步骤**：
1. 进入库存报损页面，点击【新增报损单】按钮
2. 选择仓库、商品、批次
3. 输入报损数量
4. 选择报损原因：
   - 自然损耗
   - 储存不当
   - 过期变质
   - 运输损坏
   - 鼠害虫害
   - 其他
5. 填写报损说明
6. 上传报损照片（必传，至少2张）
7. 系统自动计算报损金额（数量 × 最近采购价）
8. 点击【提交报损】按钮
9. 报损单进入审批流程，审批通过后库存扣减，财务计入损耗成本

### 5.7 库存预警

**功能说明**：监控商品库存水平，当库存低于安全库存或高于最大库存时自动预警。

**进入路径**：仓储管理 → 库存预警（`/warehouse/warning`）

**预警类型**：
- **低库存预警**：当前库存 < 安全库存
- **高库存预警**：当前库存 > 最大库存（避免积压）
- **缺货预警**：当前库存 = 0
- **临期预警**：接近保质期的商品

**操作步骤**：
1. 进入库存预警页面，默认显示所有预警
2. 可按预警类型、仓库、商品分类筛选
3. 查看预警明细：商品名称、当前库存、安全库存、预警等级
4. 对低库存预警，可点击【立即补货】跳转到采购订单创建
5. 对临期预警，可点击【查看批次】定位具体批次

#### 5.7.1 设置安全库存

**操作步骤**：
1. 在库存预警页面点击【库存阈值设置】按钮
2. 选择商品
3. 设置安全库存和最大库存
4. 点击【保存】按钮

**注意事项**：建议安全库存 = 日均消耗量 × 采购周期天数 × 1.5（安全系数）。

### 5.8 库存盘点

**功能说明**：定期盘点库存，核对账实差异，生成盘点报告和调整单。

**进入路径**：仓储管理 → 库存盘点（`/warehouse/check`）

#### 5.8.1 创建盘点任务

**操作步骤**：
1. 进入库存盘点页面，点击【新建盘点】按钮
2. 填写盘点信息：
   - 盘点名称（如"2026年6月底月度盘点"）
   - 盘点类型（全盘/部分盘点）
   - 盘点仓库
   - 盘点范围（全部商品/指定分类/指定商品）
   - 盘点开始时间
3. 点击【创建】按钮，系统生成盘点单
4. 系统自动锁定盘点范围内的库存（盘点期间不允许出入库操作）

#### 5.8.2 执行盘点

**操作步骤**：
1. 在盘点列表找到"进行中"的盘点单，点击【开始盘点】
2. 系统显示盘点表：商品名称、规格、账面库存、实盘数量
3. 逐项清点实物，在"实盘数量"列填写实际数量
4. 如发现损坏商品，在"损坏数量"列填写
5. 可分批保存（盘点工作量大时）
6. 全部盘点完成后，点击【提交盘点】按钮
7. 系统自动对比账面与实盘，生成差异列表

#### 5.8.3 处理盘点差异

**操作步骤**：
1. 系统生成盘点差异报告
2. 对每项差异，选择处理方式：
   - **盘盈**：自动生成入库调整单
   - **盘亏**：自动生成出库调整单（需说明原因）
3. 填写差异原因说明
4. 点击【确认处理】按钮
5. 盘点单状态变为"已完成"，库存自动调整

**注意事项**：
- 盘点期间锁定库存，建议选择营业低谷时段进行
- 盘点差异超过5%需主管审批
- 盘点记录永久保留，作为审计依据

### 5.9 库存报表

**功能说明**：多维度库存统计报表，辅助库存管理决策。

**进入路径**：仓储管理 → 库存报表（`/warehouse/report`）

**主要报表**：
- 库存明细表（实时库存快照）
- 出入库汇总表
- 库存周转率分析
- 滞销商品分析
- 库存资金占用分析
- 报损统计表

**操作步骤**：
1. 选择报表类型
2. 设置筛选条件（时间范围、仓库、商品分类等）
3. 点击【查询】生成报表
4. 点击【导出】下载Excel版本

### 5.10 库位管理

**功能说明**：管理仓库内的物理存储位置（库位），便于商品快速定位和先进先出管理。

**进入路径**：仓储管理 → 库位管理（`/warehouse/location`）

**操作步骤**：
1. 进入库位管理页面，左侧显示库位树（如冷库A-01-01）
2. 点击【新增库位】按钮创建库位
3. 填写库位编码、名称、所属区域、储存条件
4. 在库存管理中可将商品关联到具体库位
5. 库位可启用/停用，停用前需清空库存

### 5.11 库存调拨

**功能说明**：在仓库之间或门店之间调拨库存，适用于多门店连锁的物资调配。

**进入路径**：仓储管理 → 库存调拨（`/warehouse/transfer`）

**操作步骤**：
1. 进入库存调拨页面，点击【新增调拨】按钮
2. 选择调出仓库/门店、调入仓库/门店
3. 添加调拨明细：商品、批次、数量
4. 选择运输方式（自送/物流）
5. 填写预计到达时间
6. 点击【提交调拨】按钮
7. 调出方确认出库，调入方确认入库后，调拨完成

**注意事项**：调拨在途期间，库存处于"在途"状态，不计入双方可用库存。

### 5.12 智能补货建议

**功能说明**：基于历史消耗、当前库存、安全库存、采购周期等数据，智能推荐补货商品和数量。

**进入路径**：仓储管理 → 智能补货建议（`/warehouse/smart-restock`）

**操作步骤**：
1. 进入智能补货建议页面
2. 系统自动列出建议补货商品：
   - 商品名称、当前库存、安全库存
   - 建议补货数量
   - 推荐供应商
   - 预计补货金额
3. 可勾选需要补货的商品
4. 调整建议数量（如有特殊需求）
5. 点击【生成采购订单】按钮，一键创建采购订单（详见4.5）

**注意事项**：智能建议仅供参考，请结合促销活动、季节因素等综合判断。

## 第六章 财务中心

财务中心模块覆盖收支管理、成本核算、应收应付、报表分析等，实现经营数据的财务视角呈现。**财务中心仅限 owner、admin、finance_director 角色可见**，单人店（mini模式）不开放财务中心。

**进入方式**：左侧菜单栏点击【财务中心】展开子菜单。

### 6.1 财务总账

**功能说明**：以会计凭证为核心的总账管理，记录所有财务事项，生成总账、明细账、科目余额表。

**进入路径**：财务中心 → 财务总账（`/finance/ledger`）

**主要功能**：
- 凭证管理：新增、修改、审核、过账会计凭证
- 总账查询：按科目查询总账余额和发生额
- 明细账查询：按科目查询明细发生记录
- 科目余额表：展示所有科目的期初、本期发生、期末余额
- 试算平衡表：检查借贷平衡

**操作步骤（新增凭证）**：
1. 进入财务总账页面，切换到"凭证管理"标签
2. 点击【新增凭证】按钮
3. 填写凭证日期、凭证字号（自动生成）
4. 添加会计分录：
   - 选择科目（从会计科目表选择）
   - 输入借方金额或贷方金额
   - 填写摘要
5. 系统自动校验借贷平衡（借方合计 = 贷方合计）
6. 点击【保存】按钮（草稿状态）
7. 点击【审核】按钮提交审核
8. 审核通过后点击【过账】按钮，凭证计入总账

**注意事项**：
- 已过账的凭证不可修改，需通过红字凭证冲销
- 凭证字号按月连续编号，不可跳号
- 建议每日下班前完成当日凭证录入和审核

### 6.2 会计科目管理

**功能说明**：维护会计科目表，支持多级科目，预设餐饮行业标准科目模板。

**进入路径**：财务中心 → 会计科目（`/finance/subject`）

**操作步骤**：
1. 进入会计科目页面，左侧显示科目树（资产类、负债类、权益类、损益类等）
2. 点击【新增科目】按钮添加科目
3. 填写：科目编码、科目名称、科目类别、余额方向、父科目
4. 可启用/停用科目（已使用的科目不可停用）

**注意事项**：科目编码规则遵循国家标准（如1001库存现金、1002银行存款），新增科目建议咨询专业会计。

### 6.3 会计期间管理

**功能说明**：管理会计期间（月份），支持期末结账、反结账操作。

**进入路径**：财务中心 → 会计期间（`/finance/period`）

**操作步骤**：
1. 进入会计期间页面，显示年度期间列表
2. 每个月份有状态：未开始/开放/已结账
3. 月末操作：
   - 点击【期末结账】按钮，对当前月份结账
   - 结账后该期间不能再录入凭证
4. 如需调整已结账期间的凭证，点击【反结账】按钮（需主管授权）

**注意事项**：
- 期末结账前需完成所有凭证录入和审核
- 反结账是高风险操作，需谨慎，并记录操作原因

### 6.4 应收账款

**功能说明**：管理客户的应收款项，跟踪收款进度，预警逾期账款。

**进入路径**：财务中心 → 应收账款（`/finance/receivable`）

**主要功能**：
- 应收单据列表：未收款的应收单据
- 收款记录：已收款的记录
- 账龄分析：按账龄（0-30天、31-60天、61-90天、90天以上）统计
- 逾期预警：超过合同账期的应收款

**操作步骤（登记收款）**：
1. 进入应收账款页面
2. 找到待收款的应收单据
3. 点击【收款】按钮
4. 填写收款信息：收款日期、收款金额、收款方式、银行账户
5. 上传银行回单照片
6. 点击【确认收款】按钮

### 6.5 应付账款

**功能说明**：管理对供应商的应付款项，跟踪付款进度，与采购结算联动。

**进入路径**：财务中心 → 应付账款（`/finance/payable`）

**主要功能**：
- 应付单据列表：未付款的应付单据（来自采购结算）
- 付款记录：已付款的记录
- 账龄分析
- 付款计划：规划未来付款

**操作步骤**：参考6.4应收账款的收款操作，付款操作类似，需填写付款方式和银行账户。

### 6.6 成本管理

**功能说明**：核算菜品成本、采购成本、人工成本、租金等各项成本，分析成本结构。

**进入路径**：财务中心 → 成本管理（`/finance/cost`）

**主要功能**：
- 成本归集：从采购、仓储、人事模块自动归集各项成本
- 成本分摊：将公共成本（如水电、租金）分摊到各门店/菜品
- 成本分析：成本结构占比、成本趋势、单位成本
- 标准成本 vs 实际成本对比

**操作步骤**：
1. 进入成本管理页面
2. 选择分析维度：按门店/按菜品/按成本项目
3. 设置时间范围
4. 查看成本分析图表
5. 点击【导出】生成成本分析报告

### 6.7 预算管理

**功能说明**：制定和跟踪各部门/门店的预算执行情况。**仅标准连锁及以上规模可见**。

**进入路径**：财务中心 → 预算管理（`/finance/budget`）

**操作步骤**：
1. 点击【新增预算】按钮
2. 选择预算类型：收入预算/成本预算/费用预算
3. 选择预算维度：按门店/按部门/按科目
4. 设置预算周期（年度/季度/月度）
5. 录入预算金额
6. 提交审批
7. 系统自动跟踪实际执行情况，生成预算执行报告

### 6.8 资金管理

**功能说明**：管理银行账户、现金流、资金调拨。**仅标准连锁及以上规模可见**。

## 第七章 人事管理

人事管理模块覆盖员工全生命周期管理，包括员工档案、组织架构、考勤、招聘、入职、培训、健康证、合同、薪资等。**人事管理仅限 owner、admin、hr_director 角色可见**。

**进入方式**：左侧菜单栏点击【人事管理】展开子菜单。

### 7.1 员工管理

**功能说明**：维护员工基础档案，是考勤、薪资、合同等模块的基础数据。

**进入路径**：人事管理 → 员工管理（`/hr/employee`）

#### 7.1.1 新增员工

**操作步骤**：
1. 进入员工管理页面，点击【新增员工】按钮
2. 填写基本信息：
   - 姓名（必填）
   - 性别（男/女/其他）
   - 身份证号（必填，唯一，系统校验格式和重复）
   - 出生日期（系统根据身份证自动带出）
   - 民族、籍贯、政治面貌
   - 联系电话、紧急联系人
   - 邮箱
3. 填写入职信息：
   - 入职日期（必填）
   - 所属门店/部门
   - 岗位（参见7.3岗位职级）
   - 职级
   - 员工编号（自动生成或手动输入）
   - 用工类型（全职/兼职/实习）
4. 上传员工照片、身份证复印件
5. 设置员工状态：在职/试用期/离职
6. 点击【保存】按钮

**注意事项**：
- 身份证号一经保存不可修改，请仔细核对
- 试用期员工转正需通过"入职办理"模块处理（参见7.7）
- 员工档案是合规审计的关键资料，请确保信息真实完整

#### 7.1.2 编辑/离职操作

**编辑**：在员工列表点击【编辑】按钮，修改信息后保存。

**离职操作**：
1. 在员工列表找到要离职的员工
2. 点击【离职】按钮
3. 填写离职信息：离职日期、离职原因、是否交接完成
4. 系统自动检查未完成事项（如未归还资产、未结清薪资）
5. 点击【确认离职】按钮
6. 员工状态变为"已离职"，账号自动停用

#### 7.1.3 查询与导出

**操作步骤**：
1. 在搜索区可按以下条件筛选：姓名、工号、门店/部门、岗位、状态、入职日期范围
2. 点击【查询】刷新列表
3. 点击【导出】按钮，导出当前筛选结果为Excel

### 7.2 组织架构

**功能说明**：维护企业组织架构树（公司→部门→门店→班组），是数据权限和审批流程的基础。

**进入路径**：人事管理 → 组织架构（`/hr/organization`）

**操作步骤**：
1. 进入组织架构页面，左侧显示组织树

4. 编辑节点：选中节点 → 点击【编辑】按钮
5. 删除节点：选中节点 → 点击【删除】按钮（含下级组织或员工的不允许删除）

**注意事项**：
- 门店类型组织需关联门店档案（参见9.2）
- 组织架构变更会影响数据权限，请谨慎操作

### 7.3 岗位职级

### 7.5 考勤排班

**功能说明**：员工考勤记录、排班管理，与薪资计算联动。

### 7.6 招聘管理

### 7.9 健康证管理

**功能说明**：管理员工健康证，包括上传、查看、删除、导出、到期预警。健康证是餐饮企业的核心合规证件，必须人手一证、在有效期内。

**进入路径**：人事管理 → 健康证管理（`/hr/health-certificate`）

#### 7.9.1 上传健康证

**操作步骤**：
1. 进入健康证管理页面
2. 选择员工（或在员工列表中点击【上传健康证】按钮）
3. 在弹出的对话框中填写：
   - 健康证编号（必填）
   - 体检医院
   - 发证日期
   - 有效期至（必填，系统根据此日期计算到期预警）
4. 上传健康证照片（必传，支持 JPG/PNG，单张不超过 5MB）
5. 点击【保存】按钮

**注意事项**：
- 健康证有效期通常为1年，请提前30天安排员工体检
- 一名员工同一时间仅保留一张有效健康证，重复上传将覆盖旧的
- 上传的健康证照片请保证清晰可读，便于查验

#### 7.9.2 查看与删除

**查看**：在健康证列表点击员工行，弹出健康证详情和照片预览。
**删除**：在健康证详情中点击【删除】按钮 → 确认删除。删除后不可恢复，请谨慎操作。

#### 7.9.3 导出健康证清单

**操作步骤**：
1. 在健康证管理页面，可按门店、状态筛选
2. 点击【导出】按钮
3. 系统导出 Excel 清单，包含：员工姓名、工号、健康证编号、发证日期、有效期、状态

#### 7.9.4 到期预警

**功能说明**：系统自动监控健康证有效期，按以下规则预警：
- **30天到期**：黄色预警，工作台待办事项提醒
- **7天到期**：橙色预警，短信通知HR和店长
- **已过期**：红色预警，员工应立即停止接触食品的工作

**操作步骤**：
1. 进入健康证管理页面，顶部显示预警统计卡片
2. 点击预警数字，跳转到对应预警列表
3. 对预警员工，点击【发送体检通知】按钮，系统短信提醒员工体检
4. 员工体检完成后，重新上传新健康证（参见7.9.1）

**注意事项**：根据《食品安全法》，餐饮服务人员必须持有效健康证上岗，过期未续证将面临监管处罚。

## 第八章 食品追溯

食品追溯是系统的核心差异化模块，基于采购和仓储数据构建完整追溯链，实现"从农田到餐桌"的全链路透明化。系统为每批食材生成唯一追溯码，支持扫码查询完整流转信息。

**进入方式**：左侧菜单栏点击【食品追溯】展开子菜单。

### 8.1 临期预警

**功能说明**：监控所有库存商品的保质期，对接近过期的商品自动预警，是单人店第一需求功能。**全规模可见**。

**进入路径**：食品追溯 → 临期预警（`/traceability/expiry-warning`）

**预警等级**：
- **绿色**：保质期充足（剩余 > 1/3）
- **黄色**：保质期临近（剩余 1/3 ~ 1/5）
- **橙色**：保质期紧急（剩余 1/5 ~ 1/10）
- **红色**：已过期或当日到期

**操作步骤**：
1. 进入临期预警页面，默认显示全部临期商品
2. 可按预警等级、仓库、商品分类筛选
3. 查看商品明细：商品名称、批次号、生产日期、保质期、到期日期、剩余天数、库存数量
4. 对临期商品，可采取以下操作：
   - 点击【优先使用】按钮，标记该批次优先出库（影响出库推荐顺序）
   - 点击【发起促销】按钮，跳转到菜品定价模块，将相关菜品做促销
   - 点击【报损处理】按钮，跳转到库存报损模块（过期商品）
5. 点击【导出】按钮，导出临期商品清单

**注意事项**：
- 临期预警数据基于库存批次的生产日期和保质期自动计算
- 过期商品必须立即下架，禁止使用，否则违反《食品安全法》
- 建议每日营业开始时查看临期预警，及时处理

### 8.2 追溯查询

**功能说明**：通过追溯码、批次号、商品名称等多维度查询食材的完整追溯链。

**进入路径**：食品追溯 → 追溯查询（`/traceability/query`）

**操作步骤**：
1. 进入追溯查询页面
2. 选择查询方式：
   - **按追溯码查询**：输入追溯码（扫码或手动输入）
   - **按批次号查询**：输入采购批次号
   - **按商品查询**：选择商品 + 时间范围
3. 点击【查询】按钮
4. 系统展示追溯链（详见8.5追溯链展示），包括：
   - 供应商信息
   - 采购订单信息
   - 收货记录
   - 入库记录
   - 出库使用记录
   - 关联菜品和订单
5. 点击【导出追溯报告】按钮，生成PDF追溯报告，可用于监管检查

### 8.3 原料追溯

**功能说明**：原料级别的追溯管理，为每个原料批次生成追溯码，是追溯链的起点。

**进入路径**：食品追溯 → 原料追溯（`/traceability/material-code`）

#### 8.3.1 生成追溯码

**操作步骤**：
1. 进入原料追溯页面
2. 系统自动为每批入库的原料生成追溯码（格式如 FT20260701001）
3. 在追溯码列表可查看：
   - 追溯码
   - 原料名称、批次号
   - 供应商
   - 入库时间、数量
   - 当前库存
4. 点击【打印标签】按钮，打印追溯码标签（需连接标签打印机）
5. 标签贴在原料包装上，便于后续扫码追溯

**注意事项**：
- 追溯码一旦生成不可修改，与批次绑定
- 标签建议使用防水材质，避免储存过程中损坏

### 8.4 食品追溯

**功能说明**：菜品级别的追溯，将原料追溯链延伸到菜品和订单，实现"端到端"追溯。**仅标准规模及以上可见**。

**进入路径**：食品追溯 → 食品追溯（`/traceability/food-trace-code`）

**操作步骤**：
1. 进入食品追溯页面
2. 可按菜品名称、订单号、销售日期查询
3. 查看菜品追溯链：
   - 销售订单信息（订单号、桌号、下单时间、服务员）
   - 菜品制作记录（厨师、制作时间）
   - 使用的原料批次（来自菜品配方BOM）
   - 原料追溯链（供应商→收货→入库→出库）
4. 点击【导出追溯报告】生成完整报告

### 8.5 追溯链展示

**功能说明**：可视化展示食材的完整流转链路，从供应商到餐桌的每个节点。**仅标准规模及以上可见**。

**进入路径**：食品追溯 → 追溯链展示（`/traceability/chain`）

**追溯链节点**：
1. **供应商节点**：供应商名称、资质证照、联系方式
2. **采购节点**：采购订单号、采购日期、采购员
3. **收货节点**：收货人、收货时间、收货数量、质量检验
4. **入库节点**：入库仓库、库位、批次号
5. **存储节点**：储存条件、温度记录
6. **出库节点**：出库类型、使用部门、经办人
7. **制作节点**：菜品名称、制作厨师、制作时间
8. **销售节点**：订单号、销售时间、消费者

**操作步骤**：
1. 进入追溯链展示页面
2. 输入追溯码或批次号
3. 系统以时间轴形式展示追溯链
4. 点击每个节点查看详细信息
5. 点击【导出】生成追溯链PDF报告

### 8.6 供应商追溯

**功能说明**：从供应商维度查看其供货历史、商品批次、质量记录。**仅标准规模及以上可见**。

**进入路径**：食品追溯 → 供应商追溯（`/traceability/supplier`）

**操作步骤**：
1. 进入供应商追溯页面
2. 选择供应商
3. 查看供货历史：供货商品、批次、数量、日期
4. 查看质量记录：退货、报损、检验报告
5. 查看该供应商的所有采购合同

### 8.7 检验记录

**功能说明**：管理原料的检验检疫记录，包括供应商提供的检验报告和企业自检记录。**仅标准规模及以上可见**。

**进入路径**：食品追溯 → 检验记录（`/traceability/inspection`）

**操作步骤**：

2. 选择关联的采购批次
3. 填写检验信息：
   - 检验类型（供应商报告/入库检验/自检/第三方检验）
   - 检验项目（如农药残留、重金属、微生物等）
   - 检验结果（合格/不合格/部分合格）
   - 检验机构
   - 检验日期
4. 上传检验报告扫描件
5. 点击【保存】按钮

**注意事项**：检验报告是食品溯源的核心合规资料，监管检查必查项，请务必完整保存。

### 8.8 标签模板

**功能说明**：设计和打印追溯码标签、收货标签、保质期标签等。**仅标准规模及以上可见**。

### 8.9 召回管理

### 9.7 经营报表

## 第十章 门店管理

**进入方式**：左侧菜单栏点击【门店管理】展开子菜单。

### 10.1 待办事项

**功能说明**：门店当日待办事项集中处理，包括开闭店检查、收银对账、库存核对、人员到岗等。

**进入路径**：门店管理 → 待办事项（`/store-management/pending-tasks`）

**主要待办类型**：
- 开店检查清单（开店前必做）
- 闭店检查清单（闭店后必做）
- 收银对账
- 库存预警处理
- 健康证到期提醒
- 排班确认
- 证件到期提醒

**操作步骤**：
1. 进入待办事项页面，按时间排序显示当日待办
2. 点击待办事项可展开详情
3. 完成后点击【标记完成】按钮
4. 系统记录完成时间和完成人
5. 未完成的待办事项会标红提醒

### 10.2 日结对账

**功能说明**：每日营业结束后，核对当日营收与收银记录是否一致，生成日结报表。

**进入路径**：门店管理 → 日结对账（`/store-management/daily-settlement`）

**操作步骤**：
1. 进入日结对账页面，选择对账日期
2. 系统自动汇总当日数据：
   - 各支付方式收入（现金、微信、支付宝、银行卡、会员卡等）
   - 订单数、客单价
   - 退款金额
   - 折扣金额
3. 录入实际现金清点金额
4. 系统对比应收与实收，显示差异
5. 如有差异，填写差异原因
6. 上传当日营业照片（如收银台、监控截图）
7. 点击【提交日结】按钮
8. 日结报表自动归档，财务可在财务中心查看

**注意事项**：
- 日结对账必须每日完成，建议当日营业结束后立即处理
- 现金差异超过50元需店长说明原因
- 已日结的日期不可重复日结，如需修改需联系财务反日结

### 10.3 证件管理

**功能说明**：门店各类证件（营业执照、食品经营许可证、消防安全证等）的统一管理，到期预警。

**进入路径**：门店管理 → 证件管理（`/store-management/certificate`）

**操作步骤**：
1. 进入证件管理页面，显示门店所有证件
2. 点击【新增证件】按钮
3. 填写：证件名称、证件编号、发证机关、发证日期、有效期至
4. 上传证件照片
5. 点击【保存】按钮
6. 系统自动监控有效期，到期前30/60/90天预警

**注意事项**：证件过期将面临监管处罚，请及时续证。

### 10.4 物资需求

**功能说明**：门店向总部或采购部门提报物资需求。

**进入路径**：门店管理 → 物资需求（`/store-management/material-request`）

**操作步骤**：参考4.11物资需求提报操作。

### 10.5 门店库存

**功能说明**：门店查看本门店库存，与5.2"门店库存查看"功能相同。

**进入路径**：门店管理 → 门店库存（`/store-management/store-inventory`）

### 10.6 门店招聘

**功能说明**：门店发起的本门店招聘需求，与7.6招聘管理联动，但仅限本门店可见。

**进入路径**：门店管理 → 门店招聘（`/store-management/recruitment`）

**操作步骤**：参考7.6招聘管理，区别在于本页面仅显示和创建本门店的招聘需求。

### 10.7 桌台记录

**功能说明**：记录每日桌台使用情况，分析翻台率、平均用餐时长等。

**进入路径**：门店管理 → 桌台记录（`/store-management/table-usage`）

**主要展示**：
- 桌台编号、桌台类型（2人桌/4人桌/包间等）
- 当日使用次数、总用时
- 平均用餐时长
- 翻台率

**操作步骤**：
1. 进入桌台记录页面，选择日期
2. 查看各桌台使用情况
3. 点击桌台查看详细开台/结账记录

### 10.8 叫号记录

**功能说明**：排队叫号系统的历史记录，分析客流峰谷、等待时长。

**进入路径**：门店管理 → 叫号记录（`/store-management/queue-call-history`）

**操作步骤**：
1. 进入叫号记录页面，选择日期范围
2. 查看叫号明细：号牌、叫号时间、入座时间、等待时长
3. 查看统计：总叫号数、平均等待时长、放弃等待数

### 10.9 排班管理

**功能说明**：门店员工排班管理，创建排班、发布、调班。与7.5"考勤排班"功能联动，但本页面以门店视角管理。

**进入路径**：门店管理 → 排班管理（`/store-management/shift`）

#### 10.9.1 创建排班

**操作步骤**：
1. 进入排班管理页面，选择排班周期（如本周）
2. 点击【新增排班】按钮
3. 选择员工、班次（早班/中班/晚班/休息）
4. 设置日期范围
5. 点击【保存】按钮

#### 10.9.2 发布排班

**操作步骤**：
1. 排班表确认无误后，点击【发布排班】按钮
2. 系统通知所有员工，员工可在工作台查看本周排班

#### 10.9.3 调班操作

**操作步骤**：
1. 员工在工作台发起调班申请：选择调班日期、替换人、调班原因
2. 替换人收到调班请求，点击【同意】或【拒绝】
3. 替换人同意后，店长审批
4. 店长审批通过后，排班表自动更新

**注意事项**：调班需至少提前1天申请，避免临时调班影响门店运营。

### 14.2 签署流程

**功能说明**：发起和跟踪电子签署流程，覆盖人事合同（7.11）、采购合同（4.7/4.8）等所有需要签署的场景。

**进入路径**：签署流程通过各业务模块（人事合同、采购合同等）的【发起签署】按钮触发，签署进度在电子合同（4.8）和签署链接管理（4.9）模块跟踪。

#### 14.2.1 发起签署

**操作步骤**：
1. 在业务模块（如采购合同详情页）点击【发起电子签署】按钮
2. 选择我方签署印章（参见14.1）
3. 设置签署顺序：我方先签 / 对方先签
4. 拖拽印章到文档指定位置
5. 填写对方签署人信息（姓名、手机号、邮箱）
6. 设置签署有效期（默认7天）
7. 点击【发送签署邀请】按钮

#### 14.2.2 我方签署

**操作步骤**：
1. 在"待我方签署"列表找到待签文件

3. 系统显示文件预览
4. 拖拽印章到指定位置
5. 可选：添加签署日期、手写签名
6. 点击【确认签署】按钮
7. 系统进行实名认证（短信验证码/人脸识别）
8. 认证通过后签署完成

#### 14.2.3 跟踪签署进度

**操作步骤**：
1. 在签署链接管理（4.9）或电子合同（4.8）页面查看签署状态
2. 状态包括：待我方签署、待对方签署、已完成、已过期、已拒签
3. 点击文件查看签署日志（谁、何时、IP、设备、操作）
4. 已完成的签署可下载签署完成的PDF文件

**注意事项**：
- 电子合同与纸质合同具有同等法律效力（依据《电子签名法》）
- 签署完成的合同自动归档，不可篡改
- 签署日志永久保留，作为法律证据
- 对方可通过 H5 签署门户（`/portal/sign`）无需登录直接签署

## 第十五章 系统管理

系统管理模块是整个系统的管理基座，包括权限中心、系统配置、AI模型配置、操作审计。**系统管理仅限 owner、admin 角色可见**。

**进入方式**：左侧菜单栏点击【系统管理】展开子菜单。

### 15.1 权限中心

**功能说明**：RBAC 权限管理核心，包括用户管理、角色管理、菜单配置、数据权限。

**进入路径**：系统管理 → 权限中心（`/system/permission-center`）

#### 15.1.1 用户管理

**功能说明**：管理系统登录账号，关联员工和角色。

**操作步骤（新增用户）**：
1. 进入权限中心页面，切换到"用户管理"标签
2. 点击【新增用户】按钮
3. 填写账号信息：
   - 用户名（必填，登录用，唯一）
   - 密码（必填，8位以上含大小写字母数字特殊字符）
   - 关联员工（从员工档案选择，可选手动创建）
   - 姓名、邮箱、手机号
   - 所属门店/部门
4. 分配角色（可多选，详见15.1.2）
5. 设置账号状态：启用/禁用
6. 点击【保存】按钮

**操作步骤（编辑/禁用用户）**：
1. 在用户列表点击【编辑】按钮，修改信息后保存
2. 点击【禁用】按钮，账号立即无法登录（员工离职时使用）
3. 点击【重置密码】按钮，向用户邮箱发送重置链接

**注意事项**：
- 用户名一旦创建不可修改
- 离职员工的账号应立即禁用，避免安全风险
- 建议每季度审查一次账号清单，清理无用账号

#### 15.1.2 角色权限管理

**功能说明**：管理 RBAC 角色，配置角色可见的菜单和操作权限。

**操作步骤（新增角色）**：
1. 切换到"角色管理"标签
2. 点击【新增角色】按钮
3. 填写角色信息：
   - 角色名称（如"门店店长"）
   - 角色编码（如 store_manager）
   - 角色描述
   - 数据范围（全部/本公司/本部门/本门店/仅本人）
4. 配置菜单权限：勾选该角色可见的菜单
5. 配置操作权限：在每个菜单下勾选允许的操作（查看/新增/编辑/删除/审批等）
6. 点击【保存】按钮

**预设角色**：系统预置6种主要角色，开箱即用：
- 老板/超级管理员（owner）：全部权限
- 系统管理员（admin）：全部权限（系统内置）
- 运营总监（ops_director）：运营、门店、订单、产品权限
- 财务总监（finance_director）：财务、资产权限
- HR总监（hr_director）：人事权限
- 店长（store_manager）：本门店相关权限

**注意事项**：
- 系统预置角色不可删除，可基于预置角色创建自定义角色
- 角色权限变更后，关联用户下次登录生效
- 数据范围控制用户能查看的数据范围，谨慎配置

#### 15.1.3 菜单配置

**功能说明**：配置系统菜单结构，菜单按角色显示。系统菜单注册后锁定，不可动态修改。

**操作步骤**：
1. 切换到"菜单配置"标签
2. 显示菜单树结构
3. 可调整菜单排序
4. 可配置菜单可见角色
5. 系统菜单为锁定状态，不可删除

#### 15.1.4 权限模板

**功能说明**：基于企业规模预设的权限模板（mini单人店、standard标准店、chain-standard标准连锁、chain-enterprise大型连锁），一键应用。

**操作步骤**：
1. 切换到"权限模板"标签
2. 选择适合企业规模的模板
3. 点击【应用模板】按钮
4. 系统自动配置各角色的权限
5. 可在角色管理中微调

### 15.2 系统配置

**功能说明**：系统级参数配置，包括基础信息、业务参数、邮件短信、文件存储等。

**进入路径**：系统管理 → 系统配置（`/system/permission`）

**主要配置项**：
- 企业信息：企业名称、Logo、地址、联系方式
- 业务参数：默认分页大小、日期格式、货币单位
- 邮件配置：SMTP服务器、发件邮箱
- 短信配置：短信网关、模板
- 文件存储：上传路径、大小限制
- 主题配置：主题色、Logo

**操作步骤**：
1. 进入系统配置页面
2. 切换到对应配置标签
3. 修改配置项
4. 点击【保存设置】按钮
5. 部分配置（如邮件、短信）需点击【测试】按钮验证

### 15.3 AI模型配置

**功能说明**：配置系统集成的AI模型，用于智能分析、智能问答等AI驱动功能。

**进入路径**：系统管理 → AI模型配置（`/system/ai-model-config`）

**主要配置**：
- 模型提供商（如OpenAI、智谱、文心一言）
- API密钥
- 模型选择
- 调用频率限制
- 使用场景配置（智能分析、智能问答、画像等）

**操作步骤**：
1. 进入AI模型配置页面
2. 选择模型提供商
3. 填写API密钥
4. 选择具体模型
5. 点击【测试连接】按钮验证
6. 配置使用场景
7. 点击【保存】按钮

**注意事项**：API密钥高度敏感，请妥善保管，避免泄露。

### 15.4 操作审计

**功能说明**：记录所有用户的操作日志和登录日志，用于安全审计和问题追溯。

**进入路径**：系统管理 → 操作审计（`/system/operation-audit`）

#### 15.4.1 操作日志

**功能说明**：记录用户在系统中的所有操作（增删改查），是不可篡改的审计日志。

**操作步骤**：
1. 进入操作审计页面，切换到"操作日志"标签
2. 可按以下条件筛选：
   - 操作人
   - 操作类型（新增/修改/删除/查询/审批）
   - 模块
   - 时间范围
   - IP地址
3. 查看操作明细：操作时间、操作人、操作内容、原值、新值、IP、设备
4. 点击【导出】按钮导出日志

**注意事项**：
- 操作日志永久保留，不可删除
- 日志记录所有字段变更，便于追溯责任

#### 15.4.2 登录日志

**功能说明**：记录用户登录和登出记录，监控异常登录。

**操作步骤**：
1. 切换到"登录日志"标签
2. 可按用户、时间范围、登录结果（成功/失败）筛选
3. 查看登录明细：登录时间、用户名、IP、设备、浏览器、登录结果
4. 异常登录会高亮显示（如异地登录、深夜登录、多次失败）

**注意事项**：发现异常登录应立即联系该用户核实，必要时禁用账号。

## 附录A 常见问题FAQ

### A.1 登录与账号

**Q1：忘记密码怎么办？**
A：联系系统管理员，在【权限中心 → 用户管理】点击【重置密码】按钮，系统会向用户邮箱发送密码重置链接。如未配置邮箱，管理员可临时重置为默认密码，用户首次登录后强制修改。

**Q2：登录提示"账号已禁用"怎么办？**
A：账号被管理员禁用，常见于员工离职。如属误操作或需重新启用，请联系系统管理员在【权限中心 → 用户管理】启用账号。

**Q3：登录后页面空白或加载缓慢？**
A：① 检查网络连接；② 清理浏览器缓存（Ctrl+Shift+Delete）；③ 尝试切换浏览器（推荐 Chrome 最新版）；④ 联系系统管理员检查后端服务是否正常。

**Q4：默认管理员密码忘记，无法登录？**
A：默认账号 admin / Admin@123 仅用于初始化。如已修改且忘记密码，需联系技术支持通过数据库层面重置，无法在前端找回。

### A.2 数据操作

**Q5：误删了菜品/员工/订单等数据，能恢复吗？**
A：系统采用逻辑删除，删除后数据不在列表显示但数据库保留。误删数据可在 48 小时内联系系统管理员在数据库层面恢复。超过 48 小时无法恢复，请谨慎删除。

**Q6：导入Excel时报错"格式不正确"？**
A：① 必须使用系统提供的模板，切勿自行创建；② 检查Excel中是否有合并单元格、空行；③ 必填字段不能为空；④ 日期格式应为 YYYY-MM-DD；⑤ 数字字段不能包含非数字字符。可先导入1-2行测试数据验证。

**Q7：导出的报表打开是乱码？**
A：Excel打开CSV乱码通常是编码问题，建议：① 使用 WPS 或 Excel 2016+ 打开；② 用记事本打开CSV，另存为ANSI编码后再用Excel打开；③ 选择导出为 .xlsx 格式而非 .csv。

**Q8：搜索时输入中文查不到结果？**
A：① 检查是否有多余空格，尝试去掉空格重试；② 部分字段仅支持精确查询，不支持模糊匹配，请确认输入完整名称；③ 联想功能可能因数据量大而延迟，等待几秒后重试。

### A.3 业务操作

**Q9：采购订单创建后无法修改明细？**
A：订单状态为"已下单"后不可修改明细，需先【取消订单】再重新创建，或创建新的补货订单。

**Q10：库存盘点提示"盘点期间不能出入库"？**
A：盘点会锁定被盘点范围的库存。请等待盘点完成，或在盘点详情页点击【中止盘点】解除锁定（需主管权限）。

**Q11：健康证到期预警未收到通知？**
A：① 检查员工健康证有效期是否已填写；② 检查短信配置是否正确（系统管理 → 系统配置）；③ 检查员工手机号是否正确；④ 联系管理员检查短信余额。

**Q12：电子合同对方收不到签署邀请？**
A：① 确认对方手机号/邮箱正确；② 让对方检查垃圾邮件/短信拦截；③ 在【签署链接管理】点击【重发】按钮重新发送；④ 联系对方确认手机短信拦截设置。

**Q13：财务凭证无法过账？**
A：检查：① 凭证借贷是否平衡；② 当前会计期间是否开放（未结账）；③ 凭证是否已审核。已结账期间不能录入凭证，需先反结账。

**Q14：菜品成本分析显示为0？**
A：菜品未配置配方（BOM）。在【菜品管理】编辑菜品，配置配方（关联原料及用量）后，系统自动核算成本。

### A.4 系统配置

**Q15：菜单栏缺少某个功能？**
A：① 当前账号角色可能无权限，联系管理员分配权限；② 企业规模级别未开启该功能（如财务中心的预算管理仅标准连锁及以上可见）；③ 浏览器缓存问题，按 Ctrl+F5 强制刷新。

**Q16：主题切换不生效？**
A：清理浏览器缓存，按 Ctrl+F5 强制刷新页面。如仍不生效，检查浏览器是否禁用了 localStorage。

**Q17：上传文件提示"文件过大"？**
A：系统限制单文件一般不超过 10MB，图片不超过 5MB。请压缩后再上传，或联系管理员调整系统配置中的文件大小限制。

**Q18：AI智能功能无响应？**
A：① 检查【系统管理 → AI模型配置】是否配置了AI模型；② 检查API密钥是否有效；③ 检查API调用额度；④ 网络是否能访问AI服务。

### A.5 浏览器与显示

**Q19：表格在屏幕上显示不全？**
A：① 调整浏览器缩放比例（Ctrl+- 缩小）；② 点击表格列头调整列宽；③ 部分列可拖拽隐藏，在表格设置中开启；④ 使用更大分辨率屏幕。

**Q20：Dialog 弹窗内的下拉框位置漂移？**
A：本系统已通过全局 Popper 插件修复此问题。如仍出现，请按 Ctrl+F5 强制刷新；如问题持续，请截图反馈给技术支持。

**Q21：报表打印时格式错乱？**
A：建议使用【导出PDF】功能而非浏览器打印；如必须浏览器打印，在打印设置中调整边距为"无"，勾选"背景图形"。
