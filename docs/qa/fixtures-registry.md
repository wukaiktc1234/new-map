## 1c. 409「已被其它终端处理」分支为何不由 gate 覆盖（2026-10-29 取舍记录）

```text
要触发该分支，订单必须 payment_status=2（已支付）。但：
  ① payment_status=2 且没有 SALE 流水 → **A1 判红**（已实测：A1 rows=1 分母=54）
  ② 若补一条 SALE 流水让它满足 A1 → **改变真实账户余额**（违反 gate 零流水铁律）
两条约束不可同时满足。

结论（有意识的取舍，不是遗漏）：
  gate 只覆盖「409 订单不存在」（同码不同因，message 明确不同）+ 422；
  「409 已被处理」由集成测试 T4 / S4'' 覆盖（那里允许有真实流水）。
```
