# AI辅助开发标准流程指南

## 一、核心原则

### 1. AI是助手，不是替代
- AI擅长：生成代码、解释概念、提供方案
- AI不擅长：理解业务上下文、全局架构决策、端到端测试

### 2. 渐进式开发
- 每个功能模块必须完整：数据库 → 后端API → 前端页面 → 测试验证
- 不要跳跃开发，不要"先写前端再补后端"

### 3. 验证驱动
- 每完成一个模块，立即测试验证
- 不要等到所有代码写完再测试

## 二、标准开发流程

### 阶段1：需求分析与架构设计（人工主导）

```
输入：业务需求文档
输出：架构设计文档、数据库设计、API设计

关键活动：
1. 明确业务流程和数据流
2. 设计数据库表结构
3. 定义API接口规范
4. 确定技术栈和框架
```

**AI辅助方式**：
```
提示词示例：
"我需要设计一个采购管理系统，包含采购申请、采购订单、入库管理等功能。
请帮我设计：
1. 数据库表结构（MySQL）
2. API接口列表
3. 前端页面结构
4. 数据流转关系"
```

### 阶段2：数据库开发（AI辅助）

```
步骤：
1. 创建数据库表
2. 添加测试数据
3. 验证表结构和约束

验证标准：
□ 所有表创建成功
□ 外键关系正确
□ 测试数据可插入
□ 索引创建完成
```

**验证命令**：
```sql
-- 验证表结构
SHOW CREATE TABLE purchase_order;

-- 验证数据
SELECT COUNT(*) FROM purchase_order;

-- 验证外键
SELECT * FROM information_schema.TABLE_CONSTRAINTS 
WHERE CONSTRAINT_TYPE = 'FOREIGN KEY';
```

### 阶段3：后端API开发（AI辅助）

```
步骤：
1. 创建实体类（Entity）
2. 创建数据访问层（Mapper）
3. 创建业务逻辑层（Service）
4. 创建控制器层（Controller）
5. 编写单元测试
6. 启动服务验证

验证标准：
□ 服务启动成功
□ API可访问
□ 返回数据格式正确
□ 错误处理完善
```

**验证命令**：
```bash
# 启动后端
mvn spring-boot:run

# 测试API
curl http://localhost:8081/api/v1/purchase-orders

# 检查日志
tail -f logs/application.log
```

### 阶段4：前端开发（AI辅助）

```
步骤：
1. 创建API封装
2. 创建类型定义
3. 创建页面组件
4. 实现数据交互
5. 添加加载状态和错误处理

验证标准：
□ 页面可访问
□ 数据正确显示
□ 按钮功能正常
□ 表单验证有效
□ 错误提示友好
```

**验证清单**：
```markdown
□ 页面加载：数据是否正确显示？
□ 新增功能：表单提交后数据是否创建？
□ 编辑功能：数据是否正确更新？
□ 删除功能：数据是否正确删除？
□ 搜索功能：筛选是否正确？
□ 分页功能：翻页是否正常？
□ 导出功能：文件是否正确生成？
```

### 阶段5：集成测试（人工+AI）

```
步骤：
1. 端到端业务流程测试
2. 边界条件测试
3. 异常情况测试
4. 性能测试

验证标准：
□ 核心业务流程通过
□ 边界条件处理正确
□ 异常情况有友好提示
□ 响应时间符合要求
```

## 五、常见问题与解决方案

### 问题1：按钮点击无反应

**原因**：
- 事件未绑定
- 方法未实现
- API未调用

**解决方案**：
```vue
<!-- 检查事件绑定 -->
<el-button @click="handleClick">点击</el-button>

<!-- 检查方法实现 -->
<script setup>
const handleClick = () => {
  console.log('按钮被点击'); // 先验证事件
  // 然后添加业务逻辑
};
</script>
```

### 问题2：数据不显示

**原因**：
- API未调用
- 数据未加载
- 响应处理错误

**解决方案**：
```typescript
// 1. 确保onMounted中调用API
onMounted(() => {
  loadData();
});

// 2. 检查响应处理
const loadData = async () => {
  try {
    const response = await api.getData();
    // 响应拦截器已提取data，直接使用
    tableData.value = response?.records || [];
  } catch (error) {
    ElMessage.error('加载失败');
  }
};
```

### 问题3：数据库操作失败

**原因**：
- 表不存在
- 字段不匹配
- 外键约束

**解决方案**：
```sql
-- 1. 检查表是否存在
SHOW TABLES LIKE 'table_name';

-- 2. 检查表结构
DESC table_name;

-- 3. 检查字段
SHOW COLUMNS FROM table_name;

-- 4. 检查数据
SELECT * FROM table_name LIMIT 10;
```
