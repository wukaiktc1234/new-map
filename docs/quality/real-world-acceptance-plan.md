# 真实业务初始化验收计划

> 目标：以生产环境标准，从空数据库开始搭建系统，使用真实组织架构与业务数据，跑通采购-仓储-库存-财务完整链路。
> 更新日期：2026-07-24

---

## 一、总体策略

1. **不保留任何模拟数据**：所有供应商、物料、员工、部门必须真实录入。
2. **逐模块验收**：每个基础模块先验收，再进入下游业务。
3. **多角色切换验证**：用不同账号登录，验证权限隔离和数据可见范围。
4. **异常场景必测**：部分收货、跨仓/跨店分发、审批驳回等。

## 四、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 数据库 Schema 与实体不一致 | 高 | 每完成一个模块先跑基础 CRUD，发现即修 |
| 权限体系不完善 | 高 | 先明确最小权限集，逐步细化 |
| 门店/仓库间调拨流程缺失 | 中 | 两种配送模式共存：直发拆单 + 总仓调拨 |
| 采购订单从申请生成逻辑未实现 | 中 | 如未实现，先支持手动创建并记录 gap |
