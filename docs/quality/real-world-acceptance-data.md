## 七、审批与权限规则

### 7.1 采购申请入口

- 统一入口：工作台页面提供「采购申请」快捷入口（已完成前端改造）
- 权限控制：仅当用户拥有 `purchase:request:view` 权限时才在工作台显示该入口
- 菜单路径：保留「采购管理 → 采购申请」作为统一页面
- 不允许每个部门单独开发入口
- 涉及改造文件：
  - `frontend/src/views/dashboard/role-profiles.ts`：为 6 个角色组配置添加带 `requiredPermission` 的采购申请快捷入口
  - `frontend/src/views/dashboard/index.vue`：根据 `permissionStore.hasPermission` 过滤快捷入口
  - `frontend/src/stores/permission.ts`：新增 `purchase_manager`、`department_manager`、`warehouse_manager` 角色枚举

### 7.2 数据可见范围

| 角色 | 可见范围 |
|------|----------|
| 采购部（含经理/员工） | 所有部门的采购申请 |
| 部门经理/门店店长 | 只能看到本部门/本门店的申请 |
| 普通员工 | 只能看到自己提交的申请，以及与自己相关的任务（待办、收货任务） |

### 7.3 审批流程

```
申请人提交
  → 第一级：部门负责人审批（门店店长/部门经理/仓储部经理）
  → 第二级：采购部经理审批
  → 通过：允许采购员从申请生成采购订单，也支持手动创建采购订单
```

### 7.4 配送模式（两种共存）

| 模式 | 适用场景 | 系统实现 |
|------|----------|----------|
| 供应商直发多门店/仓库 | 配送模式，供应商直接送到多个地点 | 采购订单/到货单拆分为多个收货地点 |
| 先入总仓再调拨 | 统采统配，中央仓集中采购后再分发 | 采购到货入仓库A，再通过调拨单调往仓库B/门店 |

### 7.5 收货规则

| 到货地点 | 收货人 |
|----------|--------|
| 发门店 | 门店店长 |
| 发仓库 | 仓库主管/仓储部经理 |
