## 一、项目定位

### 1.1 是什么

**连锁餐饮门店员工自助门户**——面向单店或2-5家小型连锁餐饮企业的员工移动端应用。

### 1.2 核心原则：管理端决策、员工端继承

```
管理端（frontend/:3000）── 决策者
  │  权限模板 / 组织架构 / 审批链路 / 数据范围
  │
  ▼ 继承/适配
员工端（employee-frontend/:3004）── 继承者
  │  消费 JWT 身份 / DataScope 数据范围 / 域权限矩阵
  │  ★ 员工端不设计权限模型，只消费管理端的配置结果
```

### 1.3 目标用户画像

| 角色 | 使用场景 | 核心诉求 |
|------|---------|---------|
| 门店员工 | 每日查看排班/打卡/请假/审批 | 快速找到所需功能，操作步骤少 |
| 门店经理 | 审批下属申请/查看团队排班 | 高效处理待办，信息一目了然 |
| 总部人员 | 查看工资条/培训记录/数据报表 | 信息展示清晰，隐私安全 |

### 2.3 功能池动态聚合架构

**核心设计**："办公"页与"首页快捷入口"是功能池互通的——一个是首页精选子集，另一个是完整分类菜单。两者共享同一数据源 `ALL_MODULES`，通过 `getOfficeGroups()` 动态聚合。

**关键文件**: [stores/permission.ts](src/stores/permission.ts)

```typescript
// 分组元数据注册表（替代硬编码 moduleIds 列表）
```

## 四、原生能力封装（Capacitor 双模式）

### 4.1 文件位置

[composables/useNativeDevice.ts](src/composables/useNativeDevice.ts) — 约 430 行

### 4.2 设计理念

统一封装 Capacitor 原生插件与 Web API，实现双模式运行：
- **APP 环境**：使用 Capacitor 原生插件（高精度定位、实时网络状态、触觉反馈、状态栏控制）
- **浏览器环境**：降级为 Web API（HTML5 Geolocation、Network Info API、Vibration API）

| 网络监听 | `initNetworkListener()` / `removeNetworkListener()` | @capacitor/network | online/offline 事件 | ✅ |

### 7.1 四种约束模式

| `none` | ❌ | ❌ | 测试/远程模式 |

### 7.2 前端约束链

```
打卡按钮点击
  → 检查定位权限 → 失败则拒绝
  → 检查网络状态（WiFi BSSID）→ 失败则拒绝（both/wifi_only 模式）
  → 获取当前位置（GPS坐标 + accuracy）
  → 采集设备信息（UA/platform/screen/timezone）
  → 提交 PunchResult{success, location, constraintReason, ...}
```

## 九、代码规范速查（员工端特有）

### 9.1 必须遵守

- **API 请求**：必须使用 `src/api/request.ts` 导出的 `request` 实例，禁止直接使用 axios
- **参数传递**：GET 直接传 params 对象，禁止 `{ params }` 嵌套
- **响应提取**：响应拦截器已自动提取 `.data.data`，前端不再访问 `.data` 属性
- **Token 处理**：由拦截器自动添加，禁止手动添加 Authorization header
- **状态显示**：禁止使用 el-tag 显示状态字段，必须使用 `<StatusTag>` 组件
- **操作列按钮**：必须使用 `el-button link type="primary/danger"` 纯文字按钮
- **颜色值**：禁止硬编码，必须使用 `--fts-*` CSS 变量
- **CSS 覆盖**：Element Plus 样式覆盖集中在 `_element-overrides.scss`
- **!important**：禁止使用
- **console.log/info/debug**：禁止提交到仓库（console.error/warn 允许）
- **any 类型**：限制使用，特殊情况需注释说明原因

### 9.2 组件使用优先级

项目在 Element Plus 之上封装了 core 层自定义组件，业务开发**必须优先使用**：

| 组件 | 替代的 Element Plus 组件 |
|------|------------------------|
| `StatusTag` | `el-tag`（显示状态时） |
| `DataTable` | `el-table` |
| `PageHeader` | 自定义标题区 |
| `StatCard` | 自定义指标卡 |
| `StandardPage` | 自定义页面容器 |
| `Skeleton` | `el-skeleton` |
