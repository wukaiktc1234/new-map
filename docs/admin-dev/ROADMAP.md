## 五、设计原则备忘

1. **单一真相源**: 菜单/路由/权限三者在 permission Store 统一管理
2. **注册器模式**: 各模块自行注册，不集中维护大数组
3. **默认开放**: visibleRoles 空=所有人可见（仅敏感模块限制）
4. **超管无限制**: OWNER/ADMIN 角色忽略所有 visibleRules
5. **覆盖优先级**: 用户覆盖 > 角色覆盖 > 模板覆盖 > 默认配置
6. **持久化**: 用户级覆盖存 localStorage，刷新不丢失
