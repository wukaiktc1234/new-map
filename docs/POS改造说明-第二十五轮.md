# 第二十五轮：权限前移 + 明细入口合并 + 抬头信息

> 三条体验问题，全部落在同一屏的「少一层、前一步」上。

## 1. 权限校验前移到登录（不再等到交班才报 403）

**问题**：收银员干完一班才在交班弹窗看到「无权限访问收银数据」，属于事后告知。

**改法**：登录成功后立刻做一次预检 `GET /v1/pos/shift/stats`：
- 返回 **403** → 判定该账号无收银数据权限：清掉 token/user/terminal、清空内存能力，**留在登录页**并提示「该账号无收银数据权限，请联系店长授权后再登录」；
- 返回 404 / 5xx / 网络异常 → **不拦**（接口未上线或临时故障不能把人挡在门外）。

交班弹窗里的红色横幅仍保留，作为“会话中途权限被回收”的兜底。

## 2. 明细入口并进收款统计表

- 删除底部「调阅本班次所有订单明细（共 N 笔）」整行；
- 统计表标题行右侧新增「明细 ›」，点击**清空支付方式筛选**后打开同一个抽屉；
- 行内「详情」仍在，按单个支付方式过滤——两个入口同一份数据，不再出现“两个入口两种口径”。

## 3. 班次/账号信息上移到抬头

- 删除底部「班次进行中：测试员A · 开始于 23:32」；
- 抬头右侧改为：**收银员姓名** · `班次进行中 #1` · `开始于 09:00` · 日期时间；
- 姓名兜底链：`shiftInfo.employeeName → shiftInfo.employeeId → 登录写入的 pos-user`，信息缺失也不留空白。
