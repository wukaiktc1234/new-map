# 招聘流程表

> 生成日期：2026-07-04
> 适用版本：食品溯源系统 V1.0
> 文档说明：本表覆盖两种招聘流程（I-门店发起 / II-人事发起）的全部环节，可用于电子档归档或打印为纸质存档。
> 流程设计说明：
> - 流程I由门店一线发起（店长/门店经理提交），由 HR 审批（避免店长自审自批的无效动作）
> - 流程II由人事主动发起（适用职能/管理岗位），由 HR总监 审批
> - 门店ID（storeId）由后端 SecurityUtils.getCurrentUserStoreId() 自动注入，前端无需传入

***

## 流程 I：门店发起招聘（适用于门店一线岗位）

| 序号 | 环节名称 | 负责角色 | 操作说明 | 输入数据 | 输出数据 | 状态流转 | 系统端点 |
|------|---------|---------|---------|---------|---------|---------|---------|
| I-1 | 门店发起招聘需求 | 店长 / 门店经理 | 门店发现缺人，提交招聘需求（岗位ID、需求人数、岗位要求；门店ID由后端SecurityUtils自动注入） | 岗位ID、需求人数、岗位要求 | 招聘需求单（status=draft，storeId由后端自动注入） | → pending | `POST /v1/recruitment-requirements` |
| I-2 | HR审批 | HR总监 / HR专员 | HR审批门店提交的招聘需求，通过或驳回 | 申请单ID、审批结果、审批意见 | 审批记录、更新后的需求单（status=approved/rejected） | pending → approved / rejected | `PUT /v1/recruitment-requirements/{id}/approve` |
| I-3 | 人事发布招聘 | HR总监 / HR专员 | HR审批通过后，人事发布招聘职位 | 招聘需求ID、职位描述、薪资范围 | 招聘职位（status=open） | approved → published | `POST /v1/recruitment-positions` |
| I-4 | 候选人投递简历 | 候选人 | 候选人看到招聘信息后投递简历 | 候选人姓名、联系方式、简历附件、应聘职位ID | 简历记录（status=pending） | published → applied | `POST /v1/resumes` |
| I-5 | 门店初面 | 门店经理 / 门店面试官 | 门店对候选人进行初次面试，记录面评 | 候选人ID、面试官ID、面试时间、面评内容、评分 | 面试记录（storeEvaluation、storeEvaluationScore、result=pass/fail） | applied → store_interviewed | `POST /v1/interviews` + `PUT /v1/interviews/{id}/store-evaluation` |
| I-6 | 人事面谈 | HR总监 / HR专员 | 门店初面通过后，人事进行深度面谈（含学历核验、背调） | 候选人ID、人事面试官ID、面评内容、评分、学历核验结果、背调结果 | 面试记录（hrEvaluation、hrEvaluationScore、educationVerification、backgroundCheckResult、hrInterviewStatus=pass/fail） | store_interviewed → hr_interviewed | `POST /v1/interviews/{id}/hr-interview` + `PUT /v1/interviews/{id}/hr-evaluation` |
| I-7 | 录用入职 | HR专员 / 行政 | 人事面谈通过后，办理入职手续，创建员工档案 | 候选人ID、入职日期、部门、岗位、薪资 | 员工档案（Employee）、入职记录 | hr_interviewed → onboarded | `POST /v1/onboarding` |

## 流程 II：人事发起招聘（适用于职能/管理岗位）

| 序号 | 环节名称 | 负责角色 | 操作说明 | 输入数据 | 输出数据 | 状态流转 | 系统端点 |
|------|---------|---------|---------|---------|---------|---------|---------|
| II-1 | 人事发起招聘需求 | HR总监 / HR专员 | 人事根据公司规划提交招聘需求（部门ID、岗位ID、需求人数） | 部门ID、岗位ID、需求人数、岗位要求 | 招聘需求单（status=draft） | → pending | `POST /v1/recruitment-requirements` |
| II-2 | 人事总监审批 | HR总监 | 人事总监审批招聘需求，通过或驳回 | 申请单ID、审批结果、审批意见 | 审批记录、更新后的需求单（status=approved/rejected） | pending → approved / rejected | `PUT /v1/recruitment-requirements/{id}/approve` |
| II-3 | 人事发布招聘 | HR专员 | 人事总监审批通过后，发布招聘职位 | 招聘需求ID、职位描述、薪资范围 | 招聘职位（status=open） | approved → published | `POST /v1/recruitment-positions` |
| II-4 | 候选人投递简历 | 候选人 | 候选人看到招聘信息后投递简历 | 候选人姓名、联系方式、简历附件、应聘职位ID | 简历记录（status=pending） | published → applied | `POST /v1/resumes` |
| II-5 | 人事面谈 | HR总监 / HR专员 | 候选人投递后，人事直接进行面谈（含学历核验、背调） | 候选人ID、人事面试官ID、面评内容、评分、学历核验结果、背调结果 | 面试记录（hrEvaluation、hrEvaluationScore、educationVerification、backgroundCheckResult、hrInterviewStatus=pass/fail） | applied → hr_interviewed | `POST /v1/interviews/{id}/hr-interview` + `PUT /v1/interviews/{id}/hr-evaluation` |
| II-6 | 录用入职 | HR专员 / 行政 | 人事面谈通过后，办理入职手续，创建员工档案 | 候选人ID、入职日期、部门、岗位、薪资 | 员工档案（Employee）、入职记录 | hr_interviewed → onboarded | `POST /v1/onboarding` |

## 人事面谈环节详细字段说明

> 本环节为流程I的I-6和流程II的II-5共用，是本次补充的核心环节。

| 字段名 | 数据库字段 | 类型 | 说明 | 取值范围 |
|-------|-----------|------|------|---------|
| 人事面试官ID | hr_interviewer_id | VARCHAR(32) | 人事面试官的员工ID | 关联 employees.employee_id |
| 人事面试官姓名 | hr_interviewer_name | VARCHAR(100) | 人事面试官姓名 | 冗余字段，便于展示 |
| 人事面评内容 | hr_evaluation | TEXT | 人事面谈评价记录 | 自由文本 |
| 人事面评时间 | hr_evaluation_time | TIMESTAMP | 人事面评提交时间 | 系统自动填充 |
| 人事面评评分 | hr_evaluation_score | INTEGER | 人事面评评分 | 1-100 |
| 学历核验结果 | education_verification | VARCHAR(20) | 学历真实性的核验结果 | pending / pass / fail |
| 学历核验备注 | education_verification_remark | TEXT | 学历核验的详细说明 | 自由文本 |
| 背调结果 | background_check_result | VARCHAR(20) | 背景调查结果 | pending / pass / fail |
| 背调备注 | background_check_remark | TEXT | 背调的详细说明 | 自由文本 |
| 人事面谈状态 | hr_interview_status | VARCHAR(20) | 人事面谈的整体状态 | pending / scheduled / completed / pass / fail |

***

## 招聘流程状态机总览

```
流程I（门店发起）：
  draft → pending → approved → published → applied → store_interviewed → hr_interviewed → onboarded
                 ↘ rejected                                                        ↘ fail（淘汰）

流程II（人事发起）：
  draft → pending → approved → published → applied → hr_interviewed → onboarded
                 ↘ rejected                                          ↘ fail（淘汰）
```

## 系统端点清单

| 端点 | 方法 | 用途 | 所属环节 |
|------|------|------|---------|
| `/v1/recruitment-requirements` | POST | 创建招聘需求 | I-1 / II-1 |
| `/v1/recruitment-requirements/{id}/approve` | PUT | 审批招聘需求 | I-2 / II-2 |
| `/v1/recruitment-positions` | POST | 发布招聘职位 | I-3 / II-3 |
| `/v1/resumes` | POST | 候选人投递简历 | I-4 / II-4 |
| `/v1/interviews` | POST | 创建面试记录 | I-5 / II-5 |
| `/v1/interviews/{id}/store-evaluation` | PUT | 提交门店面评 | I-5 |
| `/v1/interviews/{id}/hr-interview` | POST | 创建人事面谈 | I-6 / II-5 |
| `/v1/interviews/{id}/hr-evaluation` | PUT | 提交人事面评 | I-6 / II-5 |
| `/v1/onboarding` | POST | 办理入职 | I-7 / II-6 |
