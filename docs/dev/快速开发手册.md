# 管理端快速开发手册

> 本文档是写给日常开发者的"使用手册"，告诉你用什么组件、怎么写代码。
> 规范约束请参照 `docs/spec/` 目录中的17个规范文档。

---

## 一、页面搭建三步走

### 第1步：选模板

所有页面只有 3 种模板，复制粘贴即可：

| 我需要做... | 用这个模板 |
|------------|----------|
| 数据列表页（增删改查） | [模板A：多标签列表页](#模板a多标签列表页) |
| 简单的CRUD + 搜索 | [模板B：单表格列表页](#模板b单表格列表页) |
| 图表 / 看板 / Dashboard | [模板C：仪表盘页](#模板c仪表盘页) |

### 第2步：用工具类布局

不写 scoped 样式，用全局工具类布局：

```html
<!-- 水平居中 -->
<div class="fts-flex fts-flex-center fts-gap-3">...</div>

<!-- 左右分栏 -->
<div class="fts-flex fts-flex-between">
  <div>左侧</div>
  <div>右侧</div>
</div>

<!-- 等间距网格 -->
<div class="fts-flex fts-gap-4 fts-flex-wrap">...</div>
```

详见 [工具类速查表](#五工具类速查表)。

### 第3步：检查清单

提交前确认：
```
[ ] 使用了 StandardPage 包裹（不是 FinanceBaseLayout / 裸div）
[ ] 表格加了 v-loading="loading"
[ ] loading 在 finally 中关闭
[ ] 筛选区使用了 fts-filter-section 结构
[ ] 没有硬编码色值（全部用 --fts-* 变量）
[ ] 没有写 scoped 样式来覆盖全局（用工具类代替）
```

## 模板A：多标签列表页

适用：有多个Tab的数据管理页面。

```vue
<template>
  <StandardPage title="页面名称" subtitle="页面说明">
    <template #stats>
      <div class="sp-stats-row">
        <StatCard icon="Calendar" label="总订单" :value="String(total)" color-type="primary" />
        <StatCard icon="TrendCharts" label="今日新增" :value="String(today)" color-type="success" />
      </div>
    </template>

    <template #toolbar>
      <div class="sp-toolbar__left">
        <el-button type="primary" :icon="Plus" @click="handleAdd">新增</el-button>
      </div>
      <div class="sp-toolbar__right">
        <el-button :icon="Download" @click="handleExport">导出</el-button>
      </div>
    </template>

    <template #tabs>
      <el-tabs v-model="activeTab">
        <el-tab-pane label="全部" name="all" />
        <el-tab-pane label="待处理" name="pending" />
      </el-tabs>
    </template>

    <template #default>
      <div v-show="activeTab === 'all'" class="sp-tab-panel">
        <el-table :data="list" stripe v-loading="loading" class="fts-table" table-layout="fixed">
          <el-table-column prop="name" label="名称" min-width="150" />
          <el-table-column label="操作" width="160" fixed="right">
            <template #default="{ row }">
              <div class="table-action-group">
                <el-button type="primary" link size="small" @click="handleEdit(row)">编辑</el-button>
                <el-button type="danger" link size="small" @click="handleDelete(row)">删除</el-button>
              </div>
            </template>
          </el-table-column>
        </el-table>
      </div>
      <div v-show="activeTab === 'pending'" class="sp-tab-panel">
        <!-- 第二个Tab的表格，结构同上 -->
      </div>
    </template>

    <template #footer>
      <el-pagination
        v-model:current-page="page.current"
        v-model:page-size="page.size"
        :total="page.total"
        layout="total, sizes, prev, pager, next, jumper"
        @size-change="loadData"
        @current-change="loadData"
      />
    </template>

    <EditDialog v-model="dialogVisible" :data="currentRow" @success="loadData" />
  </StandardPage>
</template>

<script setup lang="ts">
defineOptions({ name: 'YourPageName' })

import { ref, onMounted } from 'vue'
import { ElMessage, ElMessageBox } from 'element-plus'
import { Plus, Download } from '@element-plus/icons-vue'
import StandardPage from '@/components/core/StandardPage.vue'
import StatCard from '@/components/core/StatCard.vue'
import EditDialog from './components/EditDialog.vue'
import { yourApi } from '@/api/your-module'

const activeTab = ref('all')
const loading = ref(false)
const list = ref<any[]>([])
const page = reactive({ current: 1, size: 10, total: 0 })
const dialogVisible = ref(false)
const currentRow = ref<any>(null)

async function loadData() {
  loading.value = true
  try {
    const res = await yourApi.getList({ page: page.current, size: page.size })
    list.value = res?.records || []
    page.total = res?.total || 0
  } finally {
    loading.value = false
  }
}

function handleEdit(row: any) { currentRow.value = row; dialogVisible.value = true }
function handleAdd() { currentRow.value = null; dialogVisible.value = true }

async function handleDelete(row: any) {
  await ElMessageBox.confirm('确定删除吗？', '提示', { type: 'warning' })
  await yourApi.delete(row.id)
  ElMessage.success('删除成功')
  loadData()
}

onMounted(() => loadData())
</script>
```

## 二、核心组件用法

### StandardPage

```typescript
// 所有页面必须用它包裹
<StandardPage
  title="页面标题"        // 必填
  subtitle="副标题"       // 可选
  :loading="loading"      // 可选：显示全局loading遮罩
>
  <!-- 插槽：stats / filter / toolbar / tabs / default / footer / headerActions -->
</StandardPage>
```

### StatCard（统计卡片）

```html
<!-- 放在 #stats 插槽内，用 .sp-stats-row 包裹 -->
<div class="sp-stats-row">
  <StatCard
    icon="Calendar"       <!-- Element Plus 图标名，PascalCase -->
    label="总订单数"
    :value="String(1280)"
    color-type="primary"  <!-- primary | success | warning | danger | info -->
  />
  <StatCard icon="TrendCharts" label="增长率" value="+12.5%" color-type="success" />
  <StatCard icon="Warning" label="待处理" value="8" color-type="warning" />
  <StatCard icon="Delete" label="异常" value="3" color-type="danger" />
</div>
```

### ProTable（高级表格）

```html
<ProTable
  :data="list"
  :loading="loading"
  :columns="columns"
  :show-index="true"
  :show-selection="true"
  :show-pagination="true"
  :current-page="page.current"
  :page-size="page.size"
  :total="page.total"
  row-key="id"
  @selection-change="onSelectionChange"
  @row-click="onRowClick"
>
  <!-- 自定义列用 #colName="{ row }" -->
  <!-- 操作列用 #action="{ row }" -->
  <!-- 空状态自动使用 EmptyState 组件 -->
</ProTable>
```

### EmptyState（空状态）

```html
<EmptyState
  icon="document"          <!-- Element Plus 图标名 -->
  title="暂无数据"
  description="还没有添加任何记录"
>
  <!-- 可选：操作按钮 -->
  <el-button type="primary" :icon="Plus">立即添加</el-button>
</EmptyState>
```

## 三、常见操作写法

### 刷新数据

```typescript
async function loadData() {
  loading.value = true
  try {
    const res = await api.getList(params)
    list.value = res?.records || []
  } finally {
    loading.value = false  // ← 关键：必须在 finally 里
  }
}
```

### 删除确认

```typescript
async function handleDelete(row: any) {
  await ElMessageBox.confirm('确定删除吗？', '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  })
  await api.delete(row.id)
  ElMessage.success('删除成功')
  loadData()
}
```

### 导出Excel

```typescript
async function handleExport() {
  const loading = ElMessage.loading('正在导出...')
  try {
    const res = await api.export(params)
    if (res) ElMessage.success('导出成功')
  } finally {
    loading.close()
  }
}
```

### 新增/编辑弹窗

```typescript
const dialogVisible = ref(false)
const currentRow = ref<any>(null)

function handleAdd() { currentRow.value = null; dialogVisible.value = true }
function handleEdit(row: any) { currentRow.value = { ...row }; dialogVisible.value = true }
function handleSuccess() { dialogVisible.value = false; loadData() }
```

## 四、禁止事项速查

| ❌ 禁止 | ✅ 替代 |
|--------|-------|
| `padding: 14px;` | `fts-p-3` 或 `fts-p-4`（工具类） |
| `color: #409eff;` | `var(--fts-primary)` |
| `margin-bottom: 20px;` | `var(--fts-space-5)` |
| 裸div做页面容器 | `StandardPage` |
| 写scoped样式覆盖布局 | 用工具类布局 |
| 使用`FinanceBaseLayout` | `StandardPage`（已删除） |
| 使用`HRBaseLayout` | `StandardPage`（已删除） |
| 省略loading的finally | `finally { loading.value = false }` |

## 五、工具类速查表

### 布局工具类

| 类名 | 效果 |
|------|------|
| `fts-flex` | `display: flex` |
| `fts-flex-center` | flex + 水平垂直居中 |
| `fts-flex-between` | flex + 左右两端对齐 |
| `fts-flex-col` | flex + 垂直方向 |
| `fts-flex-1` | `flex: 1`（占据剩余空间） |
| `fts-flex-wrap` | flex + 允许换行 |

### 间距工具类

| 类名 | 效果 |
|------|------|
| `fts-p-1` ~ `fts-p-5` | padding: 4px ~ 24px |
| `fts-px-3` | 水平padding: 12px |
| `fts-py-2` | 垂直padding: 8px |
| `fts-m-1` ~ `fts-m-5` | margin: 4px ~ 24px |
| `fts-mt-3` | margin-top: 12px |
| `fts-mb-3` | margin-bottom: 12px |
| `fts-gap-1` ~ `fts-gap-5` | gap: 4px ~ 24px |

### 尺寸工具类

| 类名 | 效果 |
|------|------|
| `fts-w-full` | `width: 100%` |
| `fts-h-full` | `height: 100%` |

### 颜色语义类

| 类名 | 效果 |
|------|------|
| `fts-text-primary` | 主题色文字 |
| `fts-text-success` | 成功绿色文字 |
| `fts-text-warning` | 警告橙色文字 |
| `fts-text-error` | 错误红色文字 |
| `fts-text-muted` | 次要灰色文字 |
| `fts-bg-primary` | 主题色背景 |
| `fts-bg-soft` | 浅灰背景 |
