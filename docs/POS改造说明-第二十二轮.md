# 第二十二轮：交班界面按美团口径重做（动作流：看总账 → 数钱 → 交钱）

> 砍掉「钱箱理论应有 / 实点现金 / 长短款归因」，把「上交现金」做成页面最醒目的数字，异常单成为唯一阻断项。

## 改前 → 改后

| 区块 | 改前 | 改后 |
|---|---|---|
| 主结论 | 两态大卡 + 三数字块 + 净现金公式 | **四个指标横排**：本班次收款 / 现金收款 / 备用金(可改) / **上交现金(38px 品牌色)** |
| 钱箱核对 | 钱箱应有 + 实点输入 + 长短款胶囊 | **整块删除** |
| 非现金 | 三张大卡 + 「已直连入账」标签 | **收款统计表**：方式 / 笔数 / 小计 / 详情（可点开自查） |
| 指标卡 | 净营业额 / 有效订单 / 客单价 / 退款 四卡 | **订单统计行**：有效订单 · 退款 · 异常单 + [处理异常单] |
| 操作条 | 导出报表 / 打印小票 / 确认交班 | 左：开钱箱 · 导出报表 · 预打交班单 · 对账说明；右：**[交班] [交班，并打印交班单]** |

## 关键设计决定

1. **备用金是固定值**：只展示，旁边一个「修改」；改动走 400px 小弹窗 + 二次确认，写入 `/v1/pos/shift/opening-cash`。
2. **不数钱**：删除实点输入与长短款判定。收银员留下备用金、其余现金全交，少钱是操作问题不是系统要算的账。
3. **口径自洽**：上交现金 = 现金收款（净额，已扣退款）；本班次收款 = 现金净额 + 非现金净额 = 各方式小计之和。
4. **异常单是唯一硬门槛**：`pendingExceptionCount > 0` → 两个交班按钮同时 disabled、置灰、hover 出 tooltip「还有 N 笔异常单未处理」；清零后按钮恢复高亮，可直接下班。
5. **非现金可自查**：每行「详情」打开该方式的收款明细（时间/单号/金额/状态），出问题当场对账。

## 关于「待付单为什么能堆这么多」——建议后端加两道闸

1. **TTL 自动关单**：待付单超过 N 分钟（建议 15）未支付 → 后端自动置为 `CANCELLED(expired)`，不计入异常；
2. **下单即锁定库存**，超时释放，避免「占位不下单」。

前端可以立刻配合的两件事（下一轮做）：
- 异常抽屉里给待付单显示 **倒计时**（`expiresAt - now`），到点自动变「已关闭」；
- 收银台挂单区显示「还有 3 分钟自动取消」，减少人工干预。
