# 第二十轮：交班「应上交现金」按审计意见重构（信息过载 / 语义矛盾 / 输入焦点 / 负数收入）

> 四条意见逐条落到具体改法；另附测试基建迁移（见第 5 节）。

---

## 1. 文案堆砌、认知负荷高 → 一行算式换成三个数字块

改前：`现金收入 ¥0.00 − 现金退款 ¥134.00 = −¥134.00（退款大于收款，已由备用金垫付）`
一行里 4 个数字 + 一句括号解释，必须「读并计算」。

改后：三个并列数字块，标签在上、数字在下，眼睛直接对数字，不用读句子：

```
现金收入     现金退款     应上交现金
¥0.00        ¥134.00      ¥0.00
```

## 2. 逻辑自相矛盾（¥0.00 掩盖欠款）→ 主结论按状态切换

这是最严重的一条：原来标题固定「应上交现金 ¥0.00」，下面又说净流出 134、请补足 134。
收银员看到 0 会认为「不用交钱」，实际欠公司 134。

现在两态：

| 状态 | 标题 | 大字 | 颜色 |
|---|---|---|---|
| 现金净额 ≥ 0 | 应上交现金 | ¥60.00 | 品牌橙 |
| 现金净额 < 0 | **需补足（已从备用金垫付）** | **¥134.00** | 危险红 |

- 大字永远是「他此刻要面对的那个数」；
- 「应上交现金 ¥0.00」降级进数字块，信息不丢但不再抢注意力；
- 净流出只留一句行动指令：「本班次现金净流出 ¥134.00：退款大于收款，已从备用金垫付，交班后请补足。」

## 3. 实点输入不够醒目 → 独立成「钱箱核对」面板

改前：备用金 / 钱箱应有 / 实点 / 待点钞 全挤一行，输入框与说明同权重。改后左右分区：

```
钱箱应有现金                       实点现金
¥366.00                  [ 点完钱填入 ]  待点钞
含备用金 ¥500.00（留存钱箱）
```

- 输入框 44px 高 / 19px 数字 / 右对齐 / 聚焦品牌色描边（满足 44px 触控最小尺寸）；
- 有独立 label for，点标签可聚焦。

## 4. 负数收入与异常口径断层 → 「净退款」+ 统一「未计入」

非现金卡按 income / refund / net 三个量计算：净额为负时显示 **净退款 ¥40.00**（红色徽标），
副行写 `收入 ¥0.00 · 退款 ¥40.00`，不再出现 `微信 ¥-40.00` 这种反直觉数字。

异常单：顶部条「12 笔异常单…**未计入**营业额与上交额」，统计卡「另有 12 笔**未计入**」，
删掉「已剔除/已删除」这类实现词。

## 6. 本轮新增断言（round20，14 项）

- 短款态标题含「需补足」、大字 = 欠款额（不是 0）、应上交仍以 0.00 明示；
- 正常态标题 = 应上交现金、大字 = 应上交额；
- 数字块恰好 3 个；
- 实点输入 ≥18px / ≥44px / 右对齐；
- 非现金卡无负收入，退款 40 → 「净退款 ¥40.00」；
- 全屏文案不含「已剔除/已删除」。
