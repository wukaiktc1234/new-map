# 第十五轮：角标裁切 / 交班主数字过大 / 异常单语义色统一

> 三条反馈全部处理。验证：新增 12 项断言，回归 42+16+5 全绿。

---

## 1. 顶栏角标被裁（图一红圈）

**根因**：`.quick-actions` 为了防溢出写了 `overflow: hidden`，而 `el-badge` 的角标是
`position: absolute` + `transform: translateY(-50%) translateX(100%)` **悬在按钮外面上方**，
于是被容器上边缘裁掉一半。

**修法**（两层）：
```css
.quick-actions { overflow: visible; }        /* 不再裁自家子元素 */

.quick-actions .el-badge__content.is-fixed {
  top: 5px; right: 6px; transform: none;     /* 角标落在按钮内右上角 */
  border: none;
  box-shadow: 0 0 0 2px var(--pos-bg-primary); /* 用底色描边和按钮"切开"，可读 */
}
```
实测：`.quick-actions` 计算样式 `overflow: visible`、角标 2 个全部渲染、顶栏 `scrollWidth == clientWidth`（无溢出）。

## 2. 交班日结「应上交现金」面积过大（图二）

原来是**竖排巨幅**：54px 数字 + 居中标签 + 公式胶囊 + 备用金胶囊上下堆叠，整块 164px 高、占掉三分之一屏。

改成**横排两栏**：
```
┌───────────────────────────────────────────────┐
│ 应上交现金            现金收入 ¥X − 现金退款 ¥Y │
│ ¥0.00                备用金 ¥500 留存钱箱       │
└───────────────────────────────────────────────┘
```
- 数字 **54 → 38px**（窄屏 34px），标签 12.5px、字距 4 → 2
- `display: grid; grid-template-columns: auto 1fr`，label/value 在第一列，公式/备用金在第二列
- 卡片高度 **164 → 104px**，投影与描边同时减弱，视觉权重让位给下方的横条与统计

实测：`.sh-hero__value` 计算字号 `38px`、hero 高度 `104px`（断言 ≤130）。

## 3. 异常单文案配色不统一（图三）

**根因**：抽屉里的三处预警色各写各的硬编码 ——
提示条 `rgba(217,119,6,.1) / #92400e`、单卡 `rgba(217,119,6,.08)`、"待付"标签又一套；
深色覆盖段再各写一遍 `rgba(217,119,6,.14) / #fcd34d`，于是深色下发暗、浅色下与状态色不一致。

**修法**：抽出**语义预警三件套**（深浅各一套），全站同义同色：

| 令牌 | 浅色 | 深色 |
|---|---|---|
| `--pos-warning-soft`（底） | `#fbf5e8` | `#33291a` |
| `--pos-warning-text`（字） | `#8a6114` | `#e7bd6b` |
| `--pos-warning-border`（描边） | `rgba(194,134,31,.3)` | `rgba(231,189,107,.32)` |

统一应用到：异常提示条、异常单卡底/描边、异常原因标签、「待付（未收款）」状态胶囊。
深色覆盖段里那几条硬编码也删掉，改为直接引用令牌。

实测对比度（文字与底色亮度差）：
- 浅色 `#8a6114` on `#fbf5e8` → Δ145
- 深色 `#e7bd6b` on `#33291a` → Δ150
两套都远超 40 的可读阈值；且"提示条 / 原因标签 / 状态胶囊"三者颜色 **完全一致**（断言 C2）。
