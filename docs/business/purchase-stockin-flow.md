## 二、采购入库标准流程

### 核心流程图

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           采购入库标准流程                                        │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐ │
│  │ 1.采购订单 │───▶│ 2.到货验收 │───▶│ 3.生成追溯码│───▶│ 4.贴签入库 │───▶│ 5.上架存储 │ │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘ │
│       │               │               │               │               │        │

│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐ │
│  │ 创建采购单 │    │ 质量检查  │    │ 批量生成  │    │ 扫码确认  │    │ 库位分配  │ │
│  │ 内部确认  │    │ 数量核对  │    │ 打印标签  │    │ 连续扫码  │    │ 库存更新  │ │
│  │ 通知供应商│    │ 异常处理  │    │ 人工贴签  │    │ 实时进度  │    │ 入库完成  │ │

```

### 流程说明

| 步骤 | 操作人 | 操作内容 | 系统动作 |
|------|--------|----------|----------|
| 1.采购订单 | 采购员 | 创建采购订单，通知供应商 | 生成订单号，关联供应商 |
| 2.到货验收 | 库管员 | 质量检查、数量核对 | 记录验收结果 |
| 3.生成追溯码 | 系统 | 自动生成追溯码，打印标签 | 状态变为"待入库"(pending) |
| 4.贴签入库 | 库管员 | 人工贴签，扫码确认入库 | 状态变为"在库"(in_stock)，同步库存 |
| 5.上架存储 | 库管员 | 分配库位，商品上架 | 更新库存位置 |

## 三、自制商品入库标准流程

### 业务场景

自制商品入库是指餐饮企业将自制产品（如手工水饺、包子、酱料等）入库存储的过程。

### 核心流程图

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           自制商品入库标准流程                                    │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐ │
│  │ 1.生产计划 │───▶│ 2.原料领用 │───▶│ 3.生产制作 │───▶│ 4.成品入库 │───▶│ 5.库存更新 │ │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘ │
│       │               │               │               │               │        │
│       ▼               ▼               ▼               ▼               ▼        │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐ │
│  │ 创建计划  │    │ 扫描原料  │    │ 制作成品  │    │ 扫描原料码 │    │ 库存增加  │ │
│  │ 确认配方  │    │ 扣减库存  │    │ 质量检查  │    │ 生成成品码 │    │ 追溯关联  │ │
│  │ 计算用量  │    │ 记录追溯  │    │ 成品登记  │    │ 打印标签  │    │ 入库完成  │ │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘ │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 详细流程说明

#### 阶段一：生产计划

| 步骤 | 操作人 | 操作内容 | 系统动作 |
|------|--------|----------|----------|
| 1.1 | 厨师长 | 创建生产计划 | 生成计划单号 |
| 1.2 | 厨师长 | 选择产品配方 | 加载配方明细 |
| 1.3 | 厨师长 | 确认生产数量 | 计算原料用量 |
| 1.4 | 系统 | 检查原料库存 | 提示库存不足 |

#### 阶段二：原料领用

| 步骤 | 操作人 | 操作内容 | 系统动作 |
|------|--------|----------|----------|
| 2.1 | 厨师 | 扫描原料追溯码 | 记录原料来源 |
| 2.2 | 系统 | 验证原料状态 | 确认原料在库 |
| 2.3 | 系统 | 扣减原料库存 | 更新库存数量 |
| 2.4 | 系统 | 记录原料使用 | 建立追溯关联 |

**原料追溯码要求**：
- 原料必须是已入库状态（in_stock）
- 扫描后记录原料批次信息
- 支持多原料组合

#### 阶段三：生产制作

| 步骤 | 操作人 | 操作内容 | 系统动作 |
|------|--------|----------|----------|
| 3.1 | 厨师 | 按配方制作 | 记录生产过程 |
| 3.2 | 厨师 | 质量检查 | 记录检查结果 |
| 3.3 | 厨师 | 成品登记 | 生成成品信息 |

#### 阶段四：成品入库

| 步骤 | 操作人 | 操作内容 | 系统动作 |
|------|--------|----------|----------|
| 4.1 | 厨师 | 填写成品信息 | 产品名称、数量、成本单价 |
| 4.2 | 厨师 | 扫描使用的原料追溯码 | 关联原料来源 |
| 4.3 | 系统 | 生成成品追溯码 | 状态为"在库"(in_stock) |
| 4.4 | 系统 | 打印成品标签 | 可选打印 |
| 4.5 | 厨师 | 确认入库 | 同步库存数据 |

**成品追溯码格式**：
```
成品追溯码格式：FTC + 日期 + 产品代码 + 序号
示例：FTC20260312-P001-0001

成品追溯码包含信息：
├── 产品基本信息（名称、规格、单位）
├── 生产信息（生产日期、保质期、批次号）
├── 原料来源（关联的原料追溯码列表）
├── 成本信息（原料成本、人工成本）
└── 存储条件（存储温度、保质期）
```

#### 阶段五：库存更新

| 步骤 | 操作人 | 操作内容 | 系统动作 |
|------|--------|----------|----------|
| 5.1 | 系统 | 更新产品库存 | 库存数量增加 |
| 5.2 | 系统 | 记录库存变动 | 创建库存日志 |
| 5.3 | 系统 | 建立追溯链 | 原料→成品关联 |
| 5.4 | 系统 | 更新成本核算 | 计算产品成本 |

## 四、数据流转关系

### 采购入库数据流转

```
采购订单(purchase_order)
       │
       ▼
到货验收记录
       │
       ▼
原料追溯码(material_trace_code) ──状态: pending
       │
       ▼
扫码入库确认
       │
       ▼
原料追溯码(material_trace_code) ──状态: in_stock
       │
       ▼
库存表(inventory) ──库存增加
       │
       ▼
库存日志(store_inventory_log) ──记录变动
```

### 自制商品入库数据流转

```
原料追溯码(material_trace_code) ──状态: in_stock
       │
       ▼
扫描领用 ──扣减库存
       │
       ▼
原料追溯码(material_trace_code) ──状态: used
       │
       ▼
生产制作 ──关联原料
       │
       ▼
成品追溯码(food_trace_code) ──状态: in_stock
       │
       ▼
库存表(inventory) ──成品库存增加
       │
       ▼
库存日志(store_inventory_log) ──记录变动
```

## 五、追溯链关系

### 完整追溯链示例

```
原料采购入库
│
├── 原料追溯码: MTC202603120001001 (面粉 10kg)
├── 原料追溯码: MTC202603120002002 (猪肉 5kg)
├── 原料追溯码: MTC202603120003003 (韭菜 3kg)
│
▼
自制产品入库
│
├── 成品追溯码: FTC20260312-P001-0001 (手工水饺 500个)
│   │
│   ├── 关联原料: MTC202603120001001 (面粉 2kg)
│   ├── 关联原料: MTC202603120002002 (猪肉 1kg)
│   └── 关联原料: MTC202603120003003 (韭菜 0.5kg)
│
▼
销售出库
│
├── 销售订单: SO20260312-0001
├── 销售商品: 手工水饺 10份
└── 关联成品追溯码: FTC20260312-P001-0001
```

## 六、系统状态流转

### 原料追溯码状态

```
pending(待入库) ──采购入库扫码──▶ in_stock(在库)
                                      │
                                      │
                                      ▼
                               used(已使用) ──自制产品领用
```

### 成品追溯码状态

```
created(已创建)
    │
    └──▶ in_stock(在库) ──入库确认
            │
            └──▶ sold(已售出) ──销售出库
```

### 入库单状态

```
pending(待验收) 
    │
    ├──▶ rejected(已拒收) ──▶ 结束
    │
    └──▶ accepted(已验收) 
            │
            └──▶ labeling(贴签中) 
                    │
                    └──▶ scanning(扫码中) 
                            │
                            ├──▶ partial(部分入库)
                            │
                            └──▶ completed(已完成)
```
