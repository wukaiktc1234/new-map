## 二、设计理念：自动为主，手工为辅

本系统财务中心采用业界主流的「**自动为主，手工为辅**」混合记账模式，符合财政部《会计软件基本功能和服务规范》（财会〔2024〕12号）要求。

### 2.1 自动记账场景

以下业务在对应模块操作完成后，系统会**自动生成会计凭证**（无需人工录入）：

| 业务来源 | 触发动作 | 自动凭证示例 |
|---------|---------|------------|
| 采购入库 | 采购收货单审核 | 借：原材料 / 贷：应付账款 |
| 采购付款 | 采购结算单付款 | 借：应付账款 / 贷：银行存款 |
| 销售订单 | 订单完成结算 | 借：银行存款 / 贷：主营业务收入、应交税费 |
| 会员充值 | 会员储值成功 | 借：银行存款 / 贷：预收账款 |
| 库存领料 | 后厨领料出库 | 借：主营业务成本 / 贷：原材料 |
| 期末结账 | 损益结转 | 借：主营业务收入 / 贷：本年利润 |

自动凭证可在「**自动凭证管理**」页面查看规则配置与生成记录。

### 2.2 手工记账场景

以下场景需要财务人员**手工录入凭证**（在「财务总账」页面操作）：

- 期末调整分录（折旧计提、坏账准备、存货跌价）
- 跨期摊销（房租、保险费、广告费按月摊销）
- 差错更正（红字冲销、补充登记）
- 银行手续费、利息收入等零星业务
- 工资计提与发放
- 暂估入账（货到票未到）

### 2.3 凭证状态流转

```
   ┌────────┐  审核   ┌────────┐  过账   ┌────────┐
   │  草稿  │ ──────→ │ 已审核 │ ──────→ │ 已过账 │
   └────────┘         └────────┘         └────────┘
       │                   │                  │
       │     作废          │ 作废             │ 红字冲销
       ↓                   ↓                  ↓
   ┌────────┐         ┌────────┐         ┌─────────────┐
   │ 已作废 │         │ 已作废 │         │ 红字冲销凭证 │
   └────────┘         └────────┘         └─────────────┘
```

**关键规则**：
- **草稿**：可编辑、可作废
- **已审核**：不可编辑，可过账、可作废
- **已过账**：不可编辑、不可作废，**只能通过红字冲销更正**
- **已作废**：终态，不可恢复

## 三、会计科目管理

> **路径**：财务中心 → 会计科目
> **用途**：维护企业会计科目体系，是凭证录入的基础

### 3.1 页面功能

- 树形展示所有科目（按资产/负债/权益/成本/收入/利润六大类分组）
- 按编码、名称搜索；按类型、状态筛选
- 新增顶级科目或子科目
- 编辑科目信息
- 启用 / 禁用科目

### 3.2 新增科目操作步骤

1. 点击页面右上角「**新增科目**」按钮
2. 在弹出的对话框中填写：
   - **科目编码**：必填，遵循企业会计准则编码规则（如 1001 库存现金）
   - **科目名称**：必填，如「库存现金」
   - **科目类型**：必选，资产 / 负债 / 权益 / 成本 / 收入 / 利润
   - **余额方向**：必选，借方 / 贷方（资产类默认借方，负债/权益类默认贷方）
   - **上级科目**：可选，选择后作为子科目
   - **状态**：默认「启用」
   - **备注**：可选
3. 点击「**确定**」保存

### 3.3 编辑科目

1. 在科目树中找到目标科目，点击操作列「**编辑**」
2. 修改需要变更的字段
3. 点击「**确定**」保存

> **注意**：科目编码一旦创建不建议修改，避免历史凭证引用错乱。

### 3.4 启用 / 禁用科目

- **禁用**：点击操作列「**禁用**」，该科目将不再出现在凭证录入的科目下拉列表中
- **启用**：已禁用的科目可点击「**启用**」恢复

> **建议**：年末科目体系调整时，对不再使用的科目执行「禁用」而非「删除」，保留历史数据完整性。

## 四、财务总账（凭证管理）

> **路径**：财务中心 → 财务总账
> **用途**：手工凭证录入、审核、过账、作废，是日常会计核算的核心

### 4.1 页面功能

- 顶部统计卡片：本月凭证数、已过账数、草稿数、待审核数
- 凭证列表：展示凭证编号、日期、摘要、借/贷金额、会计科目、制单人、状态
- 按日期范围搜索
- 新增凭证 / 编辑草稿凭证 / 审核凭证 / 过账凭证 / 作废凭证
- 查看凭证详情（含分录明细）

### 4.2 手工录入凭证（核心操作）

#### 操作步骤

1. 点击页面右上角「**新增凭证**」按钮，弹出凭证录入对话框
2. 填写凭证头部信息：
   - **凭证类型**：收款 / 付款 / 转账 / 通用（默认）
   - **凭证日期**：默认今天，可修改
   - **摘要**：简述本张凭证业务（如「计提6月工资」）
   - **附件张数**：原始单据张数，默认 1
3. 录入分录明细（至少 2 行）：
   - **科目**：从下拉列表选择（仅显示已启用的末级科目）
   - **摘要**：该行分录的说明（可不同于凭证摘要）
   - **借方金额**：本行借方发生额（元）
   - **贷方金额**：本行贷方发生额（元）
   - 同一行不能同时有借方和贷方金额
4. 系统实时显示「**借方合计**」「**贷方合计**」及平衡状态
5. 点击「**添加分录**」可增加行；点击行尾删除图标可移除行
6. 确认「**借贷平衡**」提示后，点击「**保存草稿**」

#### 借贷平衡校验规则

- 借方合计必须等于贷方合计
- 不平衡时「保存」按钮置灰，无法保存
- 至少包含 2 行分录

#### 示例：计提6月工资

| 科目 | 摘要 | 借方(元) | 贷方(元) |
|------|------|---------|---------|
| 6602 管理费用 | 计提工资 | 86,000.00 | |
| 2202 应付职工薪酬 | 应付工资 | | 86,000.00 |

借方合计：86,000.00 = 贷方合计：86,000.00 ✓

### 4.3 编辑凭证

- 仅「**草稿**」状态的凭证可编辑
- 在列表中找到草稿凭证，点击操作列「**编辑**」
- 修改后保存即可

### 4.4 审核凭证

- 仅「**草稿**」状态的凭证可审核
- 点击操作列「**审核**」
- 审核后状态变为「**已审核**」，不可再编辑

> **合规建议**：制单人与审核人应为不同人员，体现三权分立原则。

### 4.5 过账凭证

- 仅「**已审核**」状态的凭证可过账
- 点击操作列「**过账**」
- 过账后状态变为「**已过账**」，凭证正式计入总账，**不可编辑、不可作废**

### 4.6 作废凭证

- 「**草稿**」或「**已审核**」状态的凭证可作废
- 点击操作列「**作废**」
- 系统弹出确认框，确认后凭证状态变为「**已作废**」
- 已作废凭证不可恢复

### 4.7 查看凭证详情

- 点击任意凭证操作列「**查看**」
- 弹出详情对话框，展示：
  - 凭证头部信息（编号、日期、类型、摘要、附件张数、制单人、审核人）
  - 分录明细表（科目编码、科目名称、摘要、借方、贷方）
  - 借方合计、贷方合计

### 4.8 已过账凭证的更正（红字冲销）

已过账凭证**不可直接修改或删除**，如需更正：

1. 录入一张与原凭证**金额相同、方向相反**的红字凭证（摘要注明「冲销 ××号凭证」）
2. 审核并过账红字凭证
3. 如需要，再录入一张正确的蓝字凭证

## 五、会计期间管理

> **路径**：财务中心 → 会计期间
> **用途**：管理月度/季度/年度会计期间，执行试算平衡、结账检查、损益结转、结账

### 5.1 页面功能

- 期间列表：展示期间编号、类型、起止日期、状态
- 按期间类型（月度/季度/年度）、状态（开放/结账中/已结账）筛选
- 新增会计期间
- 试算平衡检查
- 结账检查清单
- 损益结转
- 结账 / 反结账

### 5.2 新增会计期间

1. 点击「**新增期间**」按钮
2. 选择期间类型（月度 / 季度 / 年度）
3. 填写年份、月份/季度
4. 系统自动计算起止日期
5. 点击「**确定**」

### 5.3 试算平衡

> **用途**：检查所有科目的借方余额合计是否等于贷方余额合计

1. 在期间列表中找到目标期间（状态为「开放」或「结账中」）
2. 点击操作列「**试算平衡**」
3. 弹出对话框展示：
   - 借方余额合计 / 贷方余额合计
   - 是否平衡
   - 各科目余额明细表

> **说明**：试算不平衡时无法结账。需先检查凭证是否有错漏，必要时录入调整凭证。

### 5.4 结账检查清单

> **用途**：结账前的完整性检查，确保所有必要操作已完成

1. 点击操作列「**结账检查**」
2. 弹出检查清单对话框，展示各项检查的完成状态：
   - ✓ / ✗ 本期所有凭证已过账
   - ✓ / ✗ 试算平衡
   - ✓ / ✗ 损益类科目已结转
   - ✓ / ✗ 期末调整分录已完成
   - ✓ / ✗ 资产负债表平衡
3. 所有项目通过（✓）后方可结账

### 5.5 损益结转

> **用途**：将收入、费用类科目余额结转至「本年利润」科目

1. 点击操作列「**损益结转**」
2. 系统自动生成损益结转凭证：
   - 借：各收入类科目（按余额反向）
   - 贷：本年利润
   - 借：本年利润
   - 贷：各费用类科目（按余额反向）
3. 弹出结转结果，展示结转金额

> **注意**：损益结转应在所有期末调整分录完成后执行，且只能执行一次。如需重新结转，需先反结账。

### 5.6 结账

1. 完成上述试算平衡、结账检查、损益结转
2. 点击操作列「**结账**」
3. 确认后期间状态变为「**已结账**」
4. 结账后该期间内的凭证不可再修改

### 5.7 反结账

- 仅「**已结账**」状态的期间可反结账
- 点击操作列「**反结账**」
- 期间状态恢复为「**开放**」，可重新进行业务操作

> **风险提示**：反结账会破坏已结账数据的稳定性，建议仅在必要时操作，并做好操作记录。

## 六、应收账款

> **路径**：财务中心 → 应收账款
> **用途**：管理客户欠款，登记收款记录

### 6.1 主要操作

- **新增应收**：登记客户欠款（客户名称、应收金额、开票日期、到期日）
- **收款核销**：点击「收款」录入收款金额，系统自动计算未收余额
- **查看详情**：点击「查看」展示应收单完整信息
- **状态查询**：按未收款 / 部分收款 / 已结清 / 已逾期筛选

### 6.2 状态说明

| 状态 | 含义 |
|------|------|
| unpaid | 未收款 |
| partial | 部分收款 |
| settled | 已结清 |
| overdue | 已逾期（超过到期日仍未结清） |

## 七、应付账款

> **路径**：财务中心 → 应付账款
> **用途**：管理对供应商的欠款，登记付款记录

### 7.1 主要操作

- **新增应付**：登记供应商欠款
- **付款核销**：点击「付款」弹出付款对话框，录入付款金额、付款方式、银行账户
- **查看详情**：展示应付单完整信息
- **状态查询**：按未付款 / 部分付款 / 已结清 / 已逾期筛选

### 7.2 付款操作步骤

1. 在应付列表中找到待付款记录
2. 点击操作列「**付款**」
3. 在付款对话框中填写：
   - 付款金额（默认为未付余额，可修改为部分付款）
   - 付款方式（银行转账 / 现金 / 支票）
   - 银行账户（选择付款账户）
   - 付款日期
4. 点击「**确定**」
5. 系统自动生成付款凭证（借：应付账款 / 贷：银行存款）

## 十、发票报销

> **路径**：财务中心 → 发票报销
> **用途**：发票录入、报销审批

### 10.1 主要操作

- **发票录入**：登记收到的发票（发票号、类型、金额、税额、开票日期）
- **报销申请**：关联发票提交报销申请
- **审批**：点击「审批」弹出审批对话框，可同意/驳回/退回
- **查看详情**：展示发票及报销完整信息

### 10.2 发票类型

| 类型 | 说明 |

## 十六、典型业务场景操作流程

### 场景一：日常营业收入入账

**说明**：堂食、外卖等营业收入由销售模块自动生成凭证，无需人工操作。

**查看自动凭证**：
1. 进入「财务总账」
2. 在列表中查看 `sourceType=AUTO_POS` 的凭证
3. 点击「查看」核对金额与科目

### 场景二：手工录入银行手续费

1. 进入「财务总账」
2. 点击「新增凭证」
3. 录入：
   - 凭证类型：付款
   - 摘要：银行手续费
   - 分录1：6603 财务费用 / 借方 50.00
   - 分录2：1002 银行存款 / 贷方 50.00
4. 保存草稿
5. 审核 → 过账

### 场景三：计提本月工资

1. 进入「财务总账」
2. 点击「新增凭证」
3. 录入：
   - 凭证类型：转账
   - 摘要：计提6月工资
   - 分录1：6602 管理费用 / 借方 86,000.00
   - 分录2：2202 应付职工薪酬 / 贷方 86,000.00
4. 保存草稿
5. 审核 → 过账

### 场景四：月末结账完整流程

1. **检查所有凭证已过账**
   - 进入「财务总账」，确认无草稿/已审核状态的凭证
2. **录入期末调整分录**
   - 折旧计提、摊销、坏账准备等
3. **试算平衡**
   - 进入「会计期间」，点击「试算平衡」
   - 确认借贷平衡
4. **结账检查**
   - 点击「结账检查」，确认所有项目通过
5. **损益结转**
   - 点击「损益结转」，生成结转凭证
   - 进入「财务总账」审核并过账该凭证
6. **再次试算平衡**
   - 确认损益类科目余额为 0
7. **结账**
   - 点击「结账」，期间状态变为「已结账」
8. **生成报表**
   - 进入「财务报表」，生成资产负债表、利润表、现金流量表

### 场景五：更正已过账凭证（红字冲销）

**背景**：发现6月15日凭证「记-2026-06-0001」金额错误

1. 进入「财务总账」，查看原凭证内容
2. 点击「新增凭证」录入红字凭证：
   - 摘要：冲销记-2026-06-0001号凭证
   - 分录与原凭证**金额相同、方向相反**
3. 保存草稿 → 审核 → 过账
4. 如需要，再录入一张正确的蓝字凭证

### 场景六：新增会计科目

**背景**：企业新开展广告业务，需新增「6601.05 广告费」科目

1. 进入「会计科目」
2. 点击「新增科目」
3. 填写：
   - 科目编码：660105
   - 科目名称：广告费
   - 科目类型：成本
   - 余额方向：借方
   - 上级科目：6601 销售费用
4. 点击「确定」

## 十七、常见问题

### Q1：凭证保存时提示「借贷不平衡」

**原因**：借方合计 ≠ 贷方合计

**解决**：
- 检查每行分录的借方/贷方金额
- 确认同一行没有同时填写借方和贷方
- 查看对话框底部的「借方合计」「贷方合计」是否一致

### Q2：凭证无法编辑

**原因**：仅「草稿」状态的凭证可编辑

**解决**：
- 已审核凭证：需先作废后重新录入
- 已过账凭证：需通过红字冲销更正

### Q3：无法结账

**可能原因**：
1. 存在未过账的凭证
2. 试算不平衡
3. 结账检查清单未全部通过
4. 损益未结转

**解决**：依次检查上述项目，全部通过后再结账

### Q4：科目下拉列表中找不到某科目

**可能原因**：
1. 该科目已被禁用
2. 该科目不是末级科目（仅末级科目可录入凭证）

**解决**：
- 进入「会计科目」检查科目状态
- 启用已禁用的科目
- 选择该科目的下级末级科目

### Q5：后端服务不可用，页面显示 Mock 数据

**说明**：开发环境下，若后端服务未启动，系统会自动回退到 Mock 数据，确保页面可正常浏览和交互。

**解决**：
- 启动后端服务：`mvn spring-boot:run -DskipTests`
- 后端启动后，刷新页面即可加载真实数据

### Q6：金额显示为「分」而非「元」

**说明**：系统后端以「分」为单位存储金额，前端自动转换为「元」显示。

**解决**：如发现金额异常大（如显示 3580000 而非 35800），请检查 API 转换逻辑是否正常。

### Q7：菜单中看不到「会计科目」「会计期间」

**原因**：菜单按企业规模分级显示

**解决**：
- 这两个菜单对 standard 及以上规模可见
- 检查企业规模配置是否正确
- 联系管理员调整角色权限
