## 二、产品管理模块流程

```mermaid
flowchart TD
    subgraph 产品管理流程
        START([开始]) --> INPUT[输入产品信息]
        INPUT --> VALIDATE{信息验证}
        
        VALIDATE -->|验证失败| ERROR1[提示错误信息]
        ERROR1 --> INPUT
        
        VALIDATE -->|验证通过| CREATE[创建产品记录]
        CREATE --> GENCODE[生成溯源编码]
        GENCODE --> SAVE[(保存到数据库)]
        SAVE --> CACHE[更新缓存]
        CACHE --> LOG[记录操作日志]
        LOG --> END([结束])
    end

    subgraph 产品状态流转
        S1[新建] --> S2[上架]
        S2 --> S3[销售中]
        S3 --> S4[下架]
        S4 --> S2
        S3 --> S5[售罄]
    end
```

## 查看方式

### 方式一：VS Code 查看
1. 安装插件：`Mermaid Markdown Syntax Highlighting` 或 `Markdown Preview Mermaid Support`
2. 打开此文件
3. 按 `Ctrl+Shift+V` 预览

### 方式二：在线工具
1. 访问 https://mermaid.live
2. 复制上面的 Mermaid 代码
3. 粘贴即可查看

### 方式三：Typora 编辑器
1. 用 Typora 打开此文件
2. 自动渲染 Mermaid 图表

### 方式四：导出图片
```bash
# 安装 mermaid-cli
npm install -g @mermaid-js/mermaid-cli

# 生成 PNG 图片
mmdc -i 系统流程图.md -o 系统流程图.png
```
