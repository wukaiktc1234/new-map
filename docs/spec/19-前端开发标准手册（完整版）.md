## 1.3 间距系统（Spacing）

**核心原则**：所有间距必须使用 `--fts-space-*` 变量，禁止硬编码像素值。

| 变量名 | 值 | 使用场景 |
|--------|-----|---------|
| `--fts-space-1` | `4px` | 极小间距（图标与文字间） |
| `--fts-space-2` | `8px` | 小间距（按钮组内） |
| `--fts-space-3` | `12px` | 工具栏padding、紧凑元素间距 |
| `--fts-space-4` | `16px` | **统计卡片区域padding**、卡片内间距 |
| `--fts-space-5` | `20px` | PageHeader padding、图表卡片内间距 |
| `--fts-space-6` | `24px` | **表格区左右padding**、分页区padding |
| `--fts-space-7` | `28px` | 大区块间距 |
| `--fts-space-8` | `32px` | 区块间距 |
| `--fts-space-10` | `40px` | 大间距 |
| `--fts-space-12` | `48px` | 特大间距 |

### 常用组合模式

```
统计卡片区：    padding: var(--fts-space-4) 0;          → 上下16px，左右0
搜索工具栏：    padding: var(--fts-space-3) var(--fts-space-6); → 12px 24px
表格/内容区：   padding: 0 var(--fts-space-6) var(--fts-space-6); → 0 24px 24px
分页区域：     padding: var(--fts-space-4) var(--fts-space-6); → 16px 24px
页面头部：     padding: var(--fts-space-5) var(--fts-space-6); → 20px 24px
```

## 1.6 动画系统（Animation & Transition）

### 时长规格（Duration）
| 变量名 | 值 | 使用场景 |
|--------|-----|---------|
| `--fts-duration-fast` | `150ms` | 快速反馈（按钮悬停、颜色变化） |
| `--fts-duration-normal` | `250ms` | 正常过渡（展开/收起、淡入淡出） |
| `--fts-duration-slow` | `350ms` | 复杂动画（页面切换、大型组件） |

### 缓动函数（Easing）
| 变量名 | 值 | 使用场景 |
|--------|-----|---------|
| `--fts-easing-default` | `cubic-bezier(0.4, 0, 0.2, 1)` | **标准缓动**（大多数过渡） |
| `--fts-easing-in` | `cubic-bezier(0.4, 0, 1, 1)` | 进入动画 |
| `--fts-easing-out` | `cubic-bezier(0, 0, 0.2, 1)` | 退出动画 |
| `--fts-easing-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | 往复动画 |

### 标准过渡写法
```scss
/* 推荐用法 */
transition: all var(--fts-duration-fast) var(--fts-easing-default);

/* StatCard悬停效果 */
.stat-card {
  transition: all var(--fts-duration-fast) var(--fts-easing-default);
}
```

**⚠️ 重要**：Mock数据中的status字段必须使用字符串格式（'active'/'inactive'/'probation'），禁止使用数字（1/0/2）。

## 6.2 金额字段格式

### 存储单位
| 层级 | 单位 | 类型 | 示例 |
|------|------|------|------|
| 后端数据库 | **分** (fen) | BIGINT (整数) | 2500000 (= ¥25,000.00) |
| 前端显示 | **元** (yuan) | number (浮点数) | 25000.00 |
| 前端展示 | **元字符串** | string | "¥25,000.00" |

### 转换公式
```typescript
// 分 → 元（用于显示）
const yuan = fen / 100  // 2500000 / 100 = 25000

// 元 → 分（用于提交）
const fen = Math.round(yuan * 100)  // 25000 * 100 = 2500000

// 格式化显示（带千分位和货币符号）
const formatted = `¥${yuan.toLocaleString('zh-CN', { minimumFractionDigits: 2 })}`
// 结果: "¥25,000.00"
```

### 金额显示样式
```scss
.salary-text,
.money-text,
.amount-text {
  font-variant-numeric: tabular-nums;           // 等宽数字
  font-weight: var(--fts-font-weight-semibold);      // 600
  font-size: var(--fts-font-size-base);             // 14px
}
```

## 7.2 禁止事项清单（绝对不能违反）

| 禁止项 | 正确做法 | 违反后果 |
|--------|---------|---------|
| 硬编码颜色值（如 `#fff`, `#333`） | 必须使用 `--fts-*` CSS变量 | 无法适配深色模式 |
| 硬编码像素间距（如 `margin: 10px`） | 必须使用 `--fts-space-*` 变量 | 无法全局调整间距 |
| 直接使用 axios/fetch 发请求 | 必须使用 `src/api/request.ts` 导出的 request 实例 | 绕过拦截器 |
| 在响应中访问 `.data` 属性 | 响应拦截器已提取，直接使用返回值 | 数据结构错误 |
| 使用 `@Autowired` 字段注入 | 必须使用构造函数注入 | 违反Spring规范 |
| 对业务核心数据物理删除 | 必须逻辑删除（removeById） | 数据丢失风险 |
| 在查询条件中手动添加 `deleted = 0` | 使用 @TableLogic 注解自动处理 | 冗余且易出错 |
| Mock数据中使用数字status (1/0/2) | 必须使用字符串 ('active'/'inactive'/'probation') | StatusTag显示异常 |
| 删除操作无确认对话框 | 必须使用 ElMessageBox.confirm() | 用户误操作风险 |
| 提交 console.log 调试代码 | 只能使用 console.error/warn | 代码质量门禁不通过 |
