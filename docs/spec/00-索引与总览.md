## 关键决策记录

在阅读各章节前，请先了解以下已确认的关键技术决策：

| 决策项 | 结论 | 说明 |
|--------|------|------|
| 数据库选型 | PostgreSQL 18 | 生产环境使用PostgreSQL 18，开发环境使用H2内存数据库 |
| JDK版本 | JDK 21 | 与Spring Boot 3.2.0兼容，支持虚拟线程等新特性 |
| TypeScript严格模式 | 开启 | noImplicitAny=true, strictNullChecks=true |
| Lombok | 已禁用 | pom.xml中lombok依赖已注释，必须手写getter/setter |
| 前端请求封装 | request实例 | 必须使用src/api/request.ts，禁止直接使用axios/fetch |
| 逻辑删除 | @TableLogic | deleted字段(0/1)，禁止手动添加deleted条件 |
| 数据库字段命名 | 下划线命名 | 数据库层snake_case，Java/前端层camelCase，MyBatis-Plus自动映射 |
| 统一响应格式 | Result\<T\> | code=0成功，非0失败（注意：不是HTTP 200） |

## 规范层级

本文档体系中的规范分为三个层级：

- **强制（MUST）**：必须遵守，违反将导致代码审查不通过。标记为【强制】
- **推荐（SHOULD）**：强烈建议遵守，特殊情况可例外但需说明理由。标记为【推荐】
- **参考（MAY）**：提供指导，可根据实际情况调整。无特殊标记
