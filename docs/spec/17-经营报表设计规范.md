# 经营报表模块设计规范 v2.0

## 一、现状诊断与核心问题

### 1.1 现有设计概览

当前经营报表模块包含6个子模块：日报表、周报表、月报表、季报表、年报表、利润分析。每个模块均采用"KPI卡片 + 单图表 + 数据表格"的三段式布局。

### 1.2 核心问题诊断

| 问题类别 | 具体表现 | 业务影响 |
|---------|---------|---------|
| 图表过度使用 | 6个报表模块各含1个独立图表，图表类型与数据量级不匹配 | 页面加载慢，视觉噪音大，干扰数据阅读 |
| 数据密度不足 | 图表占据40%以上可视区域，但仅传达1-2个数据维度 | 用户需滚动多次才能获取完整数据 |
| 缺乏数据上下文 | KPI卡片仅展示当前值，无同比/环比/目标对比 | 无法快速判断经营状况好坏 |
| 交互能力薄弱 | 仅有基础日期筛选，无钻取/联动/下钻能力 | 发现异常后无法定位原因 |
| 信息层级混乱 | 所有数据平铺展示，无主次之分 | 决策者难以在30秒内抓住重点 |
| 导出功能缺失 | 仅利润分析模块有导出按钮，其他模块无 | 无法进行二次分析或汇报 |

### 1.3 用户场景分析

| 用户角色 | 核心诉求 | 使用频率 | 关注重点 |
|---------|---------|---------|---------|
| 店长/运营 | 今日经营是否正常？哪里异常？ | 每日多次 | 实时性、异常预警 |
| 区域经理 | 各店排名如何？谁需要帮助？ | 每周2-3次 | 横向对比、趋势判断 |
| 财务/老板 | 利润是否达标？成本是否合理？ | 每月/季 | 准确性、完整性、可导出 |

## 二、数据呈现优先级规划

### 2.1 核心数据指标体系（KPI金字塔）

```
                    ┌─────────────┐
                    │   净利润    │  ← 终极目标（L1：结果指标）
                    └──────┬──────┘
           ┌───────────────┼───────────────┐
           │               │               │
      ┌────┴────┐    ┌────┴────┐    ┌────┴────┐
      │ 营收指标 │    │ 成本指标 │    │ 效率指标 │  ← L2：驱动指标
      └────┬────┘    └────┬────┘    └────┬────┘
   ┌───────┼───────┐ ┌────┼────┐   ┌────┼────┐
   │       │       │ │    │    │   │    │    │
  总营收  客单价  订单数 食材成本 人工成本 翻台率 人效  ← L3：过程指标
```

### 2.2 数据与图表配比原则

| 页面类型 | 数据表格占比 | 图表占比 | 适用场景 |
|---------|------------|---------|---------|
| **经营概览页** | 60% | 40% | 首页/驾驶舱，快速扫描 |
| **明细分析页** | 80% | 20% | 日报/周报，数据核查 |
| **趋势对比页** | 50% | 50% | 月报/季报，趋势判断 |
| **专项分析页** | 40% | 60% | 利润/成本，结构分析 |

### 2.3 数据完整性规范

- **原始数据必须可访问**：所有汇总数据必须支持下钻查看明细
- **数据精度分层**：概览页保留1位小数，明细页保留2位小数，导出保留原始精度
- **时间维度完整**：日/周/月/季/年报的数据口径必须一致，可横向对比
- **异常数据标注**：超出正常范围的数据必须高亮标注（红色/绿色）并说明原因

## 三、图表使用规范

### 3.1 图表选择决策树

```
数据要表达什么？
    │
    ├─→ 比较大小 ──→ 项目数量 ≤ 5？ ──→ 是：柱状图
    │                      └─→ 否：条形图（横向）
    │
    ├─→ 看趋势变化 ──→ 时间点 ≤ 12？ ──→ 是：折线图
    │                       └─→ 否：简化折线图/数据表格
    │
    ├─→ 看占比构成 ──→ 类别 ≤ 5？ ──→ 是：饼图/环形图
    │                      └─→ 否：百分比堆叠柱状图
    │
    ├─→ 看分布情况 ──→ 直方图 / 箱线图
    │
    └─→ 看相关性 ──→ 散点图（谨慎使用）
```

### 3.2 图表使用白名单

| 图表类型 | 适用场景 | 数据量级要求 | 禁止场景 |
|---------|---------|------------|---------|
| **折线图** | 时间序列趋势 | 数据点 3-24 个 | 类别对比、占比展示 |
| **柱状图** | 类别数值对比 | 类别数 2-12 个 | 时间趋势（超过12个点） |
| **条形图** | 类别数值对比（类别名较长） | 类别数 3-15 个 | 实时数据 |
| **饼图/环形图** | 占比构成（强调部分与整体关系） | 类别数 2-5 个 | 类别超过6个、数值相近 |
| **堆叠柱状图** | 构成对比（同时看总量和结构） | 类别数 2-4 层 | 超过4层、负数 |
| **组合图** | 双指标对比（如营收+订单数） | 2个指标，单位不同 | 超过2个指标 |

### 3.3 图表使用红线（强制禁止）

1. **禁止3D图表**：所有3D效果（3D饼图、3D柱状图）一律禁止，扭曲数据感知
2. **禁止双Y轴超过2个**：组合图最多2个Y轴，避免视觉混乱
3. **禁止饼图超过6个类别**：超过6个类别必须使用条形图或表格
4. **禁止折线图超过24个数据点**：超过24个点必须降采样或改用表格
5. **禁止无意义的装饰图表**：不能传达新信息的图表必须删除
6. **禁止图表重复表格内容**：如果图表和表格展示的是同一组数据，只保留表格

### 3.4 各报表图表优化方案

| 报表模块 | 当前图表 | 优化建议 | 理由 |
|---------|---------|---------|------|
| 日报表 | 时段营收柱状图 | **保留**，但增加数据表格并列展示 | 时段数据是日报核心，图表+表格互补 |
| 周报表 | 每日营收趋势图 | **保留折线图**，但增加周同比曲线 | 趋势对比是周报核心价值 |
| 月报表 | 营收构成饼图 | **删除饼图**，改为百分比堆叠柱状图+明细表格 | 饼图仅3个类别，信息密度低 |
| 季报表 | 季度营收利润图 | **保留**，但增加去年同期对比 | 季度对比需要历史参照 |
| 年报表 | 月度营收目标图 | **保留组合图**，增加目标达成率标注 | 年度目标追踪是核心诉求 |
| 利润分析 | 收支利润趋势图 | **保留**，增加成本结构瀑布图 | 利润分析需要多维度展示 |

## 四、专业报表布局设计

### 4.1 信息层级架构（Z型阅读路径）

```
┌─────────────────────────────────────────────────────────────┐
│  L1: 页面标题 + 全局筛选器（日期范围/门店选择）              │
├─────────────────────────────────────────────────────────────┤
│  L2: 核心KPI卡片行（4-6个关键指标，带同比/环比/目标达成）    │
├─────────────────────────────────────────────────────────────┤
│  L3: 核心数据区（数据表格为主，图表为辅）                    │
│     ┌──────────────────────────────┬─────────────────────┐ │
│     │  主数据表格（占60-70%宽度）   │  辅助信息/迷你图表  │ │
│     │                              │  （占30-40%宽度）   │ │
│     └──────────────────────────────┴─────────────────────┘ │

│  L4: 明细数据区（可展开/折叠的详细表格）                     │
├─────────────────────────────────────────────────────────────┤
│  L5: 异常提示与行动建议（智能洞察区域）                      │
└─────────────────────────────────────────────────────────────┘
```

## 五、交互体验优化

### 5.1 全局筛选器设计

```
┌─────────────────────────────────────────────────────────────┐
│  [日期范围: 2024-05-01 至 2024-05-13 ▼]                    │
│  [门店: 全部门店 ▼] [渠道: 全部 ▼] [对比: 上周 ▼]          │
│  [刷新] [导出Excel] [导出PDF]                               │
└─────────────────────────────────────────────────────────────┘
```

**筛选器规范**：
- 日期范围：支持快捷选择（今日/本周/本月/本季/本年/自定义）
- 门店选择：支持多选，最多选择10个门店（超过显示"已选10+"）
- 对比维度：支持环比（上周/上月）、同比（去年同期）
- 筛选器状态持久化：切换报表Tab时保留筛选条件

### 5.2 数据钻取设计

| 钻取层级 | 触发方式 | 目标页面 | 数据粒度 |
|---------|---------|---------|---------|
| 汇总 → 明细 | 点击KPI卡片 | 对应明细表格 | 汇总 → 明细行 |
| 门店 → 门店详情 | 点击门店名称 | 门店经营详情页 | 门店维度 |
| 日期 → 日期详情 | 点击日期 | 日报表（该日期） | 日期维度 |
| 品类 → 品类详情 | 点击品类名称 | 品类销售分析页 | 品类维度 |

**钻取交互规范**：
- 可点击元素必须有hover状态（颜色变化+手型光标）
- 钻取后显示面包屑导航，支持返回上级
- 钻取过程有加载状态提示

### 5.3 数据联动设计


| 导出类型 | 格式 | 内容 | 适用场景 |
|---------|------|------|---------|
| 导出当前页 | Excel (.xlsx) | 当前可见的所有数据 | 二次分析 |
| 导出当前页 | PDF (.pdf) | 当前页面截图+数据 | 汇报展示 |
| 导出明细 | Excel (.xlsx) | 当前报表的完整明细数据 | 数据核查 |
| 批量导出 | Excel (.xlsx) | 多个报表合并导出 | 月度/季度汇报 |

**导出规范**：
- 导出文件命名：`经营报表_日报_20240513.xlsx`
- Excel导出包含数据+图表（如适用）
- 大数据量导出（>10000行）采用异步导出+邮件通知
