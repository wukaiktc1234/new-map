## 四、技术债务清单

| 序号 | 债务项 | 说明 | 优先级 |
|------|--------|------|--------|
| 1 | TypeScript严格模式未开启 | `noImplicitAny=false`, `strictNullChecks=false` | 高 |
| 2 | 数据库MySQL到PostgreSQL迁移未完成 | 需完成全部SQL语法和驱动适配 | 高 |
| 3 | pom.xml JDK版本需从17升级到21 | 影响虚拟线程等新特性使用 | 高 |
| 4 | 后端缺少代码质量检查工具 | 缺少checkstyle/spotbugs | 中 |
| 5 | 前端npm run build不含类型检查 | 构建流程未强制类型校验 | 中 |
| 6 | 部分模块状态字段映射不统一 | 前后端状态值不一致 | 中 |
| 7 | 时间字段命名不统一 | `created_at`/`create_time`/`created_time`混用 | 中 |

## 五、代码审查清单（强制）

### 5.1 新增API必须检查

- [ ] 使用request实例发送请求
- [ ] 参数传递方式正确（GET直接传params）
- [ ] 响应数据提取正确（不访问.data）
- [ ] 错误处理完整
- [ ] 类型定义完整（禁止any）

### 5.2 新增后端接口必须检查

- [ ] 实体类有@TableLogic注解
- [ ] 查询不手动添加deleted条件
- [ ] 返回统一Result格式
- [ ] 权限注解正确
- [ ] 参数校验完整

### 5.3 提交前必须检查

- [ ] 前端构建成功：`npm run build`
- [ ] 后端编译成功：`mvn compile`
- [ ] 无TypeScript类型错误
- [ ] 无console.log调试代码
- [ ] 无未使用的变量和导入
