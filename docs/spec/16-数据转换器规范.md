# 食品溯源系统 - 数据转换器规范

> 本文档定义了前端DataConverter的设计模式、接口规范和实现标准，确保前后端数据映射的一致性和可维护性。

## 文档版本

| 版本 | 日期 | 说明 |
|------|------|------|
| v1.0 | 2026-04-13 | 初始版本 |

## 第一章 总则

### 1.1 为什么需要DataConverter

前后端数据结构存在天然差异：

| 维度 | 前端 | 后端 |
|------|------|------|
| 状态字段 | `'active'` / `'inactive'` | `1` / `0` |
| 日期格式 | `'YYYY-MM-DD HH:mm:ss'` | `LocalDateTime` |
| 金额单位 | 元（浮点） | 分（整数） |
| 关联字段 | 使用名称显示 | 使用ID关联 |
| 布尔值 | `true` / `false` | `1` / `0` |

DataConverter的职责是在API边界处完成这些转换，确保：
- 组件层只处理前端友好的数据格式
- API层只发送后端期望的数据格式
- 转换逻辑集中管理，不散落在各组件中

### 1.2 核心原则【强制】

- **双向转换**：每个Converter必须提供 `toFrontend` 和 `toBackend` 方法
- **纯函数**：转换方法不得有副作用，不得调用API
- **类型安全**：所有输入输出必须有明确的类型定义
- **可组合**：Converter之间可以组合使用
- **可测试**：每个Converter方法必须有对应的单元测试

## 第二章 DataConverter 接口规范【强制】

### 2.1 基础接口

```typescript
interface DataConverter<F, B> {
  toFrontend(backend: B): F;
  toBackend(frontend: F): B;
  toFrontendList(backendList: B[]): F[];
  toBackendList(frontendList: F[]): B[];
}
```

### 2.2 完整接口（含表单转换）

```typescript
interface FullDataConverter<F, B, Form = F> extends DataConverter<F, B> {
  toFrontend(backend: B): F;
  toBackend(frontend: F): B;
  toForm(data: F): Form;
  fromForm(form: Form): F;
  toFrontendList(backendList: B[]): F[];
  toBackendList(frontendList: F[]): B[];
}
```

### 2.3 类型命名规范

| 类型 | 命名格式 | 示例 |
|------|---------|------|
| 前端展示类型 | `{Entity}` | `Employee` |
| 后端数据类型 | `{Entity}Backend` | `EmployeeBackend` |
| 表单数据类型 | `{Entity}FormData` | `EmployeeFormData` |
| Converter类 | `{Entity}DataConverter` | `EmployeeDataConverter` |

## 第三章 实现规范

### 3.1 文件位置

```
src/api/{module}/converters.ts
```

### 3.2 标准实现模板

```typescript
import type { DataConverter } from '@/types/converter';
import type { Employee, EmployeeBackend, EmployeeFormData } from '@/types/hr';

const statusMap = {
  1: 'active',
  0: 'inactive',
  2: 'probation'
} as const;

const statusReverseMap = {
  active: 1,
  inactive: 0,
  probation: 2
} as const;

export const employeeDataConverter: DataConverter<Employee, EmployeeBackend> & {
  toForm: (data: Employee) => EmployeeFormData;
  fromForm: (form: EmployeeFormData) => Employee;
} = {
  toFrontend(backend: EmployeeBackend): Employee {
    return {
      id: String(backend.employee_id),
      name: backend.name,
      department: backend.department_name,
      departmentId: String(backend.department_id),
      position: backend.position_name,
      positionId: String(backend.position_id),
      status: statusMap[backend.status as keyof typeof statusMap] || 'inactive',
      statusLabel: statusMap[backend.status as keyof typeof statusMap] === 'active' ? '在职' : '离职',
      phone: backend.phone || '',
      email: backend.email || '',
      entryDate: backend.entry_time ? formatDate(backend.entry_time) : '',
      createTime: formatDateTime(backend.create_time),
      updateTime: formatDateTime(backend.update_time)
    };
  },

  toBackend(frontend: Employee): EmployeeBackend {
    return {
      employee_id: Number(frontend.id),
      name: frontend.name,
      department_id: Number(frontend.departmentId),
      department_name: frontend.department,
      position_id: Number(frontend.positionId),
      position_name: frontend.position,
      status: statusReverseMap[frontend.status as keyof typeof statusReverseMap] ?? 0,
      phone: frontend.phone || null,
      email: frontend.email || null,
      entry_time: frontend.entryDate ? parseDate(frontend.entryDate) : null,
      create_time: parseDateTime(frontend.createTime),
      update_time: parseDateTime(frontend.updateTime)
    };
  },

  toFrontendList(backendList: EmployeeBackend[]): Employee[] {
    return backendList.map(item => this.toFrontend(item));
  },

  toBackendList(frontendList: Employee[]): EmployeeBackend[] {
    return frontendList.map(item => this.toBackend(item));
  },

  toForm(data: Employee): EmployeeFormData {
    return {
      name: data.name,
      departmentId: data.departmentId,
      positionId: data.positionId,
      status: data.status,
      phone: data.phone,
      email: data.email,
      entryDate: data.entryDate
    };
  },

  fromForm(form: EmployeeFormData): Employee {
    return {
      id: '',
      name: form.name,
      department: '',
      departmentId: form.departmentId,
      position: '',
      positionId: form.positionId,
      status: form.status,
      statusLabel: '',
      phone: form.phone,
      email: form.email,
      entryDate: form.entryDate,
      createTime: '',
      updateTime: ''
    };
  }
};
```

## 第四章 常见转换规则

### 4.1 状态字段映射

```typescript
const statusConverter = {
  toFrontend(backendValue: number): string {
    const map: Record<number, string> = { 1: 'active', 0: 'inactive', 2: 'probation' };
    return map[backendValue] ?? 'inactive';
  },
  toBackend(frontendValue: string): number {
    const map: Record<string, number> = { active: 1, inactive: 0, probation: 2 };
    return map[frontendValue] ?? 0;
  }
};
```

### 4.2 日期时间转换

```typescript
const dateTimeConverter = {
  toFrontend(backendValue: string): string {
    return backendValue ? dayjs(backendValue).format('YYYY-MM-DD HH:mm:ss') : '';
  },
  toBackend(frontendValue: string): string {
    return frontendValue ? dayjs(frontendValue).format('YYYY-MM-DDTHH:mm:ss') : '';
  }
};
```

### 4.3 金额元分转换

```typescript
const amountConverter = {
  toFrontend(backendCents: number): string {
    return (backendCents / 100).toFixed(2);
  },
  toBackend(frontendYuan: string): number {
    return Math.round(Number(frontendYuan) * 100);
  }
};
```

### 4.4 ID/名称关联字段

```typescript
const relationConverter = {
  toFrontend(backendId: number, nameMap: Map<number, string>): { id: string; name: string } {
    return {
      id: String(backendId),
      name: nameMap.get(backendId) ?? ''
    };
  },
  toBackend(frontendId: string): number {
    return Number(frontendId);
  }
};
```

## 第五章 与API层集成规范【强制】

### 5.1 API文件中使用Converter

```typescript
import { employeeDataConverter } from './converters';
import type { Employee } from '@/types/hr';

export const employeeApi = {
  async getList(params: EmployeeQuery): Promise<PageResponse<Employee>> {
    const res = await request.get<PageResponse<EmployeeBackend>>('/v1/employees', params);
    return {
      ...res,
      records: employeeDataConverter.toFrontendList(res.records)
    };
  },

  async create(data: EmployeeFormData): Promise<Employee> {
    const employee = employeeDataConverter.fromForm(data);
    const backend = employeeDataConverter.toBackend(employee);
    const res = await request.post<EmployeeBackend>('/v1/employees', backend);
    return employeeDataConverter.toFrontend(res);
  }
};
```

### 5.2 禁止事项

- 禁止在组件中直接做状态字段映射（如 `status === 1 ? '在职' : '离职'`）
- 禁止在组件中直接做金额元分转换
- 禁止在Converter中调用API或访问Store
- 禁止Converter方法返回Promise

## 第七章 测试规范【强制】

### 7.1 测试要求

每个Converter必须测试：
- `toFrontend`：后端数据 → 前端数据
- `toBackend`：前端数据 → 后端数据
- `toFrontendList`：批量转换
- 边界值：空值、null、undefined、非法值

### 7.2 测试模板

```typescript
import { describe, it, expect } from 'vitest';
import { employeeDataConverter } from '../converters';

describe('employeeDataConverter', () => {
  describe('toFrontend', () => {
    it('应正确转换状态字段', () => {
      const result = employeeDataConverter.toFrontend({ status: 1, ... });
      expect(result.status).toBe('active');
    });

    it('应处理空值', () => {
      const result = employeeDataConverter.toFrontend({ email: null, ... });
      expect(result.email).toBe('');
    });
  });

  describe('toBackend', () => {
    it('应正确转换状态字段', () => {
      const result = employeeDataConverter.toBackend({ status: 'active', ... });
      expect(result.status).toBe(1);
    });
  });
});
```
