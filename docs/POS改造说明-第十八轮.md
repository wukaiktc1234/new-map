# 第十八轮：交班金额核对（钱箱应有/实点/长短款）+ 金额与状态动效

> 后端修交班算例前先把"可验算"这件事做进界面：现在能一眼验 `钱箱应有 = 备用金 + 现金收入 − 现金退款`，
> 并支持录入实点现金算长短款。同时补了两处克制的动效。

---

## 1. 钱箱核对（配合后端交班算例验证）

hero 里新增三行结构：

```
应上交现金  ¥0.20     现金收入 ¥0.30 − 现金退款 ¥0.10 = 净现金 ¥0.20
           ────────────────────────────────────────────────
钱箱应有现金  备用金 ¥300.10 + 现金收入 ¥0.30 − 现金退款 ¥0.10      ¥300.30
实点现金      [ ¥290.30 ]                                  短款 ¥10.00
应上交现金 = 钱箱应有 − 备用金（负数按 0 交）；实点与应有不一致时，请在备注里写明差异原因。
```

- **钱箱应有现金** = 备用金 + 现金收入 − 现金退款（`data-test="shift-drawer-expected"`）
- **应上交现金** = max(0, 现金收入 − 现金退款)（备用金留在钱箱，不参与上交）
- **实点现金** 输入框 + **长短款**胶囊：0 → 绿色「账实相符」；正 → amber「长款 ¥X」；负 → 红色「短款 ¥X」
- 全部金额走**整数分**运算（`toCents`），避免 `0.1+0.2` 这类浮点漂移

## 2. 算例验证（新增 16 项断言）

| 算例 | 备用金 | 现金收入 | 现金退款 | 钱箱应有 | 应上交 |
|---|---|---|---|---|---|
| 普通 | 300.00 | 100.00 | 40.00 | **360.00** ✅ | 60.00 ✅ |
| 小数 | 300.10 | 0.30（0.20+0.10） | 0.10 | **300.30** ✅ | 0.20 ✅ |
| 退款大于收款 | 500.00 | 0.00 | 36.00 | **464.00** ✅ | 0.00 ✅ |

每个算例还断言：实点=应有 → 「账实相符」；实点少 10 → 「短款 ¥10.00」；翻牌动画最终值精确到分。

## 3. 动效（克制，可关闭）

**金额翻牌**（`AnimatedAmount.vue`）：
- 只在金额**变化**时按 `requestAnimationFrame` 从旧值滚到新值（520ms，easeOutCubic），首屏直接落地
- 按分插值，尾数不抖；`prefers-reduced-motion` 时直接给终值
- 货币符号改用 `::before` 伪元素 → DOM 里只有数字，复制/读屏/断言都干净

**订单详情状态**：
- 支付状态 / 后厨状态加 `<Transition name="status-pop">`，状态变化时上浮淡入（180ms），不再是文字硬切
- 状态徽章改胶囊 + 前置状态点；「制作中 / 待制作」叠加呼吸点（`status-breathe` 1.8s + 外圈 `status-ping`）
- 同样受 `prefers-reduced-motion` 约束
