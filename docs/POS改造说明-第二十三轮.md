# 第二十三轮：去掉重复统计，异常单并入收款统计表

> 反馈：顶部异常条 与 底部订单统计行 功能重复。已合并为一处统计 + 一处说明。

## 改后结构（一个统计表 + 一条口径说明）

```
按班次交班 · 统计区间 09:00 至现在 · 本班次含异常单，处理完才能交班   ← 只解释口径，不再报数、不再放按钮

本班次收款统计                                    共 2 笔 · ¥62.00
收款方式      笔数        小计       异常      详情
现金          1 笔 退1    ¥17.00     1 笔      详情
微信          1 笔        ¥45.00     —         详情
支付宝        0 笔        ¥0.00      —         详情
────────────────────────────────────────────
有效订单 3 笔 · 退款 1 笔 · 异常单 1 笔        [处理异常单]   ← 唯一的异常入口
```

## 具体改动

1. **删除底部独立的「订单统计」卡片**，把有效订单 / 退款 / 异常单并进统计表的**合计行**；
2. **异常处理按钮只保留一个**（合计行右侧，异常 > 0 时红色描边）；
3. **顶部条改为口径说明**：只写「按班次交班 · 统计区间 · 异常单处理完才能交班」，不再重复数量、不再重复“去处理”；
4. **表格新增两列信息**：
   - `笔数` 里补 `退 N`（退款笔数），解决“有退款但显示 0 笔”的误导；
   - 新增 `异常` 列，按支付方式显示各自挂着的异常单数（待付/无流水归到对应方式，未识别的归 `unpaid` 行）；
5. 合计行与表头共用网格，视觉上仍是一张表。
