# Inventory UOM Model (Phase 7)

## 核心问题：单位的语义层次与转换关系

> 同一种物料在不同业务场景使用不同单位，如何建立统一的语义模型？

---

## 1. UOM 语义层次定义

| UOM 类型 | 定义 | 使用场景 | 示例 |
|----------|------|----------|------|
| **Base UOM** | 最小不可分割的计量单位 | 成本核算、库存存储 | ml, g, 个 |
| **Stock UOM** | 仓库库存管理单位 | 库存收发、盘点 | 瓶, 袋, kg |
| **Purchase UOM** | 采购订单单位 | 供应商采购 | 箱, 托, pallet |
| **Sales UOM** | 销售出库单位 | 门店销售/领用 | 份, 杯, 瓶 |
| **Recipe UOM** | 菜谱配方单位 | 菜品制作用量 | ml, g, 片 |

### 2.2 UOM 存储问题分析

| 问题 | 现状 | 风险 |
|------|------|------|
| **存储分散** | 5 张表各自存储 unit 字段 | 同一物料不同表的单位可能不一致 |
| **类型不统一** | VARCHAR 各种长度 (20/32/50) | 无外键约束，单位值可随意填写 |
| **无转换关系** | 各表独立存储 | 采购"箱"→库存"瓶"无法自动转换 |
| **与 inventory_unit 脱节** | 未关联到单位主数据 | 单位主数据形同虚设 |

## 4. UOM 转换关系模型

### 4.1 转换链路设计

```
┌─────────────────────────────────────────────────────────────────┐
│                    UOM Conversion Chain                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Purchase UOM ──────→ Stock UOM ──────→ Recipe UOM             │
│       │                    │                    │                │
│       │                    │                    │                │
│       ↓                    ↓                    ↓                │
│  ┌─────────┐         ┌─────────┐         ┌─────────┐           │
│  │ 箱→瓶   │         │ 瓶→ml   │         │ ml→ml   │           │
│  │ ×24     │         │ ×330    │         │ ×1      │           │
│  └─────────┘         └─────────┘         └─────────┘           │
│                                                                 │
│       │                    │                    │                │
│       └────────────────────┼────────────────────┘               │
│                            ↓                                    │
│                    ┌───────────────┐                            │
│                    │   Base UOM    │                            │
│                    │   (ml/g/个)   │                            │
│                    └───────────────┘                            │
│                            ↑                                    │
│                            │                                    │
│                    ┌───────────────┐                            │
│                    │   Sales UOM   │                            │
│                    │  (瓶/份/杯)   │                            │
│                    └───────────────┘                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 转换系数存储设计

```sql
-- 推荐：UOM 转换关系表
CREATE TABLE uom_conversion (
    id                BIGINT PRIMARY KEY,
    material_id       BIGINT NOT NULL,          -- 物料ID（不同物料可能有不同的转换系数）
    from_uom          VARCHAR(20) NOT NULL,     -- 源单位
    to_uom            VARCHAR(20) NOT NULL,     -- 目标单位
    conversion_factor DECIMAL(12,6) NOT NULL,   -- 转换系数 (1 from = factor to)
    uom_type          VARCHAR(20) NOT NULL,     -- 转换类型: same_level / cross_level
    density           DECIMAL(12,6),            -- 密度（kg/L），用于重量-体积转换
    is_active         BOOLEAN DEFAULT TRUE,
    created_at        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE (material_id, from_uom, to_uom)
);

-- 示例数据
INSERT INTO uom_conversion (material_id, from_uom, to_uom, conversion_factor, uom_type) VALUES
-- 可乐: 箱 → 瓶
(1, '箱', '瓶', 24.000000, 'same_level'),
-- 可乐: 瓶 → ml
(1, '瓶', 'ml', 330.000000, 'cross_level'),
-- 食用油: 桶 → ml
(2, '桶', 'ml', 5000.000000, 'cross_level'),
-- 大米: 袋 → kg
(3, '袋', 'kg', 50.000000, 'same_level'),
-- 大米: kg → g
(3, 'kg', 'g', 1000.000000, 'same_level');
```

## 6. 推荐的 Canonical UOM Model

### 6.1 单位语义层次设计

```
┌─────────────────────────────────────────────────────────────────┐
│                 Canonical UOM Hierarchy                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Layer 1: Base UOM (基础单位)                                   │
│  ├── 定义: 最小不可分割的计量单位                               │
│  ├── 特性: 用于成本核算、库存精确存储                           │
│  ├── 示例: ml (体积), g (重量), 个 (数量)                       │
│  └── 存储: 每种物料定义一个 Base UOM                            │
│                                                                 │
│  Layer 2: Stock UOM (库存单位)                                  │
│  ├── 定义: 仓库收发、库存管理的主要单位                         │
│  ├── 特性: 库存数量以此单位记录                                 │
│  ├── 示例: 瓶, 袋, 桶, kg                                       │
│  └── 转换: 1 Stock UOM = N Base UOM                            │
│                                                                 │
│  Layer 3: Transaction UOM (业务单位)                            │
│  ├── 定义: 各业务环节使用的单位                                 │
│  ├── 特性: 可与 Stock UOM 不同，需转换                          │
│  ├── 子类型:                                                   │
│  │   ├── Purchase UOM (采购)                                   │
│  │   ├── Sales UOM (销售)                                      │
│  │   └── Recipe UOM (配方)                                     │
│  └── 转换: 需通过 UOM Conversion Table 转换                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 6.2 推荐的物料 UOM 主数据结构

```sql
-- 物料单位主数据（推荐结构）
CREATE TABLE material_uom (
    id                BIGINT PRIMARY KEY,
    material_id       BIGINT NOT NULL,
    uom_usage         VARCHAR(20) NOT NULL,     -- BASE/STOCK/PURCHASE/SALES/RECIPE
    uom_code          VARCHAR(20) NOT NULL,     -- 关联 inventory_unit.code
    conversion_to_base DECIMAL(12,6),           -- 到基础单位的转换系数
    is_default        BOOLEAN DEFAULT FALSE,    -- 是否默认单位
    created_at        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE (material_id, uom_usage)
);

-- 示例：可乐的单位定义
INSERT INTO material_uom (material_id, uom_usage, uom_code, conversion_to_base, is_default) VALUES
(1, 'BASE',     'ML',   1.000000,  FALSE),   -- Base: ml
(1, 'STOCK',    'BOT',  330.0000,  TRUE),    -- Stock: 瓶 (1瓶=330ml)
(1, 'PURCHASE', 'CS',   7920.000,  FALSE),   -- Purchase: 箱 (1箱=24瓶=7920ml)
(1, 'SALES',    'BOT',  330.0000,  FALSE),   -- Sales: 瓶
(1, 'RECIPE',   'ML',   1.000000,  FALSE);   -- Recipe: ml
```

## 7. UOM 业务场景转换规则

### 7.1 采购入库转换

```
┌─────────────────────────────────────────────────────────────────┐
│                  采购入库 UOM 转换规则                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  输入:                                                          │
│    purchase_order.quantity = 10                                 │
│    purchase_order.unit = 箱 (Purchase UOM)                      │
│                                                                 │
│  转换:                                                          │
│    1. 查询 material_uom WHERE uom_usage='PURCHASE'             │
│    2. 获取 conversion_to_base = 7920 (箱→ml)                   │
│    3. 查询 material_uom WHERE uom_usage='STOCK'                │
│    4. 获取 conversion_to_base = 330 (瓶→ml)                    │
│    5. 计算: 10 × 7920 / 330 = 240 瓶                           │
│                                                                 │
│  输出:                                                          │
│    inventory.current_stock += 240 (Stock UOM: 瓶)              │
│    inventory_transactions.quantity_change = 240                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 7.2 配方扣减转换

```
┌─────────────────────────────────────────────────────────────────┐
│                  配方扣减 UOM 转换规则                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  输入:                                                          │
│    dish_recipe.quantity = 100                                  │
│    dish_recipe.unit = ml (Recipe UOM)                          │
```

## 8. 结论与建议

### 8.1 核心结论

| 结论 | 说明 |
|------|------|
| **UOM 分散存储** | 5 张表各自存储 unit，无统一管理 |
| **无转换关系** | 采购→库存→配方→销售的单位无法自动转换 |
| **与 inventory_unit 脱节** | 单位主数据未被实际使用 |
| **精度风险** | 跨单位转换可能产生无限小数 |

### 8.2 改进建议

1. **建立 UOM 主数据**：完善 inventory_unit 表，增加 Base UOM 定义
2. **建立转换关系表**：新增 uom_conversion 表存储单位转换系数
3. **物料 UOM 主数据**：新增 material_uom 表定义每种物料的各单位
4. **业务层转换**：在采购入库、配方扣减等环节增加 UOM 转换逻辑
5. **统一库存单位**：建议 inventory 和 store_inventory 使用统一的 Stock UOM
