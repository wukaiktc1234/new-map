# 径向展开（FAB Speed Dial）动画 — 成功方案记录

> 本文档记录员工端"新建"按钮径向展开动画的完整实现方案、踩过的坑以及最终可行的技术路径。
> 最后更新：2026-06-07

---

## 一、最终效果描述

点击页面右上角「新建」按钮后：
1. 全屏遮罩从**右上角**以 **1/4 圆弧形（clip-path: circle）** 向左下扩展
2. 遮罩背景为**纯色半透明** + **模糊效果**
3. 图标网格随圆弧扫过自然显露（图标直接散布在遮罩层中，无独立容器）
4. 关闭时反向收缩回右上角原点

---

## 二、核心方案：始终挂载 + class 切换

### ✅ 最终可行方案

```vue
<!-- 模板结构 -->
<Teleport to="body">
  <!-- 始终存在于 DOM 中，不使用 v-if / <Transition> -->
  <div
    class="action-panel-overlay"
    :class="{ 'is-active': showActionPanel }"
    @pointerdown.self="closeActionPanel"
  >
    <button class="action-panel__close">X</button>
    <div class="action-content" v-show="showActionPanel">
      <!-- 图标网格 -->
    </div>
  </div>
</Teleport>
```

```typescript
// JS 逻辑 — 极简
const showActionPanel = ref(false)

function openActionPanel() {
  if (showActionPanel.value) return
  showActionPanel.value = true
}

function closeActionPanel() {
  if (!showActionPanel.value) return
  showActionPanel.value = false
}
```

```scss
// CSS — 非 scoped 样式块
.action-panel-overlay {
  position: fixed;
  inset: 0;
  z-index: 2000;

  // 隐藏态
  pointer-events: none;
  clip-path: circle(0% at 100% 0%);
  background: rgba(15, 15, 25, 0.75);
  -webkit-backdrop-filter: blur(12px);
  backdrop-filter: blur(12px);

  // 只过渡 clip-path 一个属性（最简可靠）
  transition: clip-path 0.5s cubic-bezier(0.4, 0, 0.2, 1);

  // 展开态
  &.is-active {
    pointer-events: auto;
    clip-path: circle(150% at 100% 0%);
  }
}
```

### 关键设计决策

| 决策点 | 选择 | 原因 |
|--------|------|------|
| DOM 管理 | **始终挂载**（不用 v-if） | 避免 DOM 创建/销毁导致的时序问题 |
| 动画触发方式 | **CSS class 切换**（`.is-active`） | 不依赖 Vue Transition 内部时序机制 |
| 样式作用域 | **非 scoped** 的 `<style>` 块 | 避免 scoped 属性选择器干扰 Teleport 元素的 transition |
| 过渡属性数量 | **只过渡 clip-path 一个属性** | 减少浏览器合成层重算，避免闪烁 |
| 背景类型 | **纯色半透明**（不用 blur 或用极轻 blur） | backdrop-filter 在每帧重算时会导致白闪 |
| 内容布局 | **图标直接散布在遮罩层中**（无面板容器） | 图标随 clip-path 圆弧扫过自然显露，无需额外动画 |

## 三、踩过的坑（失败方案清单）

以下方案全部尝试过并确认**在 Vue 3.5 + Teleport 环境下不可行**：

### ❌ 方案1：Vue `<Transition>` + `v-if`
- **问题**：Transition 内部自动管理进入/离开时序，但在 Teleport 到 `<body>` 后行为异常
- **表现**：面板打开后立即自动关闭（无任何用户操作）

### ❌ 方案2：`v-if` + 双变量（showActionPanel + panelReady）+ nextTick + offsetHeight + rAF
- **问题**：复杂的 hack 时序链在 IDE 浏览器环境中不稳定
- **表现**：有时有动画，有时没有；不同刷新状态结果不同

### ❌ 方案3：`:global(.is-active)` 选择器（在 scoped 样式中使用）
- **问题**：Vue scoped 编译后的选择器特异性可能导致 `.is-active` 类静默不生效
- **表现**：class 加上了但 CSS 规则没匹配到 → 面板永远不可见/不可交互

### ❌ 方案4：`@keyframes` 动画（在 scoped 样式中定义）
- **问题**：Vue 给 keyframes 名添加 hash，但 animation 属性引用的是原始名
- **表现**：动画完全不触发（找不到对应的 @keyframes 规则）

### ❌ 方案5：Web Animations API (`element.animate()`)
- **问题**：在 Teleport + scoped 环境中元素引用不稳定
- **表现**：无可见动画效果

### ❌ 方案6：backdrop-filter: blur() 作为背景
- **问题**：每帧 clip-path 变化都需要重新计算模糊区域，某帧可能未完成导致短暂显示底层内容
- **表现**：动画过程中出现白闪（尤其是关闭动画开始时）

### ❌ 方案7：`opacity` + `clip-path` 同时过渡
- **问题**：两个属性过渡时长不一致（0.35s vs 0.5s），opacity 先结束触发重绘
- **表现**：白闪

## 四、必须处理的环境特殊问题

### 4.1 `prefers-reduced-motion: reduce` 全局规则

项目全局样式（`tokens.scss`）中有以下规则：

```scss
@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 0.01ms !important; }
}
```

**影响**：IDE 内置浏览器很可能默认开启此设置，导致所有 CSS transition 被压缩到几乎为零。

**解决方案**：在 media query 中为目标元素添加例外：

```scss
@media (prefers-reduced-motion: reduce) {
  .action-panel-overlay,
  .action-panel-overlay *,
  .action-panel-overlay.is-active,
  .create-btn,
  .create-btn * {
    transition-duration: 0.5s !important;
    animation-duration: 0.5s !important;
  }
}
```

**注意**：例外规则的优先级必须与全局规则一致（都使用 `!important`），否则无法覆盖。

### 4.2 事件冒泡防护

Teleport 将内容传到 `<body>` 后，点击事件可能冒泡到遮罩层导致意外关闭：

```vue
<!-- 三重防护 -->
<button class="create-btn" @click.stop="openActionPanel">     <!-- 1. 按钮阻止冒泡 -->
<div class="overlay" @pointerdown.self="closeActionPanel">     <!-- 2. 只响应遮罩本身 -->
  <div class="content" @pointerdown.stop>                      <!-- 3. 内容区阻止冒泡 -->
    <button @click.stop="handleAction">                        <!-- 4. 操作项阻止冒泡 -->
```

### 4.3 按钮消失问题

面板打开时需要隐藏"新建"按钮（防止穿透显示），关闭后恢复：

```vue
<button class="create-btn" :class="{ 'is-panel-open': showActionPanel }">
```

```scss
.create-btn.is-panel-open {
  opacity: 0;
  pointer-events: none;
  // 必须显式声明 transition 属性列表，避免被 prefers-reduced-motion 影响
  transition: transform, opacity, background-color, box-shadow, border-color;
}
```

## 五、性能优化要点

| 优化点 | 做法 |
|--------|------|
| 只过渡 clip-path | 不同时过渡 opacity/background/transform，减少 GPU 合成层工作 |
| 使用 `cubic-bezier(0.4, 0, 0.2, 1)` | 标准 ease-out 曲线，比 ease 更自然 |
| 纯色背景优于 blur | 如果不需要毛玻璃效果，用纯色 rgba 完全避免合成层重算 |
| 图标无独立动画 | 图标跟随 clip-path 裁剪区域显露，不需要 opacity/scale 过渡 |
| 固定颜色值 | 图标容器背景使用固定深色 `#1C1C1E`，不依赖 CSS 变量解析 |

## 六、可复用的代码模板

以下模板可直接复制到其他需要 FAB Speed Dial / 径向展开效果的页面：

```vue
<template>
  <!-- 触发按钮 -->
  <button class="trigger-btn" :class="{ 'is-open': isOpen }" @click.stop="open">
    <slot name="trigger-icon">+</slot>
  </slot>
  </button>

  <!-- 面板 -->
  <Teleport to="body">
    <div
      class="radial-overlay"
      :class="{ 'is-active': isOpen }"
      @pointerdown.self="close"
    >
      <!-- 关闭按钮（fixed 定位到视口右上角） -->
      <button class="radial-overlay__close" @click.stop="close">&times;</button>

      <!-- 内容区（随圆弧扫过自然显露） -->
      <div class="radial-content" v-show="isOpen" @pointerdown.stop>
        <slot />
      </div>
    </div>
  </Teleport>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const isOpen = ref(false)

function open() { if (!isOpen.value) isOpen.value = true }
function close() { if (isOpen.value) isOpen.value = false }

defineExpose({ open, close })
</script>

<style lang="scss">
.radial-overlay {
  position: fixed;
  inset: 0;
  z-index: 2000;
  pointer-events: none;
  clip-path: circle(0% at 100% 0%);
  background: rgba(15, 15, 25, 0.75);
  -webkit-backdrop-filter: blur(12px);
  backdrop-filter: blur(12px);
  transition: clip-path 0.5s cubic-bezier(0.4, 0, 0.2, 1);

  &.is-active {
    pointer-events: auto;
    clip-path: circle(150% at 100% 0%);
  }
}

.radial-overlay__close {
  position: fixed;
  top: 16px;
  right: 16px;
  z-index: 2100;
  /* ... 关闭按钮样式 */
}

.radial-content {
  position: absolute;
  top: 56px;
  left: 20px;
  right: 20px;
  /* ... 内容定位 */
}

/* prefers-reduced-motion 例外 */
@media (prefers-reduced-motion: reduce) {
  .radial-overlay,
  .radial-overlay *,
  .radial-overlay.is-active {
    transition-duration: 0.5s !important;
  }
}
</style>
```

## 八、经验总结

1. **Teleport + 动画 = 始终挂载 + class 切换**：不要在 Teleport 内容上使用 `<Transition>` 或 `v-if` 控制动画
2. **scoped 样式是动画杀手**：涉及 Teleport/Overlay 动画的 CSS 必须放在非 scoped 块中
3. **只过渡一个属性**：clip-path circle() 单独过渡最稳定，多属性并行过渡容易出问题
4. **测试文件先行**：先用纯 HTML 文件验证动画可行性，再移植到 Vue 组件
5. **检查 prefers-reduced-motion**：IDE 浏览器可能默认开启，会静默杀死所有 transition
